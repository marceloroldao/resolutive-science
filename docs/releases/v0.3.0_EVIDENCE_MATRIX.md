## Release-level conclusion

The v0.3 falsification suite supports a narrower conclusion than v0.2 descriptive recurrence alone might suggest:

1. the inference pipeline passes null and injection/recovery calibration tests;
2. a positive best-fit direction recurs descriptively across several previously analyzed families;
3. the logarithmic functional form is not uniquely selected against equally complex smooth controls;
4. the fitted amplitude is sensitive to systematics/channel choices and is not universal across all probes;
5. complexity penalties do not establish RCMS model preference over Lambda-CDM;
6. the preregistered BOSS DR12 out-of-sample positive prediction fails within the frozen primary domain and hits the negative boundary.

Therefore v0.3.0 must not be described as experimental validation, model-selection support, or discovery. Its principal scientific value is a reproducible falsification record that both calibrates the inference pipeline and documents where the current phenomenological surrogate fails to generalize.
