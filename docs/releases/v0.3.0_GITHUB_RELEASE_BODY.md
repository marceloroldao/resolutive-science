# Resolutive Science v0.3.0 — RCMS Falsification Release

## Summary

Resolutive Science v0.3.0 is an adversarial falsification release for the frozen one-parameter RCMS cosmological screening surrogate under `RSMS-1.0-rc.1` compatibility.

The v0.3 line adds Protocols 09–16 and deliberately preserves favorable, limiting, heterogeneous, null, and unfavorable outcomes without response-dependent modification of the model.

Frozen surrogate:

\[
E_{\rm RCMS}^2(z)=\Omega_m(1+z)^3+(1-\Omega_m)+A_R\ln(1+z).
\]

## Scientific scope added in v0.3.0

- **P09** — null false-positive calibration, including realistic DESI DR2 covariance;
- **P10** — injection/recovery calibration;
- **P11** — equal-complexity functional controls;
- **P12** — leave-one-dataset-family-out stress test;
- **P13** — systematics and nuisance sensitivity;
- **P14** — amplitude stability;
- **P15** — complexity-penalized model-selection synthesis;
- **P16** — preregistered out-of-sample BOSS DR12 prediction.

## Principal release-level results

- P09/P10 show no material evidence that the tested inference pipeline intrinsically manufactures positive `A_R` values.
- P11 returns `FUNCTIONALLY_NON_SPECIFIC`: the logarithmic deformation is not uniquely selected against preregistered equally complex smooth controls.
- P12 finds a positive descriptive direction distributed across the previously analyzed dataset families, but this is not an independent discovery significance.
- P13 returns `SYSTEMATICS_SENSITIVE`: radial-only and transverse/volume-only DESI DR2 branches pull the fitted amplitude in materially different directions.
- P14 returns `AMPLITUDE_FAMILY_HETEROGENEOUS`: a single universal amplitude is not established.
- P15 returns `NO_MODEL_SELECTION_PREFERENCE`: complexity penalties do not establish preference over Lambda-CDM.
- P16-T0 passes the held-out BOSS DR12 intake and identifiability gate without evaluating `A_R`.
- P16-T1 does **not** reproduce the preregistered positive prediction. The fit reaches the frozen lower boundary `A_R=-1`, with the profile remaining negative inside the frozen domain. By the preregistered boundary rule the formal classification is `OUT_OF_SAMPLE_INVALID`; the bound is not widened post hoc.
