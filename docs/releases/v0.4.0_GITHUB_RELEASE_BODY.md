# Resolutive Science v0.4.0 — Post-Falsification Diagnostic Release

## Summary

v0.4.0 is a diagnostic negative release following the preregistered v0.3 held-out failure. It preserves the frozen one-parameter RCMS surrogate and asks whether the inconsistency can be organized without post-hoc model rescue.

## Diagnostic block

- **P17:** `DIFFUSE_RESIDUAL_STRUCTURE`
- **P18:** `SURVEY_SPECIFIC_CHANNEL_TENSION`
- **P19:** `NO_REDSHIFT_LOCALITY_EVIDENCE`
- **P20:** `EXACT_Z_SURVEY_DISCORDANCE`

The preregistered development stop is activated:

`DIAGNOSTIC_STOP_NO_EXTENSION`

P21–P24 are not activated because P17–P20 did not produce a stable cross-survey organizing structure suitable for candidate construction.

## Fundamental reconstruction audit

The v0.4 line also preserves the completed audit of the old RSMS fundamental formulation:


The audited `(rho_R, phi_R)` core is equivalent to the conventional polar representation of a complex scalar. RSMS-native `iota_R` and `kappa_R` remain without uniquely derived physical dynamics or observable maps. Selector tests P-A through P-E all return `REJECT_UNDERDETERMINED`.

## Claims boundary

This release does **not** claim discovery of new physics, experimental validation of Resolutive Physics, completeness of Lambda-CDM, or falsification of every possible Resolutive formulation. It records a narrower result: the current RCMS residuals do not justify an empirical extension, and the old RSMS formulation does not uniquely derive a fundamental Master Equation.

## Preservation

The v0.3 tag, DOI `10.5281/zenodo.22643804`, held-out failure, all P17–P20 outcomes, and the fundamental reconstruction negative results remain immutable evidence. No unfavorable result is rewritten to motivate a later formulation.
