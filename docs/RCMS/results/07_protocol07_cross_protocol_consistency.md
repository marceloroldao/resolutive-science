# RCMS Protocol 07 — Cross-Protocol Parameter Consistency Outcome

**Final classification:** `COMMON_POSITIVE_COMPATIBLE`  
**RSMS compatibility:** RSMS-1.0  

## 1. Scope

Protocol 07 performed a preregistered retrospective consistency synthesis of the already-frozen one-dimensional `A_R` profile summaries from P01/02, P03, P04, and P06.

No earlier likelihood was refitted and no frozen best fit or profile interval was changed.

The synthesis explicitly **does not assume statistical independence** among the protocol inputs and therefore does not constitute a combined discovery-level likelihood.

## 2. Frozen inputs

| Source | Best-fit A_R | Delta chi2 <= 1 interval |
|---|---:|---:|
| P01/02 primary | 0.187021 | [0.098671, 0.276779] |
| P03 DES-SN5YR | 0.382099 | [0.055322, 0.707729] |
| P04 eBOSS DR16 | 1.662222508 | [0.650565914, 3.103626193] |
| P06 DESI DR2 | 0.210244178 | [0.05, 0.40] |

P05 was excluded from the primary synthesis because it is a challenge rearrangement of the eBOSS dataset rather than an independent observational likelihood.

## 3. Frozen synthesis method

Each profile was represented by the preregistered asymmetric piecewise-quadratic approximation defined from its frozen best fit and lower/upper `Delta chi2 <= 1` bounds.

The descriptive common profile was

```text
S(A) = sum_i DeltaChi2_i(A)
```

and the common amplitude was the minimizer of `S(A)`.

## 4. Primary result

The hosted GitHub Actions execution returned:

- `A_common = 0.211141330`
- common descriptive `Delta S <= 1` interval: `[0.135547173, 0.289651240]`
- zero inside common interval: `False`
- heterogeneity `Q = 2.403328434`
- descriptive degrees of freedom: `3`
- descriptive chi-square tail probability: `0.493015337`
- descriptive `I2 = 0.0`
- `DeltaS_zero = 7.865934305`

`DeltaS_zero` is retained only as a directional profile diagnostic. It must **not** be converted into a Gaussian discovery significance or formal combined p-value because the required cross-protocol covariance is unavailable and independence was not assumed.

Every leave-one-out common best fit remains positive and every descriptive `Delta S <= 1` interval excludes zero.

Importantly, omitting the high-amplitude and LRG-sensitive P04 profile moves the common amplitude only from approximately `0.211` to approximately `0.203`. Thus P04 does not control the central common-amplitude result.

## 6. Preregistered classification

The frozen `COMMON_POSITIVE_COMPATIBLE` criteria required:

1. positive common amplitude;
2. common `Delta S <= 1` interval excluding zero;
3. heterogeneity `Q <= 7.815`;
4. every leave-one-out common best fit remaining positive.

All four conditions were satisfied.

Therefore the Protocol 07 classification is:

```text
COMMON_POSITIVE_COMPATIBLE
```

## 7. Interpretation

The already-frozen RCMS screening profiles are mutually compatible, at the level of this preregistered descriptive synthesis, with a common positive amplitude near

```text
A_R ~ 0.21
```

The common value is close to both the P01/02 primary best fit (`~0.187`) and the independent DESI DR2 best fit (`~0.210`). The broader DES-SN and eBOSS profiles do not create statistically large heterogeneity under the frozen profile approximation.

This result strengthens the statement that the recurring positive direction is not solely generated by the high-amplitude P04 eBOSS fit.

However, it does **not** demonstrate that RCMS is statistically preferred over Lambda-CDM, because earlier model-selection diagnostics remain weak and because Protocol 07 cannot legitimately pool overlapping datasets as independent evidence.

## 8. Scientific boundary

Protocol 07 is a consistency result for the frozen phenomenological cosmological surrogate `A_R ln(1+z)`.

It does not validate the full Resolutive Physics ontology, does not derive the surrogate from the Resolutive Master Equation, and does not establish a new physical law.

The next major theoretical question is whether the empirically useful `ln(1+z)` deformation can be derived independently from the Resolutive formalism rather than merely retained as a phenomenological screening term.
