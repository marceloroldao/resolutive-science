# v0.5 T17 — Plaquette Curvature Bridge Results

**Status:** theory-only computational consistency result; not physical validation.

## Convention audit

The first implementation draft exposed an important sign-convention issue before results were frozen. With the simulator convention

```text
dU/ds = +A_s U
```

and later column-vector transports multiplying on the left, the compatible curvature convention for this plaquette is

```text
F_xy = partial_x A_y - partial_y A_x - [A_x,A_y].
```

This is convention-equivalent to the more common `dA + A wedge A` after changing the sign used in the transport generator. The code was corrected before freezing T17.

Meanwhile the raw loop defect scales as area (`~h^2`).

## Abelian derivative control

A scalar commuting connection was also used:

```text
a_x=0.3 y
a_y=0.4 x.
```

The commutator is identically zero, while

```text
partial_x a_y-partial_y a_x=0.1.
```

The exact midpoint-linear loop integral gives

```text
(loop integral)/h^2 = 0.1
```

for `h=1e-1,1e-2,1e-3` (up to floating-point representation).

Thus the derivative contribution exists independently of noncommutativity.

## T17 result

Within the deliberately chosen smooth matrix representation:

```text
position variation -> derivative curl term
noncommutativity -> commutator term
closed small plaquette -> area-scaled combined defect
```

and


It does **not** show that a particular D13 primitive transition law coarse-grains to this connection. That stronger emergence claim remains open.
