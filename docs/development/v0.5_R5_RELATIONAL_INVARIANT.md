# v0.5 R5 — Resolutive Relational Invariant Search

**Line:** v0.5 relational ontology  
**Depends on:** R1-R4  
**Status:** STRUCTURAL AUDIT / NEGATIVE FOR UNIQUE NUMERICAL INVARIANT  
**Target-data fitting:** NONE

## 1. Question

Do the structures derived in R1-R4 force any nontrivial scalar or structured invariant that could later become a physical quantity?

No candidate may be called energy, time, action, phase, coherence, or distance merely because it is invariant, additive, or conserved.

## 2. Inherited structure only

R1-R4 provide:

```text
P_R = S_R / ~
I_[R] : [R] -> [R]
T_AB : [R_A] -> [R_B]
Gamma = ordered composition of compatible transitions
pi_end(Gamma) = (source(Gamma), target(Gamma))
```

They do not provide a metric, measure, probability, topology, field, group representation, action, generator, clock, energy scale, or observable algebra.

## 3. Invariants forced structurally

Several **structural** quantities are invariant under change of representative inside a physical-state equivalence class.

### 3.1 Endpoint class

For a transition or trajectory, source and target physical-state classes are well-defined:

```text
source(Gamma) in P_R
target(Gamma) in P_R.
```

They are invariant under replacement of a representative by an equivalent representative.

### 3.2 Closed/open predicate

Define

```text
CLOSE_R(Gamma) = 1 if source(Gamma) ==_phys target(Gamma)
                 0 otherwise.
```

This Boolean property is well-defined on physical-state classes.

### 3.3 Endpoint distinction predicate

From R1/R2:

```text
D_R(A,B) in {0,1}.
```

It is invariant under representative changes, conditional on the admissible readout equivalence.

These are genuine structural invariants but carry no physical units and no magnitude of change.

## 4. Is a unique scalar magnitude forced?

No.

Given only a set/quotient and composable arrows, infinitely many numerical assignments can be constructed:

```text
q(T) = constant
q(T) = arbitrary label-dependent value
q(Gamma) = number of transitions
q(Gamma) = any additive weight after freely choosing edge weights
```

None is selected by R1-R4.

Even imposing additivity

```text
Q(Gamma_2 o Gamma_1) = Q(Gamma_1) + Q(Gamma_2)
```

does not select a unique `Q`; it only selects a class of homomorphism/additive functionals once a codomain and elementary values are supplied.

Therefore:

```text
ADDITIVITY != UNIQUE_PHYSICAL_QUANTITY
```

## 5. Closed trajectories

A closed trajectory

```text
Gamma_loop : [R] -> [R]
```

is structurally distinguishable from identity unless trajectory equivalence later collapses it.

But R1-R4 do not force a nonzero loop invariant.

Possible loop quantities such as winding number, holonomy, phase, action, or accumulated cost require additional topology, connection, representation, metric, or weighting structure.

Thus:

```text
NONTRIVIAL_LOOP_INVARIANT = NOT_DERIVED
```

## 6. Readout-preserving transformations

If a transformation preserves all admissible readouts, it preserves physical-state equivalence by construction. This yields an invariance principle at the representation level, but still no unique numerical observable.

```text
READOUT_PRESERVING_REPRESENTATION_CHANGE = PHYSICALLY_REDUNDANT
```

This is a consistency condition, not new dynamics.

## 7. Conventional comparator

The result matches conventional set/category/quotient reasoning: categorical structure supplies identities, domains/codomains, composability and structural predicates, but numerical physical invariants require additional functorial, metric, measure, topological, probabilistic or representation structure.

```text
R5_NOVELTY = CONVENTIONAL_STRUCTURAL_FOUNDATION
```

## 8. Decision

```text
R5_STRUCTURAL_INVARIANTS = PASS
R5_UNIQUE_NUMERICAL_INVARIANT = NOT_DERIVED
R5_NONTRIVIAL_LOOP_INVARIANT = NOT_DERIVED
R5_ADDITIVE_FUNCTIONAL = UNDERDETERMINED
R5_PHYSICAL_IDENTIFICATION = FORBIDDEN_AT_THIS_STAGE
```

The strongest current invariant is qualitative/structural, not energetic.

## 9. Scientific consequence

The v0.5 ontology has reached a genuine boundary:

```text
RELATIONAL_STRUCTURE ALONE
    does not imply
A UNIQUE PHYSICAL SCALE OR MAGNITUDE.
```

Therefore Resolutive Energy cannot yet be derived from `R_A != R_B` or from composition alone.

A new physical postulate is now required if the project is to obtain a quantitative law.

This postulate must be independently motivated and must reduce freedom rather than merely name an arbitrary functional.

## 10. Candidate next problem — Q1

Before introducing energy, test the weakest possible quantitative extension:

> Does there exist a **Resolutive Valuation** `V_R` on transitions/trajectories whose algebraic properties can be fixed independently of target data?

Candidate properties must be tested separately:

```text
V_R(I) = 0 ?
V_R(Gamma_2 o Gamma_1) = V_R(Gamma_1) + V_R(Gamma_2) ?
V_R(Gamma_rev) = -V_R(Gamma) ?
V_R(Gamma) >= 0 ?
```

These properties are mutually non-equivalent and must not be bundled together by convenience.

If no independent selector exists, record `QUANTITATIVE_EXTENSION_UNDERDETERMINED` and stop before defining Resolutive Energy.
