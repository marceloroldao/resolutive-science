# v0.5 T61 — Mean-Field Degree Law for the T25 Low-Load Recursive Tree

**Status:** FROZEN BEFORE HELD-OUT NUMERICAL TEST  
**Parents:** T25, T47–T50, T58.  
**Purpose:** derive a parameter-free asymptotic degree law for the already-frozen T25 generator and test it on new seeds. This is a mathematical property of the graph generator, not a physical law.

## 1. Generator being analyzed

T25 grows a recursive tree. Each new vertex samples m=5 older vertices uniformly without replacement, orders them by increasing current degree, and attaches to the first candidate with degree < K=6. If all sampled candidates have degree K, it attaches uniformly to one currently unsaturated older vertex.

No Euclidean coordinate or physical time is introduced.

For large n, sampling without replacement differs from independent sampling by O(1/n). T61 therefore uses the asymptotic independent-sampling mean-field law below and tests the finite-n discrepancy on held-out exact simulations.

## 2. Degree fractions

Let p_k be the asymptotic fraction of vertices of degree k, k=1,...,K, with K=6.

Define tail fractions

A_k = sum_{j=k}^K p_j.

Because saturated degree-K vertices cannot accept another edge, a sampled degree-K vertex is skipped.

For k=1,...,K-1, the probability that the first admissible minimum degree among m independent candidates is exactly k is

A_k^m - A_{k+1}^m.

There is one exceptional event: all m sampled candidates have degree K. Its probability is p_K^m. T25 then chooses uniformly from all unsaturated vertices. Conditional on fallback, the probability of selecting degree k is p_k/(1-p_K).

Therefore the asymptotic parent-selection probability is

s_k(p)
=
A_k^m - A_{k+1}^m
+
p_K^m * p_k/(1-p_K),

for k=1,...,K-1,

and s_K=0.

The probabilities satisfy sum_{k=1}^{K-1} s_k = 1.

## 3. Stationary flow equations

Every birth creates one new degree-1 vertex.

Selecting a degree-k parent moves one existing vertex from class k to class k+1.

Hence the expected one-step degree-count increments are

Delta N_1 = 1 - 1[parent degree=1],

Delta N_k = 1[parent degree=k-1] - 1[parent degree=k],  2<=k<=K-1,

Delta N_K = 1[parent degree=K-1].

If N_k(n) ~ p_k n, then stationarity requires p_k=E[Delta N_k], giving

p_1 = 1-s_1,

p_k = s_{k-1}-s_k, 2<=k<=K-1,

p_K = s_{K-1}.

Together with the definition of s_k, these are a closed nonlinear parameter-free system fixed by m=5 and K=6.

## 4. Consistency constraints

Every tree with n vertices has mean degree 2(n-1)/n -> 2. Therefore a valid asymptotic solution must satisfy

sum_k p_k = 1,
sum_k k p_k = 2,
p_k >= 0.

The wedge-density prediction from T50 is

w_infinity = lim W/n
= sum_k binom(k,2) p_k.

This is a derived graph statistic, not physical energy.

## 5. Numerical fixed-point policy

Solve the frozen nonlinear system numerically from the neutral initialization

p=(1/2,1/4,1/8,1/16,1/32,1/32)

renormalized to sum one.

Use deterministic damped fixed-point iteration on the stationary flow map with fixed damping eta=0.1, maximum 100000 iterations, and convergence assessed on the undamped stationarity residual. No empirical histogram is used as initialization and no fitting is allowed.

Convergence gate:
- max absolute stationarity residual <= 1e-13;
- normalization error <= 1e-13;
- mean-degree error <= 1e-10.

If this iteration fails, T61 reports solver failure rather than tuning the initialization against simulation.

## 6. Held-out exact generator test

Use exact T25 degree dynamics, including:
- sample without replacement;
- m=5;
- K=6;
- exact sorted MIN-degree candidate rule;
- exact fallback when all candidates are saturated.

No adjacency matrix is needed because the degree histogram depends only on the parent degrees. The simulator must reproduce T25's RNG operations at each birth: uniform sample without replacement, one tie-breaking random variate per sampled candidate in the sorting key, first unsaturated candidate after sorting, and the original uniform-unsaturated fallback only if all sampled candidates are saturated.

Held-out sizes and seeds, frozen now:

N = 500,000
seeds = {811, 857, 907}.

These seeds have not been used in T25 or T47–T49.

For each run report:
- empirical p_1...p_6;
- mean degree;
- wedge density W/N;
- total-variation distance to the analytic p;
- maximum absolute class error.

## 7. Predeclared gates

T61_FIXED_POINT = PASS if all numerical fixed-point consistency constraints pass.

For the held-out simulations:

T61_DEGREE_LAW = PASS only if all three seeds satisfy
- total-variation distance <= 0.005;
- max absolute degree-class error <= 0.005.

T61_WEDGE_DENSITY = PASS only if all three seeds satisfy
- absolute empirical-minus-analytic W/N <= 0.02.

The thresholds are finite-size validation tolerances, not physical significance thresholds.

## 8. Prior-art boundary

“Power of choice” in recursive-tree growth is established mathematical literature. T61 does not claim novelty for the generic fact that choosing among several candidate parents changes degree/depth statistics.

The question is narrower: whether the exact already-frozen T25 min-degree-with-cap-and-fallback generator obeys this explicitly derived mean-field degree law.

If it does, the degree redistribution observed in T49 is partly explained as ordinary recursive-tree choice dynamics rather than evidence for a new physical interaction.

## 9. Interpretation stop

A T61 PASS establishes only a generator-level asymptotic law.

It does not imply:
- graph degree = physical load;
- vertex birth = physical time;
- graph tree = spacetime;
- w_infinity = physical density;
- a new force or field.

The degree-independent T47 M3/M7 difference remains a distinct higher-order structural question.
