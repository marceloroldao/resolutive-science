# v0.5 T44 — Held-Out Branch-Core Clustering Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T43. **New dynamics:** none.

## 1. Motivation

T43 rejected local branch-balance entropy B while again replicating M3/M7 residual specificity at N=2048.

The remaining structure may lie in higher-order organization of branching vertices.

H4 degree assortativity measures only edge-level degree correlation. It cannot distinguish:

- isolated branch-branch edges;
- short branchpoint pairs;
- extended connected branchpoint cores.

T44 tests one candidate only: the largest connected branch-core fraction K(T).

## 2. Held-out matrix

Use exactly:

```text
N = 2048
parent seeds = {211,239,269}
```

These parents were not used in T25-T43.

No rescue seed may be added.

## 3. Null construction

For each parent reuse the exact T41 C/A/G-matched null construction unchanged:

- exact labeled degree sequence;
- tree class;
- C/A/G tolerance 0.50 each;
- 500 accepted burn-in;
- 50 accepted moves thinning;
- 99 matched nulls;
- 250000 proposal ceiling;
- parent-edge overlap <=0.90;
- M3/M7 excluded from sampler;
- K excluded from sampler.

## 4. Branch-core candidate

Define the branch-vertex set

```text
V_B(T) = {v : degree(v) >= 3}.
```

Let

```text
T_B = T[V_B]
```

be the subgraph induced by branch vertices.

Because T is a tree, T_B is a forest.

Let

```text
C_max(T_B)
```

be its largest connected component.

Define

```text
K(T)
=
|C_max(T_B)| / |V_B(T)|
```

when |V_B|>0, otherwise K=0.

No alternative degree threshold, weighting, component statistic or normalization may be selected after execution.

## 5. Held-out responses

After each 99-tree matched-null ensemble is frozen, compute:

```text
K(T)
M3
M7
```

for parent and matched nulls.

K, M3 and M7 are forbidden from proposal acceptance.

## 6. Diagnostics

For each parent report:

- K_parent;
- null K mean, sd, q025, median, q975;
- parent percentile;
- Spearman rho(K,M3);
- Spearman rho(K,M7);
- M3/M7 held-out classifications.

## 7. Gates

### T44_MATCH_FEASIBILITY

PASS only if all three held-out parents yield 99 valid T41-matched nulls.

### T44_RESIDUAL_REPLICATION

IDENTIFIED only if both M3 and M7 exceed q975 for all three held-out parents.

### T44_BRANCH_CORE_PARENT_DEPARTURE

Directional hypothesis:

```text
K_parent > q975(K matched null)
```

for all three parents.

### T44_BRANCH_CORE_RESPONSE_ASSOCIATION

IDENTIFIED only if, in all three matched-null ensembles,

```text
rho(K,M3) > 0
rho(K,M7) > 0
```

and

```text
median over parents of min(rho(K,M3),rho(K,M7)) >= 0.50.
```

### T44_BRANCH_CORE_CANDIDATE

IDENTIFIED only if all four preceding gates pass.

Otherwise K is rejected as the missing invariant under this preregistration.

## 8. Interpretation boundary

A passing K would still be only a structural candidate in the current tree model.

It would require a separate matched-null intervention in which K itself is controlled before any claim of accounting for M3/M7.

No physical interpretation is authorized in T44.
