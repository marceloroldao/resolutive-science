# v0.5 T37 — Coordinate-Free Neighborhood Filtration Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T36. **New dynamics:** none.

## 1. Question

Does the scale-dependent relational structure seen in T35-T36 survive when no vector coordinates, Euclidean norm, angle, or profile-space metric is used?

T37 works directly with the graph-distance neighborhood filtration

```text
B_0(v) subseteq B_1(v) subseteq ... subseteq B_R(v),
```

where

```text
B_R(v) = {u : d(v,u) <= R}.
```

Set cardinality, intersection, union and inclusion are invariant under graph relabeling and do not depend on cumulative-ball versus shell coordinates.

## 2. Frozen objects

For every nodule v and radius R define:

### A. Scale-innovation fraction

```text
nu_R(v)
=
|B_2R(v) \ B_R(v)| / |B_2R(v)|
=
1 - |B_R(v)| / |B_2R(v)|.
```

It measures the fraction of the doubled-radius neighborhood that is genuinely new relative to the smaller neighborhood.

### B. Expansion ratio

```text
xi_R(v) = |B_2R(v)| / |B_R(v)|.
```

No power-law or dimensional interpretation is assumed.

### C. Finite-size occupancy

```text
sigma_R(v) = |B_R(v)| / N.
```

This is reported to expose finite-size saturation.

### D. Edge-neighborhood Jaccard contrast

For every existing undirected edge {v,w},

```text
J_R(v,w)
=
|B_R(v) intersect B_R(w)|
/
|B_R(v) union B_R(w)|
```

and

```text
D_R^J(v,w) = 1 - J_R(v,w).
```

This is a coordinate-free set contrast. No claim is made that it is a physical distance.

## 5. Gates

```text

```

for every tested v.

IDENTIFIED_DESCRIPTIVE only if the median `nu_R` is strictly positive for every frozen N and R->2R comparison.

No magnitude threshold is added.
