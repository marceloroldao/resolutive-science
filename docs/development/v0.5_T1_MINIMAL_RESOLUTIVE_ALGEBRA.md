## 1. Purpose

With experimental execution unavailable, the v0.5 line continues only through consequences that follow from the already declared relational structure. T1 asks for the weakest algebra capable of representing Resolutive states, transitions, identities and trajectories without importing energy, time, phase, metric, probability or legacy RSMS structure.

## 2. Base objects

Let

```text
Ob(R) = P_R = S_R / ~
```

be the set/class of Resolutive physical-state candidates established in R1.

For states `A,B in P_R`, let

```text
Hom_R(A,B)
```

denote the admissible Resolutive transitions/trajectory classes from `A` to `B`.

An element is written

```text
Gamma : A -> B.
```

The notation `Hom` is structural and does not imply linear maps.

## 3. Typed partial composition

For

```text
Gamma_1 : A -> B
Gamma_2 : B -> C,
```

define composition

```text
Gamma_2 o Gamma_1 : A -> C.
```

Composition is only defined when the target of the first trajectory equals the source of the second physical-state class.

Therefore the algebra is naturally **typed and partially composable**, rather than a single globally defined binary operation on all trajectories.

## 4. Associativity

R4 and P1 imply segmentation invariance:

```text
Gamma_3 o (Gamma_2 o Gamma_1)
=
(Gamma_3 o Gamma_2) o Gamma_1
```

whenever the compositions are defined.

Status:

```text
T1_ASSOCIATIVITY = DERIVED_FROM_TRAJECTORY_CONCATENATION
```

## 5. Identity

For every state class `A`, R2 supplies

```text
I_A : A -> A
```

such that

```text
Gamma o I_A = Gamma
I_B o Gamma = Gamma
```

for `Gamma : A -> B`.

Status:

```text
T1_IDENTITY = DERIVED
```

## 6. Minimal algebraic classification

Objects + typed arrows + associative partial composition + one identity arrow per object satisfy the axioms of a **small-category-like structure** (subject to ordinary size qualifications).

Therefore the minimal Resolutive algebra is represented as a category

```text
C_R.
```

This is a mathematical classification, not a claim of novel physics.

```text
RESOLUTIVE_CATEGORY = DEFINED_STRUCTURALLY
T1_NOVELTY = CONVENTIONAL_MATHEMATICAL_FOUNDATION
```

## 7. Why a monoid is insufficient globally

P1 found monoid-like behavior for an untyped history object `K_R`. At the full state-transition level, however, trajectories have distinct sources and targets and arbitrary pairs cannot always be composed.

Thus:

```text
GLOBAL_RESOLUTIVE_ALGEBRA = CATEGORY_LIKE
ENDOMORPHISMS_AT_FIXED_STATE = MONOID
```

For each state `A`,

```text
End_R(A) = Hom_R(A,A)
```

forms a monoid under composition, with identity `I_A`.

This is the natural algebraic home of closed Resolutive trajectories.

## 8. Closed trajectories

For

```text
Gamma_loop in End_R(A),
```

composition of loops remains a loop:

```text
Gamma_loop2 o Gamma_loop1 in End_R(A).
```

No inverse is required.

Therefore a closed trajectory may be nontrivial even though its endpoint projection equals that of `I_A`.

The question

```text
Gamma_loop ?= I_A
```

is now an algebraic question inside `End_R(A)`.

## 9. Invertible sector

Define a transition `Gamma : A -> B` as invertible only if there exists

```text
Gamma^-1 : B -> A
```

with

```text
Gamma^-1 o Gamma = I_A
Gamma o Gamma^-1 = I_B.
```

The invertible arrows of `C_R` form its maximal **groupoid sector** (the core of the category).

Status:

```text
INVERTIBILITY = DEFINED_NOT_ASSUMED
RESOLUTIVE_GROUPOID_SECTOR = DERIVED_SUBSTRUCTURE
ALL_TRANSITIONS_INVERTIBLE = NOT_DERIVED
```

## 10. Irreversible sector

Any arrow lacking an inverse remains a valid category arrow.

This allows irreversibility algebraically without interpreting it as thermodynamic irreversibility or a time arrow.

```text
ALGEBRAIC_NONINVERTIBILITY != THERMODYNAMIC_IRREVERSIBILITY
```

## 11. Isomorphism of states

Two state classes `A` and `B` are algebraically isomorphic when an invertible transition exists between them:

```text
A ~= B
```

in the categorical sense.

This does not mean they are the same physical state under R1 equivalence. It means their local transition structures may be related reversibly.

Thus:

```text
PHYSICAL_STATE_EQUALITY != CATEGORICAL_ISOMORPHISM
```

## 12. Resolutive loops and stabilizer-like structure

The invertible elements of `End_R(A)` form a group

```text
Aut_R(A).
```

These are the Resolutive automorphisms of state `A`.

They represent reversible closed transformations of the algebraic state object.

No physical observability of a nonidentity automorphism is asserted.

## 13. Representation principle

Any future physical quantity or readout that respects composition should be represented by a structure-preserving map (functor or appropriate generalized functor) from `C_R` into a target category of measurable objects.

Abstractly:

```text
F : C_R -> C_obs.
```

Then

```text
F(I_A) = I_F(A)
F(Gamma_2 o Gamma_1)
 = F(Gamma_2) o F(Gamma_1).
```

This gives a precise mathematical meaning to the earlier requirement that a physical representation respect identity and composition.

## 14. Null representation

A trivial/endpoint-only theory remains possible. A representation may collapse all path distinctions not encoded in endpoints.

Therefore categorical structure alone still does not establish nontrivial physical history.

```text
T1_NONTRIVIAL_PHYSICAL_HISTORY = NOT_DERIVED
```

The central questions are:

1. What can distinguish a nonidentity loop from identity algebraically?
