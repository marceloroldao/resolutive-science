## Question

Why does frozen D28-A activity terminate before R=8 in all nine runs?

## Competing mechanisms

M1 — DISTANCE_BAND_EMPTY
No nonadjacent pair exists with R < d_G(u,v) <= 2R.

M2 — SIGNATURE_MATCH_ABSENT
Pairs exist in the distance band, but none have equal frozen local signatures.

M3 — STRUCTURAL_AMBIGUITY
Equal-signature candidate pairs exist, but all belong to non-unique structural classes and therefore cannot be selected without forbidden label-based symmetry breaking.

M4 — FINITE_SIZE_SATURATION
The graph diameter/eccentricity is too small relative to R for the requested shell structure to represent a genuine additional scale.

M5 — FEEDBACK_SUPPRESSION
Relations accepted at earlier rounds alter distances/signatures so that a later scale loses activity that would have existed on the unmodified parent graph.

## Required counters at every N/seed/round

Before applying the round:

- V, E;
- exact diameter;
- number of unordered nonadjacent pairs;
- pairs in distance band R < d <= 2R;
- equal-signature pairs globally;
- equal-signature pairs in distance band;
- structural classes among valid candidates;
- unique structural candidate classes;
- unresolved candidate pairs;
- accepted pairs.

## Feedback counterfactual

For each R, evaluate the same frozen candidate rule in two trajectories:

A. **sequential:** graph contains all accepted D28-A relations from previous rounds;
B. **parent counterfactual:** evaluate that R directly on the original frozen T25 tree without applying previous D28-A rounds.

This is diagnostic only. Counterfactual edges are never applied and do not define a new model.

## Classification logic

For a zero-activity sequential round:

- if distance_band_pairs == 0 -> M1 supported;
- else if valid_equal_signature_pairs == 0 -> M2 supported;
- else if unique_structural_candidate_classes == 0 -> M3 supported;
- if diameter <= 2R or most vertices have eccentricity <= 2R -> M4 supported;
- if parent counterfactual has accepted pairs but sequential has none -> M5 supported.

Mechanisms may coexist. Do not force a single cause.
