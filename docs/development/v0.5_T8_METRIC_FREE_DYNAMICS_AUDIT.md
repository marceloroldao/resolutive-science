## 1. Purpose

T7 established that no unique base metric follows from the existing Resolutive ontology. T8 therefore asks whether the connection/curvature sector admits dynamics or invariant constraints before introducing metric magnitude.

The audit distinguishes structural identities, admissible metric-free actions, and uniquely selected physical dynamics.

## 3. Structural identity is not dynamics

The Bianchi identity

```text
D F_R = 0
```

follows geometrically once `F_R` is defined. It is true for every admissible connection and therefore does not select physical histories.

Classification:

```text
BIANCHI = IDENTITY
BIANCHI != EQUATION_OF_MOTION
```

## 4. Route D1 — Flatness constraint

One may postulate

```text
F_R = 0.
```

This is metric-free and gauge/frame covariant. It selects locally flat connections.

But nothing in T1-T7 requires all physical Resolutive connections to be flat. Moreover it would eliminate the local curvature structure that T6 made available except for global/topological holonomy.

Classification:

```text
D1_FLATNESS = VALID_METRIC_FREE_DYNAMICS/CONSTRAINT
D1_FLATNESS = NOT_DERIVED
```

## 5. Route D2 — Holonomy-based dynamics

For a closed represented path `Gamma`, define

```text
U_Gamma = P exp integral_Gamma A_R.
```

Under a local frame change, closed-loop holonomy transforms by conjugation at the base point. Consequently conjugacy-invariant functions of `U_Gamma` can define frame-invariant loop observables when a suitable representation/function is chosen.

This directly connects T2 closed trajectories to T6 transport.

However a law assigning preferred holonomies, weights, or an extremization principle is additional structure.

Classification:

```text
D2_HOLONOMY_OBSERVABLES = AVAILABLE
D2_HOLONOMY_DYNAMICS = NOT_SELECTED
```

## 6. Route D3 — BF-type action

On a represented base of appropriate dimension, introduce an auxiliary Lie-algebra-dual-valued form `B_R` of complementary degree and an invariant pairing `<.,.>`.

A metric-free action can then be written schematically as

```text
S_BF = integral_X <B_R wedge F_R>.
```

Variation with respect to `B_R` gives a flatness-type equation; variation with respect to `A_R` gives a covariant constancy equation for `B_R`, subject to boundary conditions and conventions.

New assumptions:

```text
base dimension/orientation
auxiliary B_R field
invariant pairing
integration structure
variational principle
boundary conditions
```

Therefore:

```text
D3_BF = MATHEMATICALLY NATURAL
D3_BF = NOT_DERIVED_FROM_C_R
```

They generally classify topology rather than provide ordinary local propagating dynamics by themselves.

## 11. Holonomy as the natural bridge to global history

For a closed path based at `x_0`,

```text
Hol_Gamma(A_R) = P exp integral_Gamma A_R.
```

The endpoint in the represented base can return to `x_0` while internal transport need not return to identity:

```text

but
Hol_Gamma(A_R) != I.
```

This is the cleanest mathematical realization so far of the v0.5 distinction between endpoint equality and nontrivial trajectory structure.

It does **not** prove that nature contains such an observable Resolutive memory. It shows that the ontology admits a standard, coherent representation of that possibility.
