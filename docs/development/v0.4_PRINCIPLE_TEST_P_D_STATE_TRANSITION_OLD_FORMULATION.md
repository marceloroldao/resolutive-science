## 1. What the existing RSMS already supplies

The current RSMS admits a generic dynamical law

```text
D[Phi;g,J,lambda] = 0
```

or an explicitly declared transition law.

When state propagation is defined it may be represented by

```text
U(tau_2,tau_1): I_(tau_1) -> I_(tau_2).
```

The RSMS explicitly does not infer composition, invertibility, linearity, unitarity or a universal physical interpretation of the evolution parameter unless separately declared.

Therefore the old formulation already has a state-transition *framework*.

## 2. Does existence of U determine U?

No.

For the same state space R, one may construct infinitely many inequivalent evolution maps, including:

- local differential flows;
- Hamiltonian flows;
- gradient-like flows;
- constrained flows;
- dissipative maps;
- stochastic kernels;
- discrete recurrences;
- nonlocal integral evolution.

The state tuple alone does not select one of these.

## 3. Does composition select the law?

Even if one additionally imposes

```text
U(t3,t2) o U(t2,t1) = U(t3,t1),
```

many semigroups and groups of evolution remain possible. Composition constrains consistency but does not uniquely identify a physical generator.

## 4. Does reversibility select the law?

No.

Invertibility would exclude dissipative/noninvertible classes but still leaves infinitely many reversible flows. Reversibility therefore cannot by itself close the Master Equation.

## 5. Does determinism select the law?

No.

Determinism reduces stochastic freedom but still leaves arbitrary deterministic vector fields/generators on the admissible state space.

## 6. Conventional-equivalence audit

A generic state-transition law on a four-component state space is standard dynamical-systems machinery. Without an independently derived generator, constraint, metric, symplectic form, connection or constitutive rule, it carries no distinct Resolutive content.

Thus

```text

```
