# v0.4 Minimal Layer-State Candidate

**Status:** CONJECTURAL/POSTULATED CANDIDATE — FOLLOW-UP TO ISSUE #85

## Purpose

Translate the project intuition of same-layer `2pi` evolution and inter-layer `4pi` closure into the smallest explicit state-space model, then determine what is genuinely new and what remains a reparametrization.

This document does not claim that the layer degree of freedom exists in nature.

## 1. Minimal state space

Let

```text
rho > 0,
phi in R/(2pi Z),
ell in Z2 = {0,1}.
```

The candidate phase/layer state space is

```text
S = R_+ x S^1 x Z2.
```

The complex amplitude may still be represented conventionally as

```text
Psi = sqrt(rho) exp(i phi).
```

The layer variable `ell` is declared independent of `Psi`.

Classification:

- `rho`: P candidate primitive;
- `phi`: P candidate phase coordinate;
- `ell`: P new independent layer postulate.

## 2. Horizontal operator

Define horizontal phase evolution inside one layer by

```text
H(alpha): (rho, phi, ell) -> (rho, phi + alpha mod 2pi, ell).
```

Then

```text
H(2pi) = identity.
```

This is ordinary `U(1)` phase closure and contains no new physics by itself.

## 3. Inter-layer operator

Define a candidate layer-transfer operation

```text
V(alpha): (rho, phi, ell) -> (rho, phi + alpha/2 mod 2pi, ell xor sigma(alpha)),
```

where the smallest discrete half-cycle rule is fixed operationally at `alpha = 2pi`:

```text
V_2pi(rho, phi, ell)
  = (rho, phi + pi mod 2pi, ell xor 1).
```

Applying it twice gives

```text
V_2pi^2(rho, phi, ell)
  = (rho, phi, ell).
```

Thus the *full* state requires two half-cycle operations to return to its initial point.

If we use the bookkeeping coordinate `Theta = 2 phi`, the same path can be described as closure after `Theta` advances by `4pi`.

## 4. Important equivalence result

This construction is not evidence that `4pi` is fundamental by itself. Mathematically it is an ordinary phase degree of freedom plus an independent binary state:

```text
S = S^1 x Z2
```

(up to the positive density factor).

The genuinely new ingredient, compared with an ordinary complex scalar, is **not the doubled angular coordinate**. It is the postulated physical layer variable `ell` and its transition law.

Therefore:

```text
4pi coordinate novelty: NO
independent layer-state novelty: POSSIBLE, IF PHYSICAL
```

## 5. Gauge-redundancy test

The candidate fails as new physics if the transformation

```text
(phi, ell) ~ (phi + pi, ell xor 1)
```

is merely a gauge identification and every admissible observable is invariant under it.

In that case `V_2pi` maps a state to an equivalent description of the same physical state and the extra `Z2` label is redundant.

For `ell` to be physical, at least one admissible observable must distinguish the two representatives after controlling for ordinary phase:

```text
O(phi, ell) != O(phi + pi, ell xor 1)
```

for some physically realizable state/reference configuration.

## 6. Minimal observable family

Introduce a layer-sensitive scalar observable only as a preregistration template:

```text
Q = q0(rho, phi) + lambda_L * L(ell),
L(ell) = (-1)^ell.
```

Then a single layer transition changes the layer contribution:

```text
L(ell xor 1) = -L(ell),
```

and two transitions restore it.

However `lambda_L` must not be fitted after observing a target anomaly. A future physical model must derive or freeze the coupling mechanism before target-data inspection.

Classification: C/F template, not an accepted observable.

## 7. Strong falsification rule

A physical layer model must beat the following null description under symmetric complexity accounting:

```text
Baseline B0: ordinary U(1) phase model.
Candidate B1: U(1) phase + physical Z2 layer state + frozen transition law.
```

Before data are inspected, specify:

- how `ell` is prepared or inferred;
- what operation triggers `ell -> ell xor 1`;
- which observable reads `ell`;
- all coupling parameters and allowed ranges;
- a held-out sequence containing one and two transitions.

Required pattern:

```text
initial state      -> Q0
one V_2pi event    -> Q1 != Q0
two V_2pi events   -> Q2 = Q0 (within preregistered tolerance)
```

and B0 must fail to reproduce the pattern under equal freedom without introducing an equivalent hidden binary degree of freedom.

## 8. Relation to the project intuition

The original language can now be translated precisely:

- **horizontal `2pi`**: evolution under `H`, which remains inside one `ell` sector and closes on `S^1`;
- **vertical `4pi`**: a two-step path involving a physical layer flip under `V_2pi`, with restoration only after the second transition.

This is a mathematically coherent candidate interpretation. It is not yet derived from the existing Master Equation and therefore remains a postulate.
