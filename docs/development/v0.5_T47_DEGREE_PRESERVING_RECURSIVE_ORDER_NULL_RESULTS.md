## 6. Main inference

Previous tests established:

- ordinary degree-matched trees produce M3/M7 below T25;
- C/A/G-matched trees also produce M3/M7 below T25;
- C/A/G/P_B-matched trees still produce M3/M7 below T25.

T47 now establishes a complementary fact:

- degree-matched **recursive-order** trees produce M3/M7 above T25.

Therefore the T25 values occupy an intermediate structural regime:

```text
ordinary matched trees
        < T25
        < generic degree-matched recursive-order trees
```

for the relevant high-radius responses, descriptively.

This strongly suggests that two ingredients act in opposite directions:

1. recursive ancestry increases high-radius innovation/contrast;
2. the T25 parent-selection rule suppresses/regulates that increase.

## 7. Generator mechanism

The T25 attachment rule is:

1. vertex v samples up to five older vertices;
2. candidates are ordered by current degree, with random tie-breaking;
3. v attaches to the first candidate below max degree;
4. fallback is used only if required.

Thus the rule is a bounded **low-degree choice / load-balancing mechanism** operating inside a recursive causal tree.

T47 shows that removing this selection mechanism while preserving final degree quotas and recursive ancestry causes M3/M7 to rise substantially.

This makes the selection mechanism itself the next target.
