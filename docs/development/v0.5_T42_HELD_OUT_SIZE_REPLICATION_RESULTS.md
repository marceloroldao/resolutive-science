## 9. Consequence

The replicated residual now justifies a new invariant search, but that search should be derived from tree structure rather than from a broad metric sweep.

For a tree, every edge e is a separator: removing e splits the graph into components of sizes s_e and N-s_e.

The distribution

```text
Sigma(T) = { min(s_e,N-s_e)/N : e in E }
```

is coordinate-free, degree-sequence-sensitive only through higher-order arrangement, and directly encodes how branch mass is distributed across the tree.

This edge-separator spectrum is a natural next candidate because high-radius neighborhood growth and overlap are governed by how much relational mass lies behind successive cut edges.

A new protocol must be frozen before evaluating this candidate on a new held-out matrix.
