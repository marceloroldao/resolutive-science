# v0.4 Lifted-Orientation Audit

**Status:** WORKING RESULT — FOLLOW-UP TO ISSUE #85

## Question

Can the proposed physical `4pi` structure be derived from the current Resolutive candidate primitives by lifting ordinary orientation to a double cover, rather than importing a spinorial structure solely because it has `4pi` closure?

Current candidate content includes, at most,

```text
rho > 0,
phi in U(1),
chi in R,
n in S^2.
```

The test is whether these variables force or physically resolve a nontrivial lift of rotations.

## 1. Canonical rotational double cover

The standard mathematical double cover is

```text
p : SU(2) -> SO(3),
```

with

```text
p(U) = p(-U).
```

Equivalently, a rigid orientation may be represented by a unit quaternion `q in S^3`, with

```text
R(q) = R(-q).
```

A `2pi` rotation corresponds to a path in the lifted space from `q` to `-q`; continuing to `4pi` returns to `q`.

This is genuine double-cover topology.

Classification: **D — known mathematical property of the lifted rotational space**.

## 2. Does `n in S^2` require this lift?

No.

A direction vector transforms under ordinary rotations:

```text
n -> R n,
R in SO(3).
```

If `R = p(U)`, then both `U` and `-U` produce exactly the same transformed vector:

```text
p(U)n = p(-U)n.
```

Therefore the current orientation primitive `n in S^2` factors through `SO(3)` and cannot distinguish the two points of the `SU(2)` fiber.

Result:

```text
CURRENT_VECTOR_ORIENTATION_SEES_CENTER_SIGN = NO
```

Classification: **D — the lift is invisible to vector orientation**.

## 3. Spinor representation of `S^2` does not derive a physical lift

A unit vector can also be represented using a normalized two-component complex object `z in C^2`, for example through a Hopf/Bloch-type map

```text
n = z^dagger sigma z,
||z|| = 1.
```

But

```text
z -> exp(i alpha) z
```

leaves `n` unchanged. In particular,

```text
z -> -z
```

is only the special case `alpha = pi` of this full `U(1)` redundancy.

Thus reconstructing `n` through a spinorial coordinate does not make the sign physical; it enlarges the representation and introduces gauge redundancy.

Classification: **D — spinorial parametrization of `S^2` does not by itself establish physical `4pi`**.

## 4. Quaternion representation of `SO(3)` does not derive a physical lift

Likewise, if a full orientation is encoded by a unit quaternion,

```text
q in S^3,
R = R(q),
```

then `q` and `-q` are two coordinates for the same ordinary rotation unless the physical theory contains a degree of freedom that transforms nontrivially under the center.

If every observable depends only on `R(q)`, then

```text
O(q) = O(-q),
```

and the two sheets are physically indistinguishable.

Classification: **D — double-cover coordinate exists; physical sheet label not established**.

## 5. What would make the lift physical?

A genuine physical distinction requires at least one state or observable carrying a representation that does not factor through `SO(3)`.

Operationally, there must exist a variable `X` such that

```text
X[U] != X[-U]
```

or an interference/transport experiment sensitive to the lifted path rather than only to the projected spatial orientation.

This is not supplied by the current scalar fields, ordinary phase, or vector `n`.

Adding such an `X` would be a new primitive or independently motivated structure. It cannot be inferred solely from the desired `4pi` behavior.

## 6. Relation to the horizontal/vertical proposal

The project proposal can be represented mathematically by a lifted path:

```text
initial lift q
2pi projected rotation -> -q
4pi projected rotation -> q.
```

But for this to describe Resolutive physics, the sign of `q` must correspond to an independently physical state.

With the currently declared primitives,

```text
q ~ -q
```

at the level of all presently defined orientation observables.

Therefore the projected/lifted distinction is not yet a derived horizontal/vertical layer distinction.

## 7. Strong no-import rule

The project must not infer

```text
Resolutive state requires SU(2)
```

from the fact that `SU(2)` has the desired `4pi` closure.

That would reverse the derivation order.

A valid derivation must instead begin from independently required primitives or transformation laws and then show that their state space is necessarily a double cover (or equivalent nontrivial bundle).
