# v0.5 Q1 — Resolutive Valuation

**Line:** v0.5 relational ontology  
**Depends on:** R1-R5  
**Status:** QUANTITATIVE EXTENSION AUDIT  
**Target-data fitting:** NONE

## 1. Purpose

R5 showed that relational structure alone does not force a unique numerical magnitude. Q1 therefore tests the weakest quantitative extension: a valuation on Resolutive transitions or trajectories.

Let

```text
V_R : Gamma_R -> K
```

where `Gamma_R` is the admissible Resolutive trajectory structure and `K` is an as-yet unspecified value space.

No identification with energy, time, action, phase, distance, probability or coherence is allowed in Q1.

## 2. Q1-A — Identity normalization

Candidate axiom:

```text
V_R(I_[R]) = 0.
```

If `V_R` is intended to measure accumulated change relative to composition, assigning the neutral transition a neutral value is structurally motivated.

However, the symbol `0` requires an additive identity in `K`. Therefore Q1-A is conditional on choosing an additive codomain.

Result:

```text
Q1_A_IDENTITY_ZERO = CONDITIONALLY_DERIVED
```

It is not a statement that an unchanged state has zero physical energy or zero elapsed time.

## 3. Q1-B — Additivity under composition

Candidate axiom:

```text
V_R(Gamma_2 o Gamma_1)
 = V_R(Gamma_1) + V_R(Gamma_2).
```

This is useful if the valuation represents an accumulated extensive quantity. But R1-R5 do not require physical quantities to accumulate additively. Multiplicative, max/min, ordered, matrix-valued, phase-valued and nonlinear composition laws are also possible.

Therefore:

```text
Q1_B_ADDITIVITY = POSTULATE_CANDIDATE
```

not a derivation.

## 4. Q1-C — Reversal antisymmetry

Candidate axiom:

```text
V_R(Gamma_rev) = -V_R(Gamma).
```

This requires more than orientation. It requires a well-defined reversal operation and an additive inverse in `K`; if reversal is to be an algebraic inverse, invertibility must also be established.

R3 explicitly showed that reverse orientation is not automatically inverse transition.

Therefore:

```text
Q1_C_REVERSAL_ANTISYMMETRY = NOT_DERIVED
```

## 5. Q1-D — Positivity

Candidate axiom:

```text
V_R(Gamma) >= 0.
```

Positivity requires an ordered codomain. Nothing in R1-R5 selects an order or requires a cost/length interpretation.

Moreover, positivity conflicts with strict reversal antisymmetry for nonzero reversible paths if both directions are admissible in the same scalar codomain.

Therefore:

```text
Q1_D_POSITIVITY = NOT_DERIVED
```

## 6. Mutual compatibility audit

The candidate axioms cannot be bundled without consequences.

If additivity, inverse reversal and identity-zero all hold, then

```text
0 = V_R(I)
  = V_R(Gamma^-1 o Gamma)
  = V_R(Gamma) + V_R(Gamma^-1),
```

so

```text
V_R(Gamma^-1) = -V_R(Gamma).
```

Thus antisymmetry is derivable **only after** the stronger assumptions of additivity plus true invertibility are accepted.

If positivity is also imposed for both `Gamma` and `Gamma^-1`, then

```text
V_R(Gamma) >= 0
V_R(Gamma^-1) = -V_R(Gamma) >= 0
```

forces

```text
V_R(Gamma) = 0
```

for every invertible trajectory.

Therefore a nontrivial positive valuation and an antisymmetric signed valuation are different model classes.

## 7. Minimal quantitative classes

Q1 exposes at least three inequivalent possibilities:

### Class S — signed additive valuation

```text
K = additive group
V(I)=0
V(G2 o G1)=V(G1)+V(G2)
V(G^-1)=-V(G)
```

Potential interpretation class: oriented accumulated quantity. No physical identity assigned.

### Class P — positive path valuation

```text
K = ordered nonnegative monoid
V(I)=0
V(G)>=0
```

Composition may be additive or subadditive, but reversal need not change sign.

Potential interpretation class: cost/length-like quantity. No physical identity assigned.

### Class G — general compositional valuation

```text
V(G2 o G1)=F(V(G1),V(G2))
```

for some composition law `F`.

This is maximally general but highly underdetermined.

## 8. Can Q1 select one class?

No.

The current ontology provides no independent reason to choose signed-additive, positive, multiplicative, or another compositional class.

Hence:

```text
QUANTITATIVE_EXTENSION_UNDERDETERMINED = TRUE
```

No unique Resolutive Valuation has been derived.

## 9. Important consequence for energy

The project must not define energy merely by selecting the convenient class after seeing known energy properties.

Doing so would reproduce the target concept by construction rather than derive it.

Therefore:

```text
RESOLUTIVE_ENERGY_STATUS = NOT_YET_DERIVED
```

## 10. What has nevertheless been learned

Q1 establishes a useful fork:

```text
oriented signed accumulation
        !=
positive path magnitude.
```

A future physical principle must decide which kind of quantity is fundamental, or explain why both arise from a deeper object.

This is a sharper problem than simply asking for a scalar `F(R_A,R_B)`.

## 11. Next gate — Q2

The next test should ask whether **comparison of two trajectories with the same endpoints** can supply the missing selector without importing a metric or known energy law.

For

```text
pi_end(Gamma_1) = pi_end(Gamma_2),
```

ask whether the ontology can define a primitive **Resolutive Contrast**

```text
Delta_R(Gamma_1,Gamma_2)
```

whose role is only comparative at first.

This follows the relational premise more faithfully than assigning an absolute number to one isolated trajectory.

Q2 must determine whether contrast can be defined as an order/equivalence relation before any numerical scale is introduced.
