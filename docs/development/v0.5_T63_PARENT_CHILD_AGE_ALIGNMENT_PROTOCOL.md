# v0.5 T63 — Parent–Child Age-Alignment Null Test

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T62.  
**Purpose:** test one preregistered birth-order pairing statistic under exact-degree recursive-order nulls, without inspecting M3/M7.

## 1. Hypothesis

T62 derives the parent-age ratio

R_v = (p(v)+1)/(v+1),

where p(v)<v is the recursive parent of vertex v.

The frozen statistic is

A_1 = (1/(N-1)) sum_{v=1}^{N-1} R_v.

T62 predicts that the T25 mechanism strongly favors relatively recent parents, with asymptotic E[R] approximately 0.72349.

T47 preserves the exact multiset of parent labels through fixed child quotas but randomizes which admissible child receives which parent label.

Therefore A_1 is a pure parent-child pairing statistic under the T47 null.

No other age moment is a T63 primary endpoint.

## 2. Direction frozen before the run

Because T62 analytically derives a bias toward relatively recent parents, T63 freezes the directional prediction

A_1(T25 parent) > A_1(recursive quota-preserving null).

The direction will not be reversed after observing the held-out null ensembles.

## 3. Parent and null construction

For each held-out T25 parent:

- exact T25 generator;
- N=4096;
- sample_size=5;
- max_degree=6;
- exact recursive parent p(v)<v.

Nulls preserve exactly:

1. every vertex's final degree;
2. equivalently every vertex's child quota;
3. the complete multiset of parent labels;
4. recursive order p(v)<v;
5. connected rooted-tree class.

The null move is the T47 two-child parent swap.

For children a,b with current parents x=p(a), y=p(b), propose

p(a)=y,
p(b)=x

only when

y<a and x<b.

Moves with x=y are rejected.

This exactly preserves child quotas and final labeled degree sequence.

## 4. Held-out matrix

Frozen before execution:

N = 4096

T25 parent seeds:
{1031, 1063, 1097}

For each parent generate 999 stored recursive-order null states.

Null RNG seed:

17000023*N + 17011*parent_seed.

## 5. Null-chain policy

- proposal ceiling: 5,000,000;
- burn-in: 5,000 accepted swaps;
- thinning: 500 accepted swaps between stored states;
- target stored states: 999.

A stored state is accepted only if its edge overlap with the original T25 parent is <=0.25.

Duplicate parent assignments are forbidden.

No statistic involving M3 or M7 is computed or used during T63.

## 6. Primary statistic

For any parent assignment p define

A1(p)
=
mean_{v=1,...,N-1} [(p(v)+1)/(v+1)].

Also compute, as an exact control only,

L(p)
=
mean_{v=1,...,N-1} [-ln((p(v)+1)/(v+1))].

By T62, L must be invariant under every child-quota-preserving parent permutation up to floating-point summation.

L is not an explanatory candidate and is not part of the discovery gate.

## 7. Frozen gates

### Structural feasibility

PASS if all three parent ensembles produce exactly 999 stored nulls and preserve:
- exact child quotas;
- recursive p(v)<v;
- tree edge count N-1;
- maximum parent-edge overlap <=0.25.

### Exact invariant control

For every stored null,

|L_null - L_parent| <= 1e-12.

### Age-alignment identification

For each seed compute the empirical null quantiles q0.005 and q0.995.

T63_AGE_ALIGNMENT = IDENTIFIED only if

A1_parent > q0.995

for all three held-out parents.

If one or more parents fail this directional gate, the candidate is not identified.

No rescue seeds and no replacement statistic.

## 8. Secondary descriptive outputs

Report only:
- parent A1;
- null mean, sd, q0.005, median, q0.995;
- standardized parent-minus-null difference as descriptive effect size;
- parent-edge overlap summary;
- parent/null L invariant residual.

No M3, M7, topology feature scan, regression or multivariate selection is authorized.

## 9. Interpretation

A PASS would establish that the T25 choice process imprints a reproducible age-alignment pairing that is not fixed by:
- final labeled degree sequence;
- child quotas;
- recursive parent order;
- marginal parent-label multiset.

It would not yet show that A1 explains the T47 M3/M7 residual.

The next authorized test after a PASS is a direct A1-matched recursive-order intervention with M3/M7 held out until matching is frozen.

## 10. Physical stop

Birth labels are causal-order labels of this graph construction, not physical time.

A1 is dimensionless and has no established physical interpretation.
