# v0.5 T27 — Structural Result Before Numerical Dimension Fit

**Protocol:** frozen D27-A one-round common-neighbor closure.
**Parent:** T25 tree.

## Exact structural derivation

Let T=(V,E) be any tree. D27-A adds an edge between every nonadjacent pair u,v having at least one common neighbor.

In a tree, two distinct nonadjacent vertices have a common neighbor iff their graph distance is exactly 2. Therefore D27-A produces exactly the graph square restricted to distances <=2:

G_27 = T^2.

Equivalently:

E_27 = {{u,v}: d_T(u,v) <= 2}.

This conclusion is independent of node labels, Euclidean coordinates and any target dimension.

## Number of closure edges

Every length-2 path u-w-v in a tree has a unique middle vertex w. Because a tree has no triangles, each unordered pair at distance 2 is generated by exactly one such wedge.

Hence the number of new closure edges is exactly

Delta E = sum_{w in V} C(deg_T(w),2).

Since T is connected and has E_T=V-1,

beta_1(G_27)
 = E_27 - V + 1
 = Delta E
 = sum_w C(deg_T(w),2).

Thus any parent tree containing a vertex of degree >=2 acquires nonzero cycle rank after one closure round.

T27_CYCLIC_GEOMETRY = IDENTIFIED structurally for every nontrivial branching/path tree with |V|>=3.

## Triangle structure

For every parent-tree wedge u-w-v, D27-A adds u-v, creating triangle (u,w,v).

Therefore at least Delta E triangles are created. Additional triangles can occur among several neighbors of the same parent vertex because all of them become mutually adjacent under closure.

Indeed, for a parent vertex w of degree k, the closed neighborhood {w} union N_T(w) becomes a clique K_(k+1) in G_27.

This is a strong local-geometric consequence of the frozen rule.

## Distance consequence

For all u,v,

d_G27(u,v) = ceil(d_T(u,v)/2).

Reason: each G27 edge traverses at most two parent-tree edges, and the unique tree path can be partitioned into segments of length <=2.

Therefore

diam(G_27) = ceil(diam(T)/2).

## Crucial dimensional consequence

Squaring a graph in this bounded-radius way changes local connectivity and creates cycles, but it does not automatically change large-scale growth class.

Because

B_T(r) subseteq B_G27(r) subseteq B_T(2r),

polynomial growth exponents, when they exist asymptotically, are preserved under this bounded-distance transformation (up to constants/scaling of radius).

Therefore D27-A can create abundant local cycles and clustering while still failing to generate a new large-scale dimension.

This is an important negative/limiting result obtained before numerical dimension fitting.

## Interpretation

D27-A separates two notions that must not be conflated:

LOCAL CYCLIC GEOMETRY != NEW LARGE-SCALE DIMENSION.

It demonstrates that cycle creation alone is insufficient to explain emergence of spatial dimensionality.

No curvature, physical area, physical metric or physical dimension is inferred.

## Consequence for next design

Do not retune the closure threshold to force a dimensional exponent.

A future candidate that genuinely changes large-scale geometry must alter the scaling organization itself, not merely add bounded-distance shortcuts to a fixed parent tree. Such a candidate must be preregistered from an independent relational/dynamical principle.
