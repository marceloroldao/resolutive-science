## 3. Log-age pure-birth process

Consider a vertex born when the graph size is i and observed when the graph size is n.

Define logarithmic age

tau = ln(n/i).

In the asymptotic mean-field limit its degree state follows the sequential pure-birth system

dP_1/dtau = -a_1 P_1,

dP_k/dtau = a_{k-1}P_{k-1} - a_k P_k,
for 2<=k<=K-1,

dP_K/dtau = a_{K-1}P_{K-1},

with initial condition P_1(0)=1 and P_k(0)=0 for k>1.

This system follows from the 1/n class-selection hazard and uses no graph-distance observable.

## 5. Closed moment law

For r>=0 define

M_r = E[R^r].

The Laplace transform of the sequential pure-birth process gives

M_r
=
sum_{k=1}^{K-1}
[
 a_k * product_{j=1}^{k-1} a_j
 /
 product_{j=1}^{k} (r+1+a_j)

The empty product is one.

M_0 must equal one.

The logarithmic parent-age moment is

L = E[-ln R] = - dM_r/dr evaluated at r=0.

For each kth summand T_k(r),

-dT_k/dr
=
T_k(r) * sum_{j=1}^{k} 1/(r+1+a_j),

so L is evaluated without numerical differencing.
