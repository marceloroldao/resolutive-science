# v0.5 T79 — Expanded-Pool Entropy-Balancing Validation Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T78.  
**Purpose:** test whether the sole T78 degeneracy failure is cured by increasing independent candidate-state diversity while leaving the matching variables, graph-state generator, entropy-balancing method and all T78 weight-quality thresholds unchanged.

## 1. Parent matrix retained

Use the same exact T25 parents as T77/T78:

N = 4096  
seeds = {1847, 1871, 1901}.

M3 and M7 remain forbidden.

No parent is replaced after the T78 difficulty at seed 1901.

## 2. Stage A and hard controls unchanged

For each parent regenerate Stage A exactly as T77/T78:

- 99 ordinary T47 recursive-order nulls;
- burn-in = 2000 accepted swaps;
- thinning = 200;
- proposal ceiling = 10,000,000;
- overlap <= 0.90.

Define the same four hard-box half-widths:

Delta_Q = 0.25 * population_sd_StageA(Q),

for Q in {A1,A2,A3,C_KR}.

## 3. T77 corrected candidate-state mechanism unchanged

Compute the exact local normalized 4D law and

lambda_y = 2 * pinv(Sigma_y) * mu_y

with rcond = 1e-12, exactly as T77.

Each candidate chain uses the unchanged T77 full-4D corrected MH kernel:

- starts from the exact T25 parent;
- hard A1/A2/A3/C_KR box unchanged;
- burn-in = 2000 accepted MH state changes;
- thinning = 200 accepted MH state changes;
- stores 11 states;
- proposal ceiling = 3,000,000;
- stored-state overlap <= 0.90.

## 4. Expanded independent candidate pool

Instead of 9 chains, run exactly:

27 independent chains * 11 states = 297 candidate states per parent.

Chain indices are 0,...,26 under the unchanged T77 RNG formula.

Thus chains 0,...,8 exactly reproduce the original T77 candidates and chains 9,...,26 add independent candidate support.

Duplicates are forbidden across the complete 297-state pool.

No within-chain target is increased.

## 5. Candidate-support gate

Require:

- exactly 297 unique candidates;
- all candidates inside the four frozen hard bands;
- parent bracketed by candidate min/max in all four controls.

If this fails for any parent, stop.

## 6. Maximum-entropy calibration unchanged

For each candidate j define normalized control vector

y_j =
(
(A1_j-A1_parent)/Delta_A1,
(A2_j-A2_parent)/Delta_A2,
(A3_j-A3_parent)/Delta_A3,
(C_j-C_parent)/Delta_C
).

Use exactly the T78 exponential tilting:

w_j(theta)
=
exp(theta dot y_j) / sum_l exp(theta dot y_l),

solving

sum_j w_j y_j = 0

with the unchanged deterministic Newton procedure:

- weighted covariance Hessian;
- pseudoinverse rcond = 1e-12;
- backtracking step sizes 1, 1/2, 1/4, ...;
- at most 100 iterations;
- convergence tolerance max_abs(weighted_mean_y) <= 1e-10;
- no regularization, clipping or coordinate deletion.

## 7. Weight-quality gates unchanged from T78

The following thresholds are **not relaxed** despite the larger pool:

- convergence <= 1e-10;
- ESS >= 50;
- maximum single-state weight <= 0.05;
- all 297 weights strictly positive.

T79_EXPANDED_BALANCING_VALIDATED = PASS only if all gates pass for all three parents.

## 8. Descriptive outputs

Report additionally, without changing the gate:

- ESS / 297;
- maximum weight relative to uniform weight 1/297;
- number of states carrying cumulative 50%, 80% and 95% total weight.

These are descriptive only.

## 9. Held-out boundary

M3 and M7 are forbidden in T79.

If T79 passes, the next protocol may evaluate weighted M3/M7 using the exact deterministic 297 graph states and exact control-only weights, without changing any state or weight.

## 10. Interpretation

A PASS would show that the T78 seed-1901 degeneracy was a finite candidate-pool diversity limitation rather than a failure of exact entropy balancing.

It would produce a nondegenerate, exactly control-mean-matched larger-N null measure suitable for a final held-out M3/M7 accounting test.
