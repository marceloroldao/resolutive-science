# v0.5 Q4 — Minimal Selector for Nontrivial Resolutive History

**Line:** v0.5 relational ontology  
**Depends on:** R1-R5, Q1-Q3  
**Status:** PHYSICAL/OPERATIONAL SELECTOR AUDIT  
**Target-data fitting:** NONE

## 1. Purpose

Q3 defined Resolutive Path Dependence and Resolutive History Residue structurally, but did not derive a nontrivial trajectory-sensitive physical distinction. Q4 asks for the weakest independently motivated selector capable of separating at least one pair of same-endpoint trajectories.

The null comparator is explicit:

```text
H0_ENDPOINT_ONLY:
pi_end(Gamma_1)=pi_end(Gamma_2)
=>
Gamma_1 ~_C Gamma_2.
```

Any nontrivial-history candidate must add information beyond this null model and state exactly how that information could be operationally accessed.

## 2. Candidate S1 — Local transition readout

Introduce a readout on elementary transitions:

```text
L : T -> X_L.
```

A trajectory may then carry the ordered sequence

```text
(L(T_01), L(T_12), ..., L(T_(n-1)n)).
```

This can distinguish two same-endpoint trajectories if at least one local transition readout differs.

However, the current ontology does not select:

- what `L` measures;
- the outcome space `X_L`;
- whether elementary transitions are physically observable;
- how local readouts compose.

Result:

```text
S1_LOCAL_READOUT = SUFFICIENT_IF_POSTULATED
S1_SELECTED_BY_CURRENT_ONTOLOGY = NO
```

## 3. Candidate S2 — Composition-sensitive readout

Introduce a readout that depends on ordered composition:

```text
C : Gamma -> X_C
```

with the possibility that

```text
C(Gamma_2 o Gamma_1)
```

is not reducible to endpoint readouts.

This directly permits nontrivial history, but without an independently fixed composition law it simply renames the desired path dependence.

Result:

```text
S2_COMPOSITION_READOUT = SUFFICIENT_IF_POSTULATED
S2_SELECTED_BY_CURRENT_ONTOLOGY = NO
S2_RISK = CIRCULAR_IF_DEFINED_ONLY_TO_DETECT_HISTORY
```

## 4. Candidate S3 — Loop-sensitive readout

Use the sharp Q3 comparator:

```text
Gamma_loop : [R] -> [R]
I_[R]      : [R] -> [R].
```

Introduce

```text
L_loop(Gamma_loop)
```

and require that at least one admissible loop satisfy

```text
L_loop(Gamma_loop) != L_loop(I_[R]).
```

This is a clean operational discriminator for history beyond endpoints.

But the ontology does not determine what loop-sensitive structure is read: winding, holonomy, accumulated phase, action, count, orientation class, or another object all require additional assumptions.

Result:

```text
S3_LOOP_READOUT = SHARP_DISCRIMINATOR_IF_POSTULATED
S3_SELECTED_BY_CURRENT_ONTOLOGY = NO
```

## 5. Candidate S4 — Endpoint-only null comparator

No trajectory-sensitive readout is admitted:

```text
O_Gamma(Gamma) = F(pi_end(Gamma)).
```

Then all same-endpoint trajectories are physically equivalent.

This model requires no additional path-sensitive physical structure and is therefore the minimal null comparator.

Result:

```text
S4_ENDPOINT_ONLY = MINIMAL_NULL
```

## 6. Selection audit

The current v0.5 structure cannot choose S1, S2 or S3 over S4 without a new physical/operational postulate.

Importantly, the mere ontological existence of a Resolutive Trajectory is not evidence that nature contains a trajectory-sensitive observable.

Therefore:

```text
NONTRIVIAL_HISTORY_SELECTOR_UNDERDETERMINED = TRUE
```

## 7. What would count as a legitimate new postulate?

A candidate postulate must not say merely:

```text
history matters.
```

That would assert the conclusion.

It must instead specify an independently meaningful operation or symmetry from which trajectory sensitivity follows. Examples of admissible *forms of question*, not accepted postulates, are:

1. Does concatenation preserve a measurable relational composition object?
2. Does reversal transform an operational readout in a fixed way?
3. Does a closed sequence produce a readout distinguishable from identity under a specified measurement protocol?
4. Is there a minimal finite experiment in which endpoint-equivalent preparations yield distinguishable outcomes conditioned only on path construction?

The postulate must have a null comparator and a failure condition.

## 8. First falsifiable architecture

Q4 nevertheless yields the first generic experimental architecture of v0.5:

```text
Prepare same physical initial class [R_A]
        |
        +--> protocol/path P1 --> [R_B]
        |
        +--> protocol/path P2 --> [R_B]

Then apply the SAME terminal readout M.
```

Null hypothesis:

```text
P(outcome | P1, [R_B]) = P(outcome | P2, [R_B])
```

for endpoint-equivalent final states under the operational state definition.

History-sensitive alternative:

```text
P(outcome | P1, [R_B]) != P(outcome | P2, [R_B]).
```

This architecture is generic and conventional. It does not yet predict which experiment or magnitude should differ.

## 9. Critical consistency condition

If the terminal readout distinguishes the two preparations, then under the R1 definition the final states were not actually physically equivalent with respect to the full admissible readout family.

Therefore a genuine claim of "same state, different history" requires care:

- either the state equivalence is defined relative to a restricted readout family and the later history readout extends that family;
- or history is modeled as part of the complete physical state;
- or the theory uses a layered notion of state (endpoint state versus history-extended state).

This is not a semantic detail. It is a structural consistency problem exposed by Q4.

## 10. Ontological refinement

To avoid contradiction, introduce two distinct notions:

### Resolutive Endpoint State

```text
E_R(Gamma) := pi_end(Gamma).target
```

The state class accessible to endpoint-local readouts.

### Resolutive Historical State

```text
HState_R(Gamma) := ([E_R(Gamma)], [Gamma]_C)
```

A candidate extended state that includes trajectory class if history-sensitive readouts are physically admitted.

Epistemic status:

```text
RESOLUTIVE_ENDPOINT_STATE = DEFINED
RESOLUTIVE_HISTORICAL_STATE = CONDITIONAL_CANDIDATE
```

This does not assert that nature requires historical state. It provides a consistent representation if Q4 is later passed empirically.
