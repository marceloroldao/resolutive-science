## Result

The T19 exponent `p*=2` is not fundamentally an exponent of raw nodule count. It is the low-eigenvalue scaling exponent of the relational operator against an appropriate **linear/coarse resolution scale**.

Numerical fits over the declared finite-size ranges gave approximately:

| family | gap exponent vs linear size | gap exponent vs node count |
|---|---:|---:|
| ring | 1.9947 | 1.9947 |
| open chain | 1.9987 | 1.9987 |
| degree-4 local circulant | 1.9562 | 1.9562 |
| periodic 2D torus | 1.8652 | 0.9326 |

The 2D finite-size fit is farther from the asymptotic value because the tested lattices are small; analytically its first Laplacian gap is `4 sin^2(pi/L) ~ 4 pi^2/L^2`, so the asymptotic exponent is exactly 2 against linear size `L`, and 1 against node count `N=L^2`.

## Interpretation

For the D13-A two-step sector, the correct scaling statement is

```text
delta_R ~ |lambda_low(L)|.
```

For local nearest/fixed-range Laplacian-like interactions on regular 1D/2D lattices,

```text
|lambda_low(L)| ~ L^-2.
```

Therefore `p=2` is robust against the tested changes of boundary condition and regular local topology **when expressed against linear resolution L**.

It is not universal against total nodule count. In dimension d with `N ~ L^d`, the same diffusive spectral law corresponds schematically to

```text
delta_R ~ N^(-2/d).
```

This dimensional dependence is a derived counting consequence once a lattice-like dimension is supplied; it is not yet a derived physical spatial dimension.
