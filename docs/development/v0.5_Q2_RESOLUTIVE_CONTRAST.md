# v0.5 Q2 — Resolutive Contrast Between Trajectories

**Line:** v0.5 relational ontology  
**Depends on:** R1-R5, Q1  
**Status:** COMPARATIVE STRUCTURE AUDIT  
**Target-data fitting:** NONE

## 1. Purpose

Q1 showed that assigning an absolute numerical valuation to an isolated trajectory is underdetermined. Q2 therefore tests a weaker and more relational object: comparison between admissible trajectories with the same physical endpoints.

Let

```text
pi_end(Gamma_1) = pi_end(Gamma_2) = ([R_A],[R_B]).
```

The question is whether a **Resolutive Contrast** can be defined before introducing a numerical scale.

## 2. Primitive comparative question

The weakest meaningful comparison is not

```text
V(Gamma_1) - V(Gamma_2)
```

because that already assumes a numerical valuation.

Instead introduce a candidate relation

```text
Gamma_1 ~_C Gamma_2
```

meaning: the two trajectories are indistinguishable under every admissible trajectory-sensitive Resolutive Readout available to the theory.

Formally, for a family `A_Gamma` of admissible trajectory readouts,

```text
Gamma_1 ~_C Gamma_2
iff
O_Gamma(Gamma_1) = O_Gamma(Gamma_2)
for every O_Gamma in A_Gamma.
```

This parallels R1 at the trajectory level.

## 3. Resolutive Trajectory Class

Define the quotient candidate

```text
P_Gamma = Gamma_R / ~_C.
```

An element

```text
[Gamma]_C
```

is a **Resolutive Trajectory Class**.

Epistemic status:

```text
TRAJECTORY_CLASS = DERIVED_FROM_ABSTRACT_READOUT_EQUIVALENCE
```

The admissible family `A_Gamma` remains underdetermined.

## 4. Boolean Resolutive Contrast

The weakest contrast is a Boolean distinction predicate:

```text
Delta_C(Gamma_1,Gamma_2) = 0 if Gamma_1 ~_C Gamma_2
                           1 otherwise.
```

This answers only whether the trajectories are distinguishable, not by how much.

It is symmetric:

```text
Delta_C(Gamma_1,Gamma_2) = Delta_C(Gamma_2,Gamma_1)
```

and satisfies

```text
Delta_C(Gamma,Gamma) = 0.
```

No triangle inequality or metric is implied.

## 5. Can an order be derived?

A stronger relation would be

```text
Gamma_1 <=_C Gamma_2.
```

But ordering requires a criterion such as lower cost, greater organization, higher probability, stronger coherence, shorter length, or preferred dynamics.

None is supplied by R1-R5/Q1.

Therefore:

```text
RESOLUTIVE_CONTRAST_ORDER = NOT_DERIVED
```

## 6. Can a signed contrast be derived?

A signed contrast

```text
C_R(Gamma_1,Gamma_2) = -C_R(Gamma_2,Gamma_1)
```

requires an oriented numerical value space or a selected reference convention.

No such structure is currently forced.

Therefore:

```text
SIGNED_CONTRAST = NOT_DERIVED
```

## 7. Can a magnitude of contrast be derived?

A nonnegative magnitude

```text
d_C(Gamma_1,Gamma_2) >= 0
```

would require at least a pseudometric/divergence-like structure or an operational distinguishability scale.

The current ontology does not select one.

Therefore:

```text
CONTRAST_MAGNITUDE = NOT_DERIVED
```

## 8. Composition compatibility

Suppose

```text
Gamma_1 ~_C Gamma_1'
Gamma_2 ~_C Gamma_2'.
```

For trajectory classes to support physical composition, we require the equivalence to be a congruence:

```text
Gamma_2 o Gamma_1 ~_C Gamma_2' o Gamma_1'
```

whenever both sides are composable.

This is not automatically guaranteed by arbitrary readouts. It becomes a consistency requirement on admissible trajectory readouts/equivalence.

Classification:

```text
COMPOSITION_CONGRUENCE = REQUIRED_FOR_QUOTIENT_DYNAMICS
```

## 9. Closed-loop comparison

For two closed trajectories on the same physical-state class,

```text
Gamma_loop1 : [R] -> [R]
Gamma_loop2 : [R] -> [R],
```

Q2 can ask whether they occupy the same trajectory class:

```text
[Gamma_loop1]_C ?= [Gamma_loop2]_C.
```

This comparison exists before assigning winding, phase, action, energy or duration.

Thus path-sensitive physics, if it later exists, can be introduced as a readout that separates loop classes rather than being assumed at the start.

## 10. Conventional comparator

Operational equivalence classes and quotienting by indistinguishability are conventional mathematical structures.

```text
Q2_NOVELTY = CONVENTIONAL_STRUCTURAL_FOUNDATION
```

No new physics is claimed.

## 11. Result

Q2 succeeds at a strictly comparative, non-numerical level:

```text
Q2_BOOLEAN_CONTRAST = PASS
Q2_TRAJECTORY_EQUIVALENCE = DEFINED_ABSTRACTLY
Q2_COMPOSITION_CONGRUENCE = REQUIRED
Q2_ORDER = NOT_DERIVED
Q2_SIGNED_CONTRAST = NOT_DERIVED
Q2_MAGNITUDE = NOT_DERIVED
```

The new formulation can therefore express:

```text
these two physical histories are distinguishable
```

before it can express:

```text
history 1 differs from history 2 by amount x.
```

## 12. Key conceptual consequence

The ontology now has two levels of physical equivalence:

```text
STATE EQUIVALENCE:
[R_A] == [R_B]

TRAJECTORY EQUIVALENCE:
[Gamma_1]_C == [Gamma_2]_C
```

Endpoint equivalence does not imply trajectory equivalence.

This makes the trajectory itself a potential bearer of physical information while preserving the distinction between structure and measurable magnitude.
