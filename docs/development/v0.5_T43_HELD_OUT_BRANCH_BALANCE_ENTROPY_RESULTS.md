## 7. Scientific interpretation

The T43 negative result is informative.

The replicated residual is not associated with more locally balanced branching as defined by B.

Instead, the parents combine:

- strong global compactness;
- very high degree assortativity relative to baseline degree-matched trees;
- C/A/G matched residual high-radius structure;
- and lower local split entropy B.

This suggests that the remaining organization is not simply "balanced branching."

One structurally motivated alternative is **higher-order clustering of branching vertices**: H4 measures only pairwise degree assortativity along edges, while it does not distinguish isolated branch-branch edges from extended connected runs/cores of branch vertices.

That candidate requires a new held-out protocol before evaluation.

## 9. Consequence

The next candidate should distinguish higher-order branch-node organization beyond H4 edge-level assortativity.

Define the branch set

```text
V_B = {v : degree(v) >= 3}
```

and the induced branch forest

```text
T_B = T[V_B].
```

A natural next single candidate is the largest branch-core fraction

```text
K(T)
=
size(largest connected component of T_B) / |V_B|.
```

K captures whether branch vertices form extended connected cores rather than isolated/pairwise assortative contacts.

It should be tested only on new held-out parents.
