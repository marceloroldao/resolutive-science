## 4. Fixed child quotas

For the rooted recursive tree define

```text
q(u) = number of v such that parent(v)=u.
```

Because each non-root vertex contributes one parent edge:

```text
degree(0) = q(0)
degree(v) = q(v)+1 for v>0.
```

Therefore preserving q(u) for every labeled vertex preserves the full labeled degree sequence exactly.

## 5. Null state space

A null state is a parent array

```text
p[1],...,p[N-1]
```

satisfying simultaneously:

1. `p[v] < v` for every v>0;
2. every labeled vertex u has exactly q(u) children.

Any such state is automatically a connected rooted tree because parent indices strictly decrease along ancestral chains and therefore terminate at vertex 0.

## 6. Frozen proposal move

Choose two distinct child labels a,b uniformly from {1,...,N-1}.

Let

```text
x = p[a]
y = p[b].
```

Propose the parent swap

```text
p'[a] = y
p'[b] = x.
```

Accept exactly if:

```text
y < a
x < b
```

and the proposed state differs from the current state.

The move preserves every child quota q(u) exactly.

No M3, M7, C/A/G or P_B quantity enters acceptance.
