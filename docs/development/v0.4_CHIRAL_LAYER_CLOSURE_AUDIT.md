# v0.4 Chiral Layer Closure Audit

**Status:** WORKING RESULT — FOLLOW-UP TO ORIENTATION AUDIT

## Question

Can a physical `Z2` layer derived from chirality also derive the proposed rule

```text
same layer -> 2pi closure
inter-layer -> 4pi closure
```

without separately postulating that a `2pi` operation flips the layer?

## 1. Minimal chiral state

Let an ordered orthonormal frame be represented by a matrix

```text
F in O(3).
```

Its handedness is

```text
ell(F) = (1 - det(F))/2 in Z2,
```

or equivalently the sign

```text
C(F) = det(F) in {+1,-1}.
```

This gives two disconnected components:

```text
O(3) = O_+(3) union O_-(3),
```

with `det=+1` and `det=-1`.

Classification: **D — genuine discrete invariant of O(3)**.

## 2. Continuous-rotation test

Every proper spatial rotation belongs to `SO(3)` and has determinant `+1`. Therefore, for any continuous rotational evolution

```text
F -> R(alpha) F,
R(alpha) in SO(3),
```

we have

```text
det(R(alpha) F) = det(F).
```

In particular,

```text
alpha = 2pi
```

does not change chirality.

Thus ordinary `2pi` evolution cannot produce

```text
ell -> ell xor 1
```

when `ell` is handedness.

Classification: **D — 2pi chirality flip is not derived**.

## 3. What flips chirality

Changing `det(F)` requires an improper transformation with determinant `-1`, such as parity/reflection, or passage through a singular/non-orthonormal configuration if one insists on continuous deformation in a larger matrix space.

Let `P` be such that

```text
det(P) = -1.
```

Then

```text
ell(PF) = ell(F) xor 1,
P^2 -> det +1.
```

Two parity-like operations restore the chirality sector. This is a genuine two-step `Z2` closure, but the operation count is not an angular `4pi` law.

Classification: **D — two-step parity closure; NOT a derived 4pi periodicity**.

## 4. Independence from phase

Adding ordinary phase gives a state such as

```text
S = R_+ x U(1) x O(3).
```

The phase circle and chirality component are independent unless an explicit coupling law is introduced. A rule

```text
2pi phase evolution -> parity flip
```

would therefore be an additional postulate, not a consequence of the product topology.

No existing Resolutive primitive currently derives such a coupling.

## 5. Falsification of the minimal chirality explanation

The hypothesis

```text
VERTICAL_4PI_FROM_CHIRALITY_ALONE
```

fails in the minimal model because:

1. chirality is a valid `Z2` state;
2. proper rotations preserve it for every angle, including `2pi`;
3. chirality-changing operations are parity-like, not ordinary angular continuation;
4. two parity flips close the binary state but do not imply `4pi`.

Result:

```text
CHIRALITY_GIVES_LAYER = YES
CHIRALITY_DERIVES_2PI_TO_LAYER_FLIP = NO
CHIRALITY_DERIVES_PHYSICAL_4PI = NO
```

## 6. Remaining route to genuine angular 4pi

If the project requires `2pi` to change the lifted state while `4pi` restores it, the mathematical structure must carry a nontrivial lift of rotations rather than only a chirality bit.

The canonical comparison class is a double cover of rotational state space, e.g. a lifted orientation with projection

```text
p : S_lift -> SO(3)
```

such that a closed `2pi` loop in the base lifts to a path between distinct fiber points and a `4pi` continuation closes the lifted path.

This does not authorize importing a spinor model by analogy. The next test must ask whether such a lift can be motivated from Resolutive primitives and whether the lift label is observable.

## 7. Decision

```text
CHIRAL_LAYER = PHYSICALLY_POSSIBLE_Z2
CHIRAL_4PI = REJECTED_AS_DERIVATION
NEXT_ROUTE = LIFTED_ORIENTATION_AUDIT
```

The horizontal/vertical idea survives only in a weaker form at this stage: horizontal ordinary rotation and vertical discrete transition can be distinct operations, but `2pi`/`4pi` is not yet derived from chirality.
