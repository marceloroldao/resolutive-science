# v0.5 T25 — Endogenous Dimension Protocol

**Line:** v0.5 relational ontology — theory-only track
**Depends on:** T13–T24 and T25 estimator harness
**Status:** FROZEN PROTOCOL BEFORE ENDOGENOUS NETWORK TEST

## Purpose

Determine whether dimension can be inferred from a relational network generated without assigning Euclidean coordinates or a construction dimension.

## Ontological vocabulary

- **Nódulo Resolutivo:** vertex carrying the declared local resolutive state.
- **Relação Resolutiva:** adjacency/interaction relation used by the transition law.
- **Distância Relacional:** shortest-path graph distance; not meters.
- **Vizinhança Resolutiva:** graph ball around a nodule.
- **Dimensão Resolutiva Efetiva:** scaling property inferred from the relational structure; not assumed to equal physical spatial dimension.

## Estimators

Growth dimension:
V(r) ~ r^(d_g).

Spectral dimension:
P_return(t) ~ t^(-d_s/2).

Walk dimension:
<r^2>(t) ~ t^(2/d_w).

No estimator is privileged in advance and disagreement is preserved.

## Endogenous-network requirement

The candidate graph must be generated from a coordinate-free rule. Forbidden during generation:

1. embedding vertices in R^d;
2. using Euclidean distance;
3. supplying a target dimension;
4. choosing edges to reproduce a known lattice;
5. retuning after inspecting d_g, d_s or d_w.

Node labels may be used only as opaque identifiers. Relabeling must not change inferred observables beyond numerical/statistical tolerance.

## First candidate family

Start from a finite set of Nódulos Resolutivos with local states and create/remove Relações Resolutivas using only state-local information and graph-local information already available to each nodule.

A minimal preregistered candidate is degree-limited relational attachment:

- each new nodule receives an opaque identifier;
- it samples existing nodules through a deterministic seed recorded with the run;
- attachment score may depend on current graph degree and declared local resolutive state only;
- no coordinate or lattice-neighbor information is available;
- maximum degree and attachment rule are frozen before dimension estimation.

This family is an instrument test for endogenous geometry, not a claim that nature uses preferential or degree-limited attachment.

## Scaling-window gates

A dimension estimate is reportable only if:

- at least three graph sizes are tested;
- multiple roots/seeds are tested;
- a nontrivial pre-saturation radius/time window exists;
- fitted exponent is stable when the window endpoints move;
- relabeling leaves the result invariant;
- finite-size drift is reported.

If no stable window exists:
T25_ENDOGENOUS_DIMENSION = NOT_IDENTIFIED.

## Cross-estimator rule

Do not average d_g, d_s and d_w.

Possible outcomes:

- CONSISTENT_INTEGER_LIKE
- CONSISTENT_NONINTEGER
- MULTIFRACTAL_OR_SCALE_DEPENDENT
- ESTIMATOR_DISAGREEMENT
- NO_STABLE_SCALING_WINDOW

Only the measured scaling behavior is reported.

## Physical interpretation guard

Even a stable d_R does not establish physical spatial dimension. That requires an operational mapping from relational distance/propagation to physical rods, clocks and observables.
