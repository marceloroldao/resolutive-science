# v0.5 E1 — Precision RC Preregistration and Synthetic Validation

**Line:** v0.5 relational ontology  
**Depends on:** E0  
**Status:** PREREGISTERED SYNTHETIC TEST SPECIFICATION  
**Hardware testing:** FORBIDDEN UNTIL SYNTHETIC GATES PASS

## 1. Objective

Instantiate P2 in the simplest useful passive linear electrical system and validate the complete analysis pipeline on synthetic data before hardware.

E1 is a null-methodology experiment. It is not designed to manufacture a Resolutive effect.

## 2. Frozen topology

Use a two-state passive RC ladder:

```text
u(t) -- R1 --o-- R2 --o
             |        |
             C1       C2
             |        |
            GND      GND
```

Nominal values:

```text
R1 = 10.0 kOhm
R2 = 22.0 kOhm
C1 = 10.0 uF
C2 = 4.7 uF
```

State vector:

```text
x(t) = [v_C1(t), v_C2(t)]^T.
```

Endpoint verification must include both capacitor-node voltages. Equality of only the output node is insufficient.

## 3. Ideal conventional model

Kirchhoff equations:

```text
C1 dv1/dt = (u-v1)/R1 - (v1-v2)/R2
C2 dv2/dt = (v1-v2)/R2
```

or

```text
x_dot = A x + B u.
```

with

```text
A11 = -(1/R1 + 1/R2)/C1
A12 = +(1/R2)/C1
A21 = +(1/R2)/C2
A22 = -(1/R2)/C2

B1 = 1/(R1*C1)
B2 = 0.
```

Primary probe output:

```text
y(t) = v_C2(t).
```

Secondary diagnostic output:

```text
v_C1(t).
```

## 4. Initial preparation

Each trial begins from a reset condition:

```text
|v_C1| < 1 mV
|v_C2| < 1 mV
```

in synthetic tests the exact initial state is frozen to

```text
x0 = [0,0] V.
```

Hardware reset criteria will later require a separate E2 specification.

## 5. Two distinct preparation histories

Target endpoint state:

```text
x_target = [2.000 V, 1.000 V]^T.
```

Synthetic P1 and P2 are generated as distinct piecewise-constant input histories and then completed by a deterministic endpoint-matching control segment computed from the ideal state-space model.

Frozen qualitative construction:

```text
P1 prefix: positive-first excitation
P2 prefix: overshoot/reversal excitation
```

The final matching segment must solve for controls so that both histories end at the same `x_target` at the same preregistered terminal time.

The endpoint-matching algorithm is part of the simulation and must not use post-probe outcomes.

## 6. Endpoint equivalence criterion

For synthetic ideal tests:

```text
max_i |x_i(P1)-x_i(P2)| <= 1e-9 V
```

and both must satisfy

```text
max_i |x_i(Pj)-x_target_i| <= 1e-9 V.
```

For noisy synthetic tests, the endpoint tolerance is relaxed only according to a preregistered simulated measurement-noise model, not after seeing the history-probe statistic.

## 7. Common history probe

Immediately after endpoint verification, both preparations receive the identical probe:

```text
u_H(t) = 2.000 V + 0.100 V step
```

for

```text
T_probe = 1.000 s.
```

Synthetic sample rate:

```text
f_s = 10 kHz.
```

The same numerical integrator and time grid are used for both arms.

## 8. Primary null statistic

Let

```text
r(t) = y_P1(t) - y_P2(t).
```

Primary statistic:

```text
S_RMS = sqrt(mean(r(t)^2)).
```

Secondary diagnostics:

```text
S_MAX = max |r(t)|
S_AREA = integral |r(t)| dt
```

Only `S_RMS` is primary in E1.

For exact ideal synthetic data, expected result is numerical zero up to solver precision.

## 9. Synthetic noise model

For the noisy-null validation, independently add zero-mean Gaussian measurement noise after simulation:

```text
sigma_v = 100 uV RMS
```

per sampled channel.

The underlying physical state evolution remains ideal RC.

No noise parameter may be fitted from the P1/P2 contrast.

## 10. Trial structure and randomization

Synthetic validation uses:

```text
N = 1000 paired trials
```

with randomized hidden labels for P1/P2 in the analysis input.

The analysis pipeline receives trial waveforms and labels only through the preregistered decoding stage.

Negative-label control: randomly permute P1/P2 labels within identically generated null trials; false detection must remain at the nominal decision rate.

## 11. Null decision rule

The exact ideal gate is deterministic:

```text
E1_IDEAL_PASS iff S_RMS <= 1e-10 V
```

or a documented tighter numerical floor established solely from solver convergence tests.

For noisy paired trials, compute one scalar `S_RMS` per pair and compare the distribution against a synthetic null generated from the frozen noise model. Use a two-sided Monte Carlo/permutation decision with

```text
alpha = 0.01.
```

No optional stopping.

## 12. Conventional positive-control memory model

Synthetic positive control introduces a deliberately hidden dielectric-absorption branch on C2:

```text
C2 ideal branch plus series (R_DA, C_DA) relaxation branch
```

frozen nominal injection:

```text
C_DA = 0.047 uF   # 1% of nominal C2
R_DA = 2.2 MOhm
```

This creates a conventional internal state not included in the two-voltage endpoint vector.

P1/P2 are still matched in accessible `v_C1,v_C2`, but the hidden DA state may differ and alter the subsequent probe transient.

This is **known conventional memory**, not a Resolutive effect.

## 13. Positive-control gate

The pipeline must detect the injected DA model at the frozen decision threshold in at least

```text
>= 90% of 100 independent synthetic batches
```

while maintaining the noisy-null false-positive rate compatible with `alpha=0.01` within binomial sampling uncertainty.

If sensitivity is inadequate, the protocol may be redesigned only before hardware and the revision must be versioned as a new preregistration.

## 14. Model-mismatch controls

Additional synthetic nuisance runs must independently vary:

```text
R1,R2: +/-1%
C1,C2: +/-5%
temperature-correlated resistance drift: documented synthetic coefficient
ADC gain offset: documented fixed injection
sampling-time jitter: documented fixed injection
```

The purpose is to determine which conventional mismatches mimic a path contrast.

These nuisance runs are diagnostics; they cannot be used to tune a post-hoc anomaly threshold.

## 15. Synthetic pass/fail matrix

Hardware authorization requires all mandatory gates:

```text
G1 IDEAL_NULL: PASS
G2 NOISY_NULL_CALIBRATION: PASS
G3 RANDOM_LABEL_CONTROL: PASS
G4 DA_POSITIVE_CONTROL: PASS
G5 SOLVER_CONVERGENCE: PASS
G6 ENDPOINT_MATCHING: PASS
```

If any mandatory gate fails:

```text
E1_SYNTHETIC_VALIDATION = FAIL
HARDWARE_AUTHORIZATION = NO
```

## 16. Interpretation boundary

A successful E1 only demonstrates that the experimental/analysis architecture can:

1. return null for an ideal Markov RC system;
2. detect a known omitted internal memory state;
3. control false positives under the frozen synthetic model.

It provides no evidence for Resolutive Physics.
