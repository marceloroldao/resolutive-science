# v0.4 Fundamental Principle Selection Protocol

**Status:** FROZEN SEARCH PROTOCOL — no new data fitting authorized

## 1. Purpose

After the fundamental reconstruction audit returned

```text
MASTER_EQUATION_STATUS = NOT_UNIQUELY_DERIVED_FROM_CURRENT_RSMS
V0.4_FUNDAMENTAL_RECONSTRUCTION = DIAGNOSTIC_STOP_UNDERDETERMINED
```

the next scientific task is not to add terms to a Master Equation. It is to determine whether one independently motivated principle can reduce the present dynamical freedom.

This protocol is frozen before any new cosmological or galactic fit. Negative outcomes are retained.

## 2. Inherited state

The RSMS primitive state remains

```text
R = (rho_R, Theta_R, iota_R, kappa_R).
```

No fifth primitive is introduced by this protocol.

The existing half-angle representation does not supply an independent physical 4pi law. The current classification remains

```text
FOUR_PI_STATUS = PARAMETRIZATION_ONLY_4PI.
```

## 3. Question under test

Does there exist a single principle P, motivated independently of target residuals, such that P:

1. acts on the inherited RSMS state or its already admitted bundle structure;
2. restricts the admissible evolution law nontrivially;
3. is not removable by coordinate/field redefinition;
4. has a conventional comparison model;
5. yields at least one observable consequence before fitting target data; and
6. can fail?

A principle that merely renames a conventional structure is rejected as a source of Resolutive novelty.

## 4. Candidate-principle classes

Candidates are screened in this order. Ordering is methodological, not evidence for any candidate.

### P-A — Extremal/variational principle

Question: can a minimal action be selected from independently declared symmetries, dimensions, locality and state-space geometry?

Failure condition: many inequivalent actions remain admissible with no independent selector.

### P-B — Geometric transport/coherence principle

Question: does a connection/parallel-transport/holonomy rule already motivated by the RSMS bundle structure select dynamics or a measurable path dependence?

Failure condition: the connection or holonomy must itself be freely chosen to obtain the desired effect.

### P-C — Conservation/invariance principle

Question: does a declared physical invariance force a conserved current or restrict couplings enough to determine dynamics?

Failure condition: the symmetry is only conventional U(1), coordinate invariance, or another standard redundancy with no new observable content.

### P-D — Relational/state-transition principle

Question: can physical change be defined only through relations between resolutive states in a way that produces a unique composition/evolution rule?

Failure condition: the relation is descriptive but leaves arbitrary transition functions.

### P-E — Information/coherence extremum

Question: can a precisely defined scalar functional of the inherited state be extremized or conserved without importing an arbitrary metric, entropy or loss function?

Failure condition: the functional is selected because it improves a fit or because its mathematical form is convenient.

## 6. Selection gates

### S1 — INDEPENDENT_MOTIVATION

PASS only if the principle was not chosen from RCMS/BOSS/DESI/SPARC residual structure or other target-domain fit behavior.

### S2 — MATHEMATICAL_CLOSURE

PASS only if all objects, domains, transformations and dimensions required by the principle are explicit.

### S3 — NONTRIVIAL_RESTRICTION

PASS only if the principle removes at least one genuine degree of model-building freedom.

### S4 — NOVELTY_AUDIT

Allowed outcomes:

```text
CONVENTIONAL_EQUIVALENT
NEW_STRUCTURE_POSTULATED
NEW_STRUCTURE_DERIVED
UNDERDETERMINED
```

Only the last two non-conventional outcomes may continue, and a postulated structure requires an explicit observable and complexity accounting.

### S5 — FALSIFIABILITY

PASS only if a result exists that would reject the candidate principle or its proposed physical role.

### S6 — OBSERVABLE_MAP_FROZEN

PASS only after the observable mapping is frozen before target-domain evaluation.

## 7. Anti-retuning rules

Forbidden during principle selection:

- selecting a term because it repairs the v0.3 BOSS failure;
- selecting a term because it reproduces a historical SPARC improvement;
- adding survey-specific coefficients;
- introducing a hidden binary state solely to restore 4pi;
- changing the primitive state count without opening an explicit RSMS-extension issue;
- interpreting iota_R or kappa_R as known physical quantities without a normative map;
- using parameter-fit success as derivation evidence.

## 8. First screening order

The first pass shall test P-A through P-E analytically and structurally, without observational optimization.

For each class record exactly one of:

```text
REJECT_CONVENTIONAL
REJECT_UNDERDETERMINED
RETAIN_CANDIDATE
BLOCKED_MISSING_DEFINITION
```

No candidate advances merely because the others fail.

## 9. Stop rule

If all P-A through P-E fail S1-S5, record

```text
PRINCIPLE_SEARCH = NO_UNIQUE_SELECTOR_FOUND
```

and stop. Do not synthesize a hybrid principle from the failed candidates in the same cycle.

If exactly one or more candidates survive, each survivor receives an independent preregistration before any empirical fit. Multiple survivors remain competing hypotheses; they are not combined until a separate selection rule exists.

## 10. Current next action

Begin with P-A, because the repository already contains a candidate Lagrangian history and RSMS admits variational dynamics while explicitly refusing to choose a universal equation. The test is whether inherited state-space structure, dimensional consistency and symmetry can uniquely constrain a minimal action.

The expected result is not presumed positive. If conventional scalar-field freedom remains, P-A shall be recorded as `REJECT_UNDERDETERMINED` or `REJECT_CONVENTIONAL` as appropriate, and the search proceeds to P-B.
