# v0.5 T33 — Vector Relational Geometry Results

**Protocol:** frozen T33. **Dynamics:** none.
Matrix: N=128,256,512; seeds 11,23,47; R=1,2,4,8.

## Test / Result / Conclusion

### A. Path composition

For any path v0,...,vk,

sum_i [p(v_{i+1})-p(v_i)] = p(v_k)-p(v_0)

holds identically by telescoping. This validates internal consistency of the displacement representation but is not evidence of physical vector space.

T33_PATH_COMPOSITION = EXACT_BY_CONSTRUCTION.

### B. Local displacement rank

The local edge-displacement matrices are generally not rank-one once R>=2. Multiple independent profile-space directions occur around branching nodules.

However rank is bounded both by profile dimension R+1 and by graph degree, and the parent T25 graph has mean degree approximately two. Consequently no stable high-dimensional local tangent structure is identified.

T33_VECTOR_INFORMATION = NONTRIVIAL.
T33_STABLE_LOCAL_TANGENT_DIMENSION = NOT_IDENTIFIED.

### C. Linear span

For many reference/current-node pairs, the target displacement has a nonzero component outside the span of immediately available edge displacements. The unrestricted span therefore does not generically reconstruct the target direction from one-hop local information.

T33_LOCAL_LINEAR_COMPLETENESS = NOT_IDENTIFIED.

### D. Positive cone

The positive cone is more restrictive than the linear span and does not generically contain the target displacement. Cone residuals remain substantial and vary with graph, reference and R.

T33_LOCAL_CONE_COHERENCE = NOT_IDENTIFIED.

### E. Scalar-trap resolution

This is the decisive test.

At a strict scalar trap v relative to reference a, every neighbor w satisfies

||t - delta p(v->w)|| > ||t||,

where t=p(a)-p(v).

Expanding the squared norm gives

||t-delta||^2 = ||t||^2 + ||delta||^2 - 2 delta·t.

A neighbor can therefore increase scalar distance while still having delta·t>0 whenever

0 < 2 delta·t < ||delta||^2.

Thus scalar trapping does not mathematically imply absence of target-aligned vector information.

The frozen audit finds such positive-alignment directions in a nonzero subset of scalar traps across the matrix. Therefore the vector representation recovers directional information that scalar descent discards.

But the signal is not universal: many traps still have no positively aligned available edge, and positive alignment alone does not imply that repeated local moves reach the reference.

T33_SCALAR_TRAP_VECTOR_SIGNAL = IDENTIFIED_PARTIAL.
T33_VECTOR_RESOLVES_ALL_SCALAR_TRAPS = REJECTED.

## Core conclusion

The scalar T30 distance is a lossy projection of a richer relational profile geometry.

SCALAR_LOCAL_MINIMUM != VECTOR_DIRECTION_ABSENCE.

However:

VECTOR_DIRECTION_PRESENT != COHERENT_LOCAL_NAVIGATION.

The T33 profile-space vector structure is therefore mathematically richer than T30/T31 scalar descent, but it is insufficient to promote a transition law.

## Consequence for T34

Do not convert positive dot product into a transition rule.

The next test should determine whether the profile-displacement vectors possess a reproducible **local subspace structure across scale**. Specifically, compare local singular spectra/subspaces between R and 2R and between increasing N.

If a stable low-rank subspace emerges without selecting a target rank, it could provide a coordinate-free candidate for local effective geometry. If rank/subspace drifts without convergence, freeze that negative result before considering dynamics.
