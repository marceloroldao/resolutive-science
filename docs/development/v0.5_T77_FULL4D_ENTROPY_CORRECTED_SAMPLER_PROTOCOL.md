# v0.5 T77 — Full Four-Dimensional Entropy-Corrected Sampler Validation Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T76.  
**Purpose:** validate a full 4D inverse-tilt correction for the constrained A1/A2/A3/C_KR null measure before reopening M3/M7.

## 1. New held-out parent matrix

Exact T25 parents:

N = 4096  
seeds = {1847, 1871, 1901}.

These seeds are new relative to T70–T76.

M3 and M7 are forbidden.

## 2. Stage A and hard box

For each parent generate 99 ordinary T47 recursive-order nulls.

- burn-in = 2000 accepted swaps;
- thinning = 200;
- proposal ceiling = 10,000,000;
- parent-edge overlap <= 0.90.

Compute:

A1 = mean(R)
A2 = mean(R^2)
A3 = mean(R^3)
C_KR = Cov(K_pre,R).

For each Q define the hard half-width

Delta_Q = 0.25 * population_sd_StageA(Q).

No band widening is allowed.

## 3. Normalized coordinates

Define the four normalized offsets

y_i = (Q_i-Q_i,parent)/Delta_i,

for i in {A1,A2,A3,C_KR}.

The hard matching region is therefore the fixed hypercube

-1 <= y_i <= +1.

## 4. Exact local 4D accepted-step law

At the exact T25 parent, exhaustively enumerate all unordered child-pair proposals.

Keep a proposal only if:
1. the quota-preserving parent swap is structurally valid;
2. the one-step result lies inside all four hard bands.

For the accepted normalized step vector Delta y compute:

mu_y = E[Delta y]

Sigma_y = Cov(Delta y).

Use the Moore-Penrose pseudoinverse with fixed numerical cutoff

rcond = 1e-12.

Define the minimum-norm local tilt

lambda_y
=
2 * pinv(Sigma_y) * mu_y.

Report:
- covariance eigenvalues;
- numerical rank under the same rcond;
- reconstruction residual
  ||0.5 Sigma_y lambda_y - mu_y||.

No post-hoc component deletion is allowed.

## 5. Corrected Stage B target

Inside the unchanged four-dimensional hard box, use target weight

w(state)
=
exp[-lambda_y dot y(state)]

relative to the uniform graph-state measure.

For a symmetric child-pair proposal with normalized increment Delta y, accept a structurally valid, hard-box-valid move with probability

min(1, exp[-lambda_y dot Delta y]).

This uses all four coordinates.

## 6. Multi-chain construction

For each parent run exactly 9 independent corrected chains.

Each chain:
- starts from the exact T25 parent;
- burn-in = 2000 accepted MH state changes;
- thinning = 200 accepted MH state changes;
- stores 11 states;
- proposal ceiling = 3,000,000.

Pool 99 unique states.

Stored-state parent-edge overlap must be <=0.90.

Duplicates are forbidden across the pooled ensemble.

## 7. Frozen validation gates

For every parent:

### Feasibility
All 9 chains store 11 states.

### Hard box
Every stored state remains inside all four hard bands.

### Parent bracketing
For each of A1,A2,A3,C_KR, the exact parent value lies inside the pooled min/max range.

### Four-coordinate centering
For every Q in {A1,A2,A3,C_KR}:

|mean(Q_null)-Q_parent|
<=
0.20 * Delta_Q.

The 20% gate is frozen before execution.

## 8. Decision

T77_FULL4D_SAMPLER_VALIDATED = PASS only if all four gates pass for all three held-out parents.

No rescue seeds, no rcond change, no band widening and no centering relaxation.

## 9. Interpretation

A PASS validates a larger-N matched-null sampler whose coordinate measure is approximately centered in the complete control space used by T69.

Only after a PASS may M3/M7 be evaluated under an identical, separately frozen runner.

## 10. Scientific stop

The 4D tilt is a correction to a Markov-chain sampling measure. It is not physical entropy, energy, force or time.
