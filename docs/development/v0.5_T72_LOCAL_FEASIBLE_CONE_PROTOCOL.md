## 3. Exhaustive one-swap neighborhood

For every unordered pair of children a,b in {1,...,N-1}, with current parents x=p(a), y=p(b), consider the exact T47 quota-preserving swap

p(a)=y,
p(b)=x.

A move is structurally valid only if:
- x != y;
- y < a;
- x < b.

This preserves child quotas and final labeled degree sequence exactly.

Enumerate **all** such one-swap moves.

## 4. Band-feasible local move

For every structurally valid swap compute exact changes:

Delta A1,
Delta A2,
Delta A3,
Delta C_KR.

A move belongs to the local feasible cone if the resulting state remains inside all four frozen T70 bands around the exact parent.

No parent-edge-overlap requirement is used in this one-step geometry audit; a one-swap state is necessarily a near-copy and is not proposed as a null sample.

## 5. Frozen directional questions

T70/T71 support failures were one-sided toward:
- smaller A1 for seeds 1571 and 1601;
- less-negative C_KR for all three seeds.

T72 therefore freezes the following questions before enumeration:

1. Does any band-feasible one-swap move have Delta A1 > 0?
2. Does any band-feasible one-swap move have Delta C_KR < 0?
3. Does any band-feasible one-swap move simultaneously have Delta A1 > 0 and Delta C_KR < 0?

Report these for every seed.

Also report:
- total structurally valid swaps;
- total four-band-feasible swaps;
- min/max Delta of each control;
- counts by sign of Delta A1 and Delta C_KR.

## 6. Classification

T72_LOCAL_BOUNDARY_A1 is identified for a seed if no four-band-feasible move has Delta A1>0.

T72_LOCAL_BOUNDARY_C is identified for a seed if no four-band-feasible move has Delta C_KR<0.

T72_JOINT_OUTWARD_DIRECTION is reachable only if at least one feasible move has both Delta A1>0 and Delta C_KR<0.

This is a local, one-swap statement only. It does not prove global extremality.
