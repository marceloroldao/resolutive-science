# v0.5 T33 — Vector Relational Geometry Protocol

**Status:** FROZEN BEFORE EXECUTION
**Parent:** T30/T31/T32. **New dynamics:** none.

## Question

Does the full T30 profile vector contain directional relational information that is lost when compressed to the scalar distance D_R?

## Frozen vector object

For each nodule v and radius R:

p_R(v)=(m_0(v),...,m_R(v))

exactly as frozen in T30.

For every existing oriented relation u->v define

delta p_R(u->v)=p_R(v)-p_R(u).

This satisfies exact antisymmetry:
delta p(u->v)=-delta p(v->u).

For reference a and current nodule v define target displacement

t_a(v)=p_R(a)-p_R(v).

No coordinates external to the graph are introduced; profile space is derived from relational shell counts.

## Diagnostic A — path composition

For every graph path v0,...,vk test

sum_i delta p(vi->v{i+1}) = p(vk)-p(v0).

This telescoping identity must hold numerically. It is a consistency check, not evidence of physical vector space.

## Diagnostic B — local displacement rank

At each v form the matrix whose rows are neighbor displacements delta p(v->w).

Measure:
- rank;
- rank/(R+1);
- singular values;
- effective participation rank = (sum s_i^2)^2 / sum s_i^4 where defined.

Aggregate over all nodules, sizes, seeds and R.

## Diagnostic C — target in local linear span

For each reference a and v != a, project t_a(v) onto the linear span of local edge displacements.

Residual:

epsilon_span = ||t-Proj_span(t)|| / ||t||.

Measure exact/near numerical reconstruction using only machine-precision consistency, not a fitted tolerance. Report raw residual distributions.

Linear span allows signed coefficients and therefore is diagnostic only; it does not define an allowed transition.

## Diagnostic D — target in local positive cone

Ask whether t_a(v) can be approximated by a nonnegative combination of local edge displacements.

Use nonnegative least squares where available; otherwise an explicitly documented deterministic solver.

Residual:

epsilon_cone = ||t-X^T alpha||/||t||, alpha_i>=0.

The cone is closer to available forward relational directions than the unrestricted span, but still does not define dynamics.

## Diagnostic E — scalar-trap resolution

Use the exact strict local minima identified by T32.

For each scalar trap v relative to a, test:
- span residual;
- cone residual;
- whether at least one neighboring displacement has positive dot product with target t_a(v).

The last condition asks whether vector information contains a locally target-aligned direction even when every neighbor increases scalar D_R.
