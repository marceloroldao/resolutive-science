# v0.5 Q3 — Resolutive Composition Contrast

**Line:** v0.5 relational ontology  
**Depends on:** R1-R5, Q1-Q2  
**Status:** STRUCTURAL PATH-DEPENDENCE AUDIT  
**Target-data fitting:** NONE

## 1. Purpose

Q2 established non-numerical trajectory equivalence and contrast. Q3 asks when alternative decompositions with the same physical endpoints must be identified and what is represented when they are not.

Consider

```text
Gamma_ABC = T_BC o T_AB
Gamma_ADC = T_DC o T_AD
```

with

```text
pi_end(Gamma_ABC) = pi_end(Gamma_ADC) = ([R_A],[R_C]).
```

No energy, phase, curvature, time, action, metric or probability is introduced.

## 2. Endpoint equality is insufficient

From R4 and Q2,

```text
pi_end(Gamma_1) = pi_end(Gamma_2)
```

does not imply

```text
Gamma_1 ~_C Gamma_2.
```

Thus the ontology permits alternative physical histories between the same endpoint classes.

Classification:

```text
ENDPOINT_DETERMINES_TRAJECTORY_CLASS = FALSE_IN_GENERAL
```

This is a structural allowance, not yet evidence of physical path dependence.

## 3. Path independence as an additional condition

Define **Resolutive Path Independence** on a domain `D` by

```text
for all Gamma_1,Gamma_2 in D,
pi_end(Gamma_1)=pi_end(Gamma_2)
=>
Gamma_1 ~_C Gamma_2.
```

If this holds, trajectory class is determined by endpoint classes within `D`.

This condition is not forced by R1-Q2.

Therefore:

```text
RESOLUTIVE_PATH_INDEPENDENCE = OPTIONAL_ADDITIONAL_STRUCTURE
```

## 4. Path dependence as failure of factorization through endpoints

Let

```text
q : Gamma_R -> P_Gamma
```

map a trajectory to its physical trajectory class, and let

```text
pi_end : Gamma_R -> P_R x P_R.
```

Path independence means that there exists a map

```text
f : P_R x P_R -> P_Gamma
```

such that

```text
q = f o pi_end.
```

In words: the physical trajectory class factors entirely through the endpoints.

If no such `f` exists, then trajectory information cannot be reduced to endpoint information.

Define this structural condition as **Resolutive Path Dependence**:

```text
PATH_DEPENDENT
iff
q does not factor through pi_end.
```

This is the cleanest non-numerical definition obtained so far.

## 5. Resolutive History Residue

Introduce the ontological name **Resolutive History Residue** for the information retained in trajectory class after endpoint projection:

```text
H_R(Gamma) := information in [Gamma]_C not fixed by pi_end(Gamma).
```

This is not yet a number or physical observable. Formally, it denotes the failure of endpoint projection to determine trajectory class.

Epistemic status:

```text
RESOLUTIVE_HISTORY_RESIDUE = DEFINED_STRUCTURALLY
```

It must not be identified with energy, memory, entropy, phase, action or curvature at Q3.

## 6. Zero residue condition

Within a path-independent domain,

```text
H_R = 0
```

is shorthand for

```text
trajectory class is completely determined by endpoints.
```

This zero is logical/structural, not a physical scalar zero.

## 7. Closed trajectories sharpen the test

For a closed trajectory

```text
Gamma_loop : [R] -> [R],
```

the endpoint projection is the same as that of the identity transition:

```text
pi_end(Gamma_loop) = pi_end(I_[R]).
```

Therefore a particularly sharp path-dependence test is

```text
Gamma_loop ~_C I_[R] ?
```

If every closed trajectory is equivalent to identity, no trajectory-sensitive residue survives on loops.

If at least one closed trajectory satisfies

```text
Gamma_loop not~_C I_[R],
```

then endpoint information is provably insufficient under the chosen admissible readouts.

This still does not determine what observable distinguishes the loop.

## 8. Composition consistency

Because Q2 requires `~_C` to be a congruence, any detected history residue must be compatible with composition. Equivalent subtrajectories cannot become distinguishable solely because they are embedded in a larger composition, unless the admissible readout is explicitly context-dependent.

For the minimal context-independent formulation:

```text
Gamma_1 ~_C Gamma_1'
Gamma_2 ~_C Gamma_2'
=>
Gamma_2 o Gamma_1 ~_C Gamma_2' o Gamma_1'.
```

## 9. Does Q3 derive a nontrivial residue?

No.

Q3 defines precisely what path dependence would mean, but the current ontology does not supply a trajectory-sensitive readout that proves

```text
Gamma_1 not~_C Gamma_2
```

for same-endpoint alternatives.

Thus:

```text
PATH_DEPENDENCE_CONCEPT = DEFINED
NONTRIVIAL_HISTORY_RESIDUE = NOT_YET_DERIVED
```

## 10. Conventional comparator

Failure of factorization through endpoint data is a conventional structural way to express path dependence/information beyond endpoints.

```text
Q3_NOVELTY = CONVENTIONAL_STRUCTURAL_FOUNDATION
```

No new physics is claimed.

## 12. Key consequence

The relational ontology can now distinguish three logically separate objects:

```text
STATE INFORMATION
ENDPOINT-RELATIONAL INFORMATION
TRAJECTORY/HISTORY INFORMATION
```

The third exists as a structural possibility exactly when trajectory class does not factor through endpoint classes.

This is a stronger and cleaner statement than asserting that a path carries energy or memory.
