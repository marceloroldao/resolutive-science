# v0.5 T43 — Held-Out Branch-Balance Entropy Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T42. **New dynamics:** none.

## 1. Motivation

T42 replicated residual high-radius structure after exact degree control and C/A/G matching.

The next candidate must be motivated from tree structure rather than selected from a broad metric sweep.

For a tree, removal of a vertex v partitions the remaining graph into one connected component for each incident edge. The relative masses of those components describe how evenly relational mass is distributed among the branches meeting at v.

The T25 low-degree attachment rule can produce compact yet hierarchically balanced branching. C/A/G do not explicitly measure that local partition balance.

T43 tests one candidate only: normalized branch-balance entropy.

## 4. Branch-balance entropy

For a vertex v with degree d_v >= 2, remove v from the tree.

Let the resulting component sizes be

```text
s_(v,1), ..., s_(v,d_v)
```

with

```text
sum_i s_(v,i) = N-1.
```

Define

```text
p_(v,i) = s_(v,i)/(N-1)
```

and normalized split entropy

```text
h(v)
=
-[sum_i p_(v,i) ln p_(v,i)] / ln(d_v).
```

Then

```text
0 <= h(v) <= 1.
```

Leaves are excluded because ln(d_v)=0.

Define the tree-level candidate

```text
B(T)
=
mean_{v: d_v>=2} h(v).
```

No alternative weighting, entropy base, threshold or vertex subset may be selected after execution.

## 7. Gates

### T43_MATCH_FEASIBILITY

PASS only if all 3 N=2048 parents produce 99 valid T41-matched nulls under unchanged controls.

### T43_LARGE_N_RESIDUAL_REPLICATION

IDENTIFIED only if M3 and M7 are both above q975 for all 3 parents.

### T43_BRANCH_BALANCE_PARENT_DEPARTURE

The directional hypothesis is:

```text
B_parent > q975(B matched null)
```

for all 3 parents.

Only then is the parent-departure gate identified.

### T43_BRANCH_BALANCE_RESPONSE_ASSOCIATION

IDENTIFIED only if, in all 3 matched-null ensembles:

```text
rho(B,M3) > 0
rho(B,M7) > 0
```

and

```text
median over parents of min(rho(B,M3),rho(B,M7)) >= 0.50.
```

The 0.50 threshold is frozen before execution.

### T43_BRANCH_BALANCE_CANDIDATE

IDENTIFIED only if all of:

1. T43_MATCH_FEASIBILITY passes;
2. T43_LARGE_N_RESIDUAL_REPLICATION is identified;
3. T43_BRANCH_BALANCE_PARENT_DEPARTURE is identified;
4. T43_BRANCH_BALANCE_RESPONSE_ASSOCIATION is identified.

Otherwise B is not promoted as the missing invariant.
