# v0.5 T73 — Exact One-Step Transition-Drift Audit Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T72.  
**Purpose:** determine whether the constrained T47 swap kernel has an intrinsic one-step drift away from the exact T25 parent in the same coordinates that became one-sided after T70/T71 burn-in.

## 1. Parent matrix

Use exactly the T70–T72 parents:

N = 4096  
seeds = {1571, 1601, 1627}.

M3 and M7 are forbidden.

## 2. Frozen state coordinates

For each structurally valid one-swap move compute exact increments

d = (Delta A1, Delta A2, Delta A3, Delta C_KR),

with the same definitions and exact T70 bands used in T72.

T72 established that every structurally valid one-swap move from each exact parent remains inside all four bands. Therefore, at the parent, the constrained Stage-B kernel accepts every structurally valid proposal.

## 3. Proposal kernel

The T47/T69–T71 kernel samples two distinct children uniformly and swaps their parents when the recursive-order constraints remain valid.

T73 exhaustively enumerates all unordered child pairs a<b and classifies the proposal as:

- invalid/rejected structurally; or
- valid/accepted structurally.

Because each unordered pair has equal proposal weight, the exact conditional accepted-step drift is the uniform mean of d over all valid pairs.

Also report the unconditional proposal drift, counting structurally invalid proposals as zero increments.

## 4. Frozen directional prediction

T70/T71 repeatedly moved toward:

- A1 smaller than the exact parent;
- C_KR less negative than the exact parent.

T72 showed both opposite directions are locally reachable, but sign counts already favored A1-down and C-less-negative moves.

Therefore T73 freezes, before computing magnitude-weighted means:

mean(Delta A1 | valid) < 0

and

mean(Delta C_KR | valid) > 0

for all three parents.

No direction is frozen for A2 or A3; they are descriptive only.

## 5. Primary outputs

For each seed report:

- total unordered proposals;
- structurally valid proposals;
- valid fraction;
- conditional accepted-step mean Delta A1, A2, A3, C_KR;
- unconditional proposal mean increments;
- standard deviation of each valid-step increment;
- covariance and correlation between Delta A1 and Delta C_KR;
- sign fractions:
  - Delta A1 > 0 / < 0;
  - Delta C_KR < 0 / > 0;
  - joint Delta A1>0 and Delta C_KR<0.

## 6. Frozen classification

T73_DRIFT_MATCHES_T70_T71 = IDENTIFIED only if, for all three seeds:

mean(Delta A1 | valid) < 0

and

mean(Delta C_KR | valid) > 0.

If one or more seeds fail, the transition-drift explanation is not identified.

## 7. Interpretation boundary

A PASS would show that the exact accepted-swap kernel itself has a local entropic/transition drift in the same direction as the T70/T71 one-sided support.

It would not prove the long-run stationary distribution or global mixing behavior.

It would also show that the T70/T71 bracketing failure can arise even though opposite directions are locally reachable.

No physical interpretation is permitted.
