## 2. Discrete domain of dependence

Let a local update at nodule v depend only on a declared relational neighborhood N(v). For nearest-neighbor radius-one updates on a chain/ring, information entering x_{k+1}(v) can originate at most from one graph edge farther away per microscopic update, plus the second-order local state inherited from k-1.

After r updates, the dependency set is contained in the graph ball

B_r(v) = {u : d_G(u,v) <= r},

where d_G is graph distance induced by the primitive relation structure.

Thus the rule itself supplies a finite discrete domain of dependence:

influence outside B_r(v) cannot affect v after only r local updates.

This is a causal-order precursor and does not require a metric length in meters.

## 3. Resolutive causal order

Define an event provisionally as

E=(v,k),

where k is update order, not physical time.

Write

E1 <=_R E2

if the state at E1 can enter the dependency ancestry of E2 under the transition law.

This relation is transitive by composition of dependencies. For a deterministic acyclic update ordering it is antisymmetric at the event level after quotienting identical event labels.

Therefore a partial-order-like causal structure can be defined from dependency alone.

## 4. Discrete cone

For radius-one propagation in one relational dimension, an event (v0,k0) can influence only events satisfying

|Delta j| <= Delta k

in lattice coordinates.

The boundary

|Delta j| = Delta k

is the discrete maximum-propagation front.

This is a combinatorial cone. It is not yet a Lorentzian null cone because j and k do not yet carry physical distance/time units.

## 5. Two-step D13-A subtlety

D13-A is second order in update index. Its complete state is `(x_{k-1},x_k)`. Dependency propagation remains finite because both inherited and newly coupled information are local. The doubled state does not permit super-neighborhood jumps.

Hence exact microscopic reversibility is compatible with a bounded dependency cone.

## 7. Cone survives coarse-graining

Because z=1 requires Delta tau_R proportional to a, both the spatial relational resolution and relational clock increment shrink linearly. Their ratio stays finite.

Therefore a nondegenerate cone can survive the continuum limit:

Delta xi / Delta tau_R = finite.

By contrast, a z=2 diffusive scaling Delta tau_R ~ a^2 gives a/Delta tau_R ~ a^-1, so the microscopic graph-neighbor bound expressed in those rescaled coordinates diverges. This is consistent with diffusion equations lacking a finite propagation cone.

Thus finite-speed causal-cone behavior is naturally aligned with the z=1 class, not with every continuum class.

## 8. Anisotropic interactions

In more than one relational direction, suppose first-order interactions have direction-dependent coefficients g_i. The characteristic set need not be isotropic.

A schematic second-order equation may take

partial_tau^2 q = sum_ij C^{ij} partial_i partial_j q,

with positive spatial principal matrix C in a stable hyperbolic sector.

The cone is then determined by C, and different directions can have different characteristic speeds.

Therefore isotropy is an additional property to derive/test; it is not guaranteed by relational locality alone.

## 9. Multiple species/modes

Different relational modes may possess different characteristic coefficients. Then there may be nested cones rather than a unique universal cone.

A single universal limiting cone requires an additional universality mechanism, symmetry or infrared fixed point causing the relevant sectors to share the same characteristic structure.

T24 does not derive such universality.

## 10. From cone to conformal structure

In continuum Lorentzian geometry, a sufficiently regular null-cone structure determines the metric only up to a positive conformal factor under standard assumptions.

Accordingly, if the emergent Resolutive continuum possesses a smooth universal cone field, the strongest immediate geometric object justified is a conformal Lorentzian class

not a fully normalized metric.

T24 records this as a conditional bridge, not as a derivation of physical spacetime.
