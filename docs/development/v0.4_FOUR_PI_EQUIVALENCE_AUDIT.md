# v0.4 4π Equivalence Audit

**Status:** WORKING RESULT — ISSUE #85

## Question

Does the representation

```text
Psi = sqrt(rho) exp(i Theta/2)
```

establish a physically new `4pi` periodicity, or is `Theta` only a doubled coordinate for an ordinary `2pi` phase?

## 1. Exact coordinate map

Define

```text
phi := Theta/2.
```

If `Theta` is identified modulo `4pi`, then `phi` is identified modulo `2pi`:

```text
Theta in R/(4pi Z)  <->  phi in R/(2pi Z).
```

The map

```text
[Theta]_(4pi) -> [Theta/2]_(2pi)
```

is bijective and smooth, with smooth inverse

```text
[phi]_(2pi) -> [2 phi]_(4pi).
```

Therefore the bare phase spaces `R/(4pi Z)` and `R/(2pi Z)` are diffeomorphic circles. A `4pi` coordinate range alone does not create a new topology.

Classification: **D — derived mathematical equivalence**.

## 2. Transformation law

From the representation,

```text
Psi(Theta + 2pi) = -Psi(Theta)
Psi(Theta + 4pi) =  Psi(Theta).
```

Equivalently, in the ordinary phase coordinate,

```text
Psi(phi + pi)  = -Psi(phi)
Psi(phi + 2pi) =  Psi(phi).
```

Thus the sign change after a `2pi` shift in `Theta` is exactly the ordinary sign change after a `pi` shift in the conventional phase `phi`.

This transformation law is real algebraic content, but by itself it is not evidence for a new physical periodicity.

## 3. Kinetic-sector equivalence

For

```text
Psi = sqrt(rho) exp(i Theta/2),
```

direct differentiation gives

```text
partial_mu Psi = exp(i Theta/2)
                 [ (partial_mu rho)/(2 sqrt(rho))
                   + i sqrt(rho) (partial_mu Theta)/2 ].
```

Hence, up to the chosen metric contraction/sign convention,

```text
|partial Psi|^2
= (partial rho)^2/(4 rho)
  + rho (partial Theta)^2/4.
```

With `phi = Theta/2`, the same expression is

```text
|partial Psi|^2
= (partial rho)^2/(4 rho)
  + rho (partial phi)^2.
```

Therefore the current `(rho,Theta)` kinetic sector is exactly the polar decomposition of an ordinary complex scalar kinetic term. No new dynamics follows from the half-angle notation alone.

Classification: **D — equivalent reparametrization for this sector**.

## 4. Why a sign-sensitive observable is not sufficient by itself

Suppose an observable is sensitive to the sign of `Psi` relative to a reference field `R`, for example through an interference term

```text
O = Re(R* Psi).
```

Then `O[-Psi] = -O[Psi]` when `R` is fixed.

However this still does not distinguish a genuinely `4pi` theory from an ordinary `2pi` complex phase theory. In the coordinate `phi=Theta/2`, the same effect is simply a relative phase shift `phi -> phi + pi`.

Therefore an observable satisfying `O[Psi] != O[-Psi]` is necessary only if the project claims the two signs are distinct; it is **not sufficient** to establish new `4pi` physics.

A valid discriminator must depend on additional structure that cannot be removed by the field redefinition `phi=Theta/2`.

## 5. Current gate result

For the presently specified state content

```text
(rho, Theta, chi, n)
```

with no independently defined layer bundle, discrete sector, holonomy, or transition operator, the correct classification is:

```text
PARAMETRIZATION_ONLY_4PI
```

This result applies to the **current formulation only**. It does not prohibit a future physical `4pi` structure. It states that such a structure has not yet been supplied by the existing variables and half-angle representation.

## 6. What would be required for nontrivial 4π physics

At least one independent mathematical ingredient must be added and justified upstream of data fitting. Acceptable classes include, but are not limited to:

1. **Independent layer state**
   - state space `M x L` with nontrivial `L`;
   - explicit transition map between layer states;
   - a `2pi` operation that changes the physical layer state and a `4pi` operation that restores it.

2. **Nontrivial bundle/connection**
   - base space and fiber explicitly declared;
   - connection or transport law defined;
   - closed transport with a nontrivial holonomy after the first cycle;
   - holonomy not removable by a global coordinate redefinition.

3. **Discrete internal degree of freedom**
   - e.g. a physical `Z2` label independent of `Psi`;
   - transformation law coupling `Theta -> Theta + 2pi` to the label;
   - measurable consequence of the label.

4. **Topological obstruction**
   - state space whose relevant loops cannot be reduced to the ordinary scalar `U(1)` description;
   - explicit fundamental-group/covering argument;
   - an observable tied to the nontrivial class.

Merely declaring `Theta` to range over `4pi`, or calling the construction a double cover, is not enough.

## 7. Strongest candidate consistent with the project intuition

The horizontal/vertical intuition can be translated into a testable mathematical hypothesis without yet claiming it is true.

Introduce a layer variable

```text
ell in Z2 = {0,1}
```

and a candidate half-cycle transition operator

```text
T_2pi : (Theta, ell) -> (Theta + 2pi, ell xor 1).
```

Then

```text
T_2pi^2 : (Theta, ell) -> (Theta + 4pi, ell),
```

so the full state closes only after two applications.

This construction creates a genuine two-step state evolution **only if `ell` is an independently physical degree of freedom** and cannot be absorbed into the phase coordinate or a gauge redundancy.

Classification at entry: **C/P — candidate model, not accepted physics**.

## 8. Falsifiable discriminator required before promotion

A future `POSTULATED_4PI_WITH_OBSERVABLE` model must preregister an observable `Q` for which:

```text
Q after one T_2pi cycle != Q at the initial state,
Q after two T_2pi cycles = Q at the initial state,
```

while an otherwise matched conventional `2pi` baseline does not reproduce the same state-transition pattern without adding an equivalent hidden degree of freedom.

The comparison must count all independent state variables and parameters symmetrically.
