# v0.5 T52 — Representation-Refinement No-Go and Linear-Circuit Equivalence

**Status:** ANALYTICAL RESULT / FROZEN  
**Parent:** T51. **Scope:** separate objective physical entities from arbitrary graph discretization.

## 1. Question

Does an unweighted graph statistic define an operational physical observable if it changes when a conventional physical element is subdivided into series components while retaining exactly the same terminal response?

Answer: not without additional physical ontology and a justified coarse-graining prescription.

## 2. Exact subdivision construction

Let an edge e={a,b} of a simple tree be replaced by the path

a -- x -- b,

with one newly introduced degree-two vertex x and no other incidence changes.

For all original vertices v,

d_new(v)=d_old(v),

and d_new(x)=2.

The global wedge statistic

W(G)=sum_v binom(d(v),2)

obeys

W(G_new)=W(G_old)+1.

In a tree, sum_v |S_2(v)|=2W(G); hence the total second-shell population rises by exactly 2.

Individual second-shell values and graph distances can also change.

Therefore W and the unnormalized second-shell sum are not invariant under this refinement.

## 3. Conventional circuit-equivalent physical realization

Give the original edge a fixed resistance R_e>0. In the subdivided circuit choose

R_ax>0, R_xb>0, R_ax+R_xb=R_e.

The new interior point x has no current injection, leakage, shunt or independent sensing load.

KCL at x gives equal series current, so the port relation between a and b is exactly

I_ab=(V_a-V_b)/(R_ax+R_xb)
    =(V_a-V_b)/R_e.

Consequently every original-node voltage/current relation and every external terminal response, including effective resistance, is unchanged by this series subdivision.

This is an exact network reduction, not an approximation.

## 4. Elementary counterexample

Original path:

a -- b -- c

with R_ab=R_bc=1 ohm.

Degrees: (1,2,1).
W_old=1.
Two-terminal R_ac=2 ohm.

Replace R_ab by two series resistors of 0.5 ohm each:

a -- x -- b -- c.

Degrees: (1,2,2,1).
W_new=2.
Two-terminal R_ac=2 ohm.

At the original center b, |S_2(b)| changes from 0 to 1 although its degree remains 2.

There is no change in two-terminal conventional physics despite the change in W and L_2.

## 5. General linear-circuit equivalence

For an ordinary reciprocal, passive, linear resistive network in which every edge obeys the local law I_e=g_e Delta V_e with g_e>0,

I_ext=B diag(g_e) B^T V=L_g V.

Any proposed *static linear correction* that simply changes each edge coefficient,

I_e=[g_e+delta g_e] Delta V_e,

is exactly an ordinary weighted-resistor network with measured effective edge conductances g_e'=g_e+delta g_e, provided g_e'>0.

Its terminal response alone cannot identify a distinct interaction beyond conventional conductance change.

This statement covers this restricted local reciprocal class only; it is not a no-go theorem for all possible physical theories.

## 6. Operational admissibility gate

A physical mapping based on a relational graph must specify one of:

(a) **objective node ontology:** each node is independently identifiable as a physical entity that cannot be inserted by convention, with a test showing which entities are counted;

(b) **representation-invariant observable:** the predicted measurable quantity does not change under equivalent subdivision/coarse-graining;

(c) **physical refinement dynamics:** an inserted node is a new physical object with specified additional degrees of freedom and a measurable consequence beyond ordinary series resistance.

A graph-only observable that changes under circuit-equivalent subdivision without any of (a)-(c) cannot be promoted as universal physical energy, density, distance or current.

## 7. Scientific consequence for T25–T49

The T49 regulator is a valid graph-construction mechanism. Its local topology quantities need not be invariant under arbitrary graph subdivision because the model explicitly specifies its node set and birth process.

But this does **not** give an automatic physical map.

M3, M7, W, L2 and graph radius may depend on how a physical system is graphically discretized. Their physical meaning needs its own experimentally defensible ontology and coarse-graining.

## 9. Next step

A candidate physical postulate must (i) identify objective physical entities, (ii) carry correct units and symmetries, (iii) survive the relevant representation-equivalence tests, and (iv) deliver a preregistered prediction outside the specified conventional comparator.
