# v0.5 T39 — Higher-Order Topology Source Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T38. **New dynamics:** none.

## 1. Question

Which coordinate-free higher-order tree property, if any, tracks the two stable T38 departures

```text
M3 = median nu_4 for 4->8
M7 = mean existing-edge D_J at R=8
```

after exact control of N, tree class and full labeled-node degree sequence?

T39 is a source-diagnostic audit. It does not introduce a physical geometry or a dynamical law.

## 2. Parent and null ensemble

Reuse exactly the T38 ensemble:

- 9 frozen T25 parent trees;
- N in {128,256,512};
- parent seeds in {11,23,47};
- 99 Prüfer-randomized degree-sequence-matched labeled-tree nulls per parent;
- the same deterministic null seeds as T38.

No new null family is selected after execution.

## 3. Frozen topology diagnostics

For each parent and every null compute exactly the following coordinate-free graph quantities.

### H1 — Diameter

```text
H1 = max_{u,v} d(u,v)
```

### H2 — Mean pairwise graph distance

```text
H2 = mean_{u<v} d(u,v)
```

### H3 — Mean eccentricity

```text
H3 = mean_v max_u d(v,u)
```

### H4 — Degree assortativity

Pearson correlation of endpoint degrees over the symmetrized directed edge list

```text
(u,v), (v,u)
```

for every undirected edge {u,v}.

### H5 — Mean maximal branch-segment length

A branch segment is a maximal simple path whose internal vertices have degree 2 and whose endpoints have degree != 2.

```text
H5 = mean segment edge count.
```

### H6 — Maximum branch-segment length

```text
H6 = max segment edge count.
```

### H7 — Maximum normalized node betweenness

For a tree, remove node v and let the resulting component sizes be s_i. Define

```text
b(v) = [sum_{i<j} s_i s_j] / C(N-1,2).
```

Then

```text
H7 = max_v b(v).
```

### H8 — Gini concentration of normalized betweenness

```text
H8 = Gini({b(v)}).
```

No additional topology diagnostic may be added after execution.

## 4. Joint T38 target

Within each parent-specific null ensemble, standardize M3 and M7 using null mean and null standard deviation:

```text
z3 = (M3 - mean_null(M3)) / sd_null(M3)
z7 = (M7 - mean_null(M7)) / sd_null(M7).
```

Define the preregistered joint high-radius departure score

```text
Z_37 = (z3 + z7)/2.
```

For null-tree correlation analysis, each null replicate receives its own z3, z7 and Z_37 using the same parent-specific null means and standard deviations.

Z_37 is a diagnostic composite only; it is not a physical observable.

## 5. Diagnostics

For every H1..H8 and every parent ensemble report:

1. parent value;
2. null mean, standard deviation, q025, median and q975;
3. parent null percentile;
4. Spearman correlation rho(Hj, M3) across the 99 nulls;
5. Spearman correlation rho(Hj, M7) across the 99 nulls;
6. Spearman correlation rho(Hj, Z_37) across the 99 nulls.

No regression model is fitted.

## 6. Stable source-candidate gate

A topology diagnostic Hj is classified

```text
T39_STABLE_SOURCE_CANDIDATE
```

only if all of the following hold:

1. the parent Hj lies strictly outside the central 95% null interval in the **same direction for all 9 parents**;
2. rho(Hj,Z_37) has the **same nonzero sign in all 9 null ensembles**;
3. median over the 9 ensembles of |rho(Hj,Z_37)| is >= 0.50;
4. rho(Hj,M3) and rho(Hj,M7) have the same sign as rho(Hj,Z_37) in at least 8 of 9 ensembles each.

The 0.50 threshold is frozen before execution as a deliberately strong effect-size requirement; it is not a significance test.

If no Hj satisfies all four conditions:

```text
T39_STABLE_SOURCE_CANDIDATE = NONE_IDENTIFIED
```

and the higher-order source remains distributed or unmeasured by H1..H8.

## 7. Multiple-candidate rule

If more than one Hj passes, T39 does not select a winner.

All passing candidates are retained as a correlated structural family for a later conditional audit.

No ranking is constructed post hoc.
