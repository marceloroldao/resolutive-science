## 2. Exact modal dynamics

For one eigenmode of the relational operator,

`L phi = lambda phi`,

D13-A becomes

`q_{k+1} = q_{k-1} + mu q_k`,

where

`mu = c lambda`.

Equivalently,

`q_{k+1} - mu q_k - q_{k-1} = 0`.

The characteristic equation is

`r^2 - mu r - 1 = 0`,

with

`r_+ r_- = -1`.

The two branches therefore do not merge into a conventional same-sign near-identity pair. At `mu -> 0`, the roots approach `+1` and `-1`.

This is the algebraic origin of the one-step swap sector found in T18.

## 3. Two-step branch decomposition

Write the one-step lifted map

`M(mu) = [[0,1],[1,mu]]`.

Then

`M(mu)^2 = [[1,mu],[mu,1+mu^2]]`.

For small `mu`,

`M^2 = I + mu S + O(mu^2)`,

with

`S = [[0,1],[1,0]]`.

Thus after two microscopic updates the paired state does admit a near-identity continuum generator.

If

`mu(a) = c lambda(a) ~ c C a^z`

and

`Delta tau_R = kappa a^z`,

then formally

`partial_tau Psi = g K_z S Psi`,

where

`Psi=(q,p)^T`, `g=c/(2 kappa)` up to the precise two-step clock convention, and `K_z` is the continuum relational operator.

The key matrix `S` has real eigenvalues `+1,-1`.

## 4. Diagonal branches

Define

`u_+ = (q+p)/sqrt(2)`,

`u_- = (q-p)/sqrt(2)`.

Then the leading continuum system diagonalizes:

`partial_tau u_+ = + g K_z u_+`,

`partial_tau u_- = - g K_z u_-`.

Therefore the reversible completion contains paired forward/backward exponential branches rather than a generic oscillatory pair.

For a symmetric Laplacian-like `K_2 = partial_x^2`, one branch is diffusion-like and the other is anti-diffusion-like.

The full pair retains algebraic reversibility, but generic initial data includes an unstable coarse branch.

## 5. Second-order elimination

From

`partial_tau q = g K_z p`,

`partial_tau p = g K_z q`,

eliminate `p`:

`partial_tau^2 q = g^2 K_z^2 q`.

Similarly,

`partial_tau^2 p = g^2 K_z^2 p`.

For `K_2 = partial_x^2`,

`partial_tau^2 q = g^2 partial_x^4 q`,

which is not the ordinary wave equation.

For an antisymmetric first-order operator `K_1 = partial_x`,

`partial_tau^2 q = g^2 partial_x^2 q`.

This has the algebraic form of the 1+1 wave equation:

`partial_tau^2 q - g^2 partial_x^2 q = 0`.

Thus a wave-like sector emerges conditionally from the **z=1 antisymmetric interaction class**, not from the symmetric Laplacian class.

## 7. Stability classification

Consider Fourier modes with `K_z -> sigma_z(k)`.

The paired generator has eigenvalues

`omega_±(k) = ± g sigma_z(k)`.

If `sigma_z(k)` is real, the branches are real exponential growth/decay.

If `sigma_z(k)` is purely imaginary, the branches are oscillatory/unit-modulus in the continuum approximation.

Hence:

`REAL SPECTRUM -> hyperbolic-in-state growth/decay pair`

`IMAGINARY SPECTRUM -> oscillatory/stable pair`

The z=1 antisymmetric derivative has `sigma_1(k)=ik`, so it gives oscillatory Fourier evolution and a wave-like second-order equation.

The symmetric Laplacian has `sigma_2(k)=-k^2`, so it gives paired decay/growth branches.

## 8. Quadratic invariant

For the paired continuum equations

`q_tau = g K p`,

`p_tau = g K q`,

suppose `K` is skew-adjoint under the selected inner product:

`K^† = -K`.

Then

`I_+ = ||q||^2 + ||p||^2`

satisfies

`d I_+/d tau = 0`.

Proof:

`d/dtau (||q||^2+||p||^2) = 2g(<q,Kp>+<p,Kq>) = 0`

for real fields with suitable boundary conditions.

For self-adjoint `K`, the indefinite form

`I_- = ||q||^2 - ||p||^2`

is conserved:

`d I_-/d tau = 2g(<q,Kp>-<p,Kq>) = 0`.

Thus reversibility/symmetry supplies quadratic invariants, but their positivity depends on the operator class.

T23 does **not** name either invariant energy.

## 9. Important distinction: invariant versus energy

A conserved quadratic form becomes a candidate energy only after additional physical structure identifies:

- the relevant clock-translation generator;
- units/dimensions;
- positivity/boundedness conditions;
- observable coupling/work interpretation or equivalent operational meaning.

Therefore:

`CONSERVATION != ENERGY IDENTIFICATION`.

## 13. Main consequence

The reversible D13-A continuum completion is not generically a wave equation. The interaction symmetry class decides the behavior.

`D13-A + antisymmetric z=1 relational interaction -> paired reversible first-order system -> second-order wave-like equation`.

This prevents an unjustified jump from microscopic reversibility to ordinary wave dynamics.
