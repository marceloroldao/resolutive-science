## 1. Question

Are the T35 Euclidean subspace diagnostics properties of the underlying relational neighborhoods, or do they depend on the coordinate representation chosen for the same information?

T35 used the cumulative ball profile

```text
B_R(v)_k = |{u : d(v,u) <= k}| / N,
k = 0,...,R.
```

T36 compares it with the exact-shell profile

```text
S_R(v)_k = |{u : d(v,u) = k}| / N,
k = 0,...,R.
```

No new graph information is introduced.

## 2. Exact information equivalence

For every v,

```text
B_k = sum_{j=0}^k S_j
S_0 = B_0
S_k = B_k - B_{k-1},  k>=1.
```

Thus B_R and S_R are related by an invertible lower-triangular linear map.

They contain exactly the same finite-radius information.

This identity is fixed before execution.

## 3. Why the audit is physically necessary

The T35 quantities

- principal angles;
- Frobenius power;
- projection residual;

use the Euclidean inner product of profile-coordinate space.

A general invertible change of coordinates preserves information but does not preserve Euclidean angles or norms.

Therefore, if T35 classifications depend materially on choosing B_R instead of S_R, the current profile-space metric is not representation independent and cannot yet be promoted to physical local geometry.

No preferred internal metric is postulated in T36.
