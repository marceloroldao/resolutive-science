# v0.5 T38 — Degree-Matched Tree Null Specificity Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T37. **New dynamics:** none.

## 1. Motivation

The frozen T25 generator produces connected graphs with exactly N-1 edges.

Construction:

- one edge is created between nodules 0 and 1;
- every later nodule is attached by exactly one new edge to an earlier nodule;
- no additional edge is created for that nodule.

Therefore every frozen T25 graph is a tree.

This means the coordinate-free multiscale structure found in T37 may be generic to sparse trees or to the parent degree sequence rather than specific to the T25 relational construction.

T38 tests that possibility before any physical interpretation.

## 2. Null ensemble

For each frozen parent graph separately:

- retain N exactly;
- retain every labeled-node degree exactly;
- retain connected-tree topology class;
- destroy the parent higher-order adjacency arrangement.

For a tree with degree sequence d_i, the Prüfer multiset contains label i exactly d_i-1 times.

A degree-matched null tree is generated by:

1. constructing that exact Prüfer multiset;
2. uniformly shuffling it;
3. decoding the shuffled Prüfer sequence.

Thus every null tree has exactly the parent degree sequence.

No geometry, coordinates, target dimension or dynamics are used.

## 4. Frozen T37 summary statistics

For parent and every null tree compute exactly these seven statistics:

### Scale innovation

```text
M1 = median nu_1   for 1->2
M2 = median nu_2   for 2->4
M3 = median nu_4   for 4->8
```

where

```text
nu_R(v) = 1 - |B_R(v)|/|B_2R(v)|.
```

### Existing-edge neighborhood contrast

```text
M4 = mean D_J at R=1
M5 = mean D_J at R=2
M6 = mean D_J at R=4
M7 = mean D_J at R=8.
```

No statistic is added after execution.

## 5. Per-parent null comparison

For every metric Mj report:

- parent value;
- null mean;
- null standard deviation;
- null q025;
- null median;
- null q975;
- empirical percentile/rank of the parent.

A parent value is called an **extreme null departure** only if it lies strictly outside the empirical central 95% null interval [q025,q975].

This conventional interval is fixed before execution.

## 6. Gates

### T38_DEGREE_SEQUENCE_CONTROL

PASS only if every null tree exactly matches the full parent degree sequence.

### T38_TREE_CLASS_CONTROL

PASS only if every null is connected and has N-1 edges.

### T38_STABLE_GENERATOR_SPECIFICITY

IDENTIFIED only if at least one preregistered metric M1..M7 is an extreme null departure in the **same direction** for all 9 parent graphs.

This deliberately strong gate prevents isolated seed/size deviations from being promoted.

If no metric satisfies that rule:

```text
T38_STABLE_GENERATOR_SPECIFICITY = NOT_IDENTIFIED
```

and the degree-matched tree null explanation remains viable.

### T38_T37_PHYSICAL_SPECIFICITY

Remains NOT_DERIVED regardless of outcome. Even generator-specific structure would still need a physical mapping and empirical discriminator.

## 7. Forbidden

- no target physical dimension;
- no null generator selected after seeing results;
- no rewiring that changes degree sequence;
- no profile-space metric;
- no graph evolution;
- no transition law;
- no cosmological/galactic target data;
- no physical claim from a single extreme comparison.
