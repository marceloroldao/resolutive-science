# v0.5 T16 — Infinitesimal Commutator Bridge Results

**Status:** theory-only computational/mathematical consistency result  
**Physical validation:** NONE

## Setup

Use two independently chosen nilpotent noncommuting generators

```text
A = [[0,1],[0,0]]
B = [[0,0],[1,0]]
[A,B] = [[1,0],[0,-1]].
```

Because A^2=B^2=0, the near-identity maps are exact:

```text
exp(e A)=I+eA,
exp(e B)=I+eB.
```

Define the small commutator loop

```text
H(e)=exp(eA) exp(eB) exp(-eA) exp(-eB).
```

The tested quantity is

```text
K(e)=(H(e)-I)/e^2.
```

## Results

Direct execution gives the following Frobenius-norm errors relative to `[A,B]`:

| epsilon | ||H-I||_F | ||K-[A,B]||_F |
|---:|---:|---:|
| 1e-1 | 1.428320692e-2 | 1.417744688e-1 |
| 5e-2 | 3.544367230e-3 | 7.075485849e-2 |
| 2e-2 | 5.659116765e-4 | 2.828709953e-2 |
| 1e-2 | 1.414354980e-4 | 1.414248917e-2 |
| 5e-3 | 3.535622294e-5 | 7.071112006e-3 |
| 2e-3 | 5.656876877e-6 | 2.828429953e-3 |
| 1e-3 | 1.414214977e-6 | 1.414213916e-3 |

The scaled error decreases approximately linearly with epsilon, as expected from the first neglected commutator corrections. Therefore

```text
(H(e)-I)/e^2 -> [A,B]
```

for this test family.

A commuting control using A with itself gives identity loop up to floating arithmetic.

## Interpretation

T16 establishes a clean mathematical bridge:

```text
near-identity reversible transformations
-> noncommuting closed loop
-> O(epsilon*delta) loop defect
-> generator commutator in the infinitesimal limit.
```

This is precisely the algebraic ingredient required by the commutator part of a continuum curvature expression.

It does **not** yet derive the full curvature

```text
F = dA + A wedge A
```

from the D13 foundational dynamics. The derivative/inhomogeneous `dA` contribution requires generators that vary over a relational base and a controlled discrete-to-continuum comparison between neighboring locations/directions.
