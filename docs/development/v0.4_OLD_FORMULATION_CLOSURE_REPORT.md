# v0.4 Old Formulation — Closure Report

**Status:** CONSOLIDATED NEGATIVE / DIAGNOSTIC CLOSURE  
**Scope:** old RSMS formulation only  
**Target-data retuning:** forbidden and not used  
**New relational formulation:** not introduced in this report

## 1. Purpose

This document closes the current audit cycle of the old formulation before any new fundamental formulation is introduced.

The question was deliberately narrow:

> Can the mathematical structures already present in the current RSMS uniquely select a fundamental Resolutive dynamics without importing a new physical postulate or tuning against target data?

The answer from the completed structural audit is **no**.

This is a negative scientific result, not a deletion of the framework. RSMS remains useful as a specification/state architecture, but the audited structures do not uniquely determine a Master Equation.

The normative RSMS primitive state is

```text
R = (rho_R, Theta_R, iota_R, kappa_R).
```

```text

Psi = sqrt(rho_R) exp(i phi_R)
```

produces a conventional complex-scalar polar representation for the audited `(rho_R,phi_R)` core.

Current classification remains:

```text
FOUR_PI_STATUS = PARAMETRIZATION_ONLY_4PI
NOVELTY_(rho_R,phi_R) = EQUIVALENT_REPARAMETRIZATION
```

No physical 4pi law is inferred from the coordinate period alone.

## 6. What has been ruled out

The audit rules out the following claims **within the current specification**:

1. that writing `Theta_R` on a 4pi coordinate circle by itself derives new physical 4pi behavior;
2. that the polar complex-field kinetic identity is a new Resolutive dynamical law;
3. that the mere existence of a bundle or connection derives physical transport;
4. that a generic action principle uniquely determines the Resolutive action;
5. that a generic symmetry framework supplies a new physical conservation law without selecting a physical symmetry;
6. that generic determinism/reversibility/composition uniquely selects a state-transition law;
7. that the word `coherence` by itself defines a measurable extremal functional;
8. that `iota_R` or `kappa_R` currently possess uniquely derived dynamics or observable maps.

## 7. What has NOT been ruled out

The negative closure does **not** show that:

- no future Resolutive theory can exist;
- variational dynamics can never be used;
- nontrivial topology or holonomy can never be physical;
- coherence can never become an operational quantity;
- iota_R or kappa_R can never acquire physical definitions;
- a new independently motivated principle cannot select a dynamics;
- a future relational formulation is false.

Those are separate hypotheses requiring separate specifications and tests.
