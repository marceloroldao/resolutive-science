# v0.4 Connection / Transport Invariant Audit

**Status:** WORKING NEGATIVE/UNDERDETERMINED RESULT — ISSUE #84

## Question

Can the bundle/connection framework already admitted by RSMS derive a non-conventional physical role for `iota_R` or `kappa_R` without adding arbitrary post-fit structure?

## 1. What RSMS actually supplies

RSMS admits a resolutive state bundle

```text
pi_M : E_R -> M
```

with typical fiber `R`, and it defines the mathematical vocabulary for:

- bundle transition functions;
- a structure group `G_R` if a specialization declares one;
- an Ehresmann or covariant connection;
- parallel transport;
- connection curvature;
- holonomy/path dependence.

But RSMS explicitly does **not** choose a physical connection, structure group, topology, transport law or dynamical principle.

Therefore the existence of this vocabulary is not itself a physical derivation.

## 2. Product-bundle null

The minimal untwisted RSMS representation allows

```text
E_R = M x R.
```

On a product bundle, the bundle topology alone does not force a nontrivial holonomy or layer transition. A trivial connection is admissible.

Hence:

```text
BUNDLE_EXISTENCE ->/= NONTRIVIAL_TRANSPORT
```

and

```text
PRODUCT_RSMS_BUNDLE_DOES_NOT_DERIVE_4PI
```

## 3. Phase/U(1) connection test

The already audited phase sector may be written as a conventional `U(1)` phase degree of freedom. If one introduces a principal `U(1)` connection `A`, the standard covariant derivative is of the form

```text
D_mu Psi = (partial_mu - i q A_mu) Psi
```

with curvature

```text
F = dA
```

in the Abelian case, and loop transport produces conventional `U(1)` holonomy.

This is a mathematically valid nontrivial transport sector, but it is standard gauge-field structure. It does not become Resolutive novelty by relabeling the connection or the holonomy.

Result:

```text
U1_CONNECTION_NOVELTY = NO
```

unless a new independently motivated coupling, constraint or observable relation is added and shown inequivalent to conventional gauge theory.

## 4. General internal-connection test

One can instead choose a larger structure group acting on the full internal state.

But before such a choice the theory is massively underdetermined:

```text
choose G_R
choose representation of G_R on R
choose connection
choose curvature
choose coupling to state
choose action/evolution law
choose observable projection
```

Different choices generate different theories. RSMS does not select one.

Therefore an arbitrary non-Abelian or multi-component connection cannot be called a derivation from the four-component state alone.

Result:

```text
GENERAL_CONNECTION_ROUTE = UNDERDETERMINED
```

## 5. Can kappa_R be connection curvature?

A tempting mapping is to identify `kappa_R` with a scalar derived from the connection curvature, for example schematically

```text
kappa_R ?= K(F_nabla).
```

This is currently not derived. It also creates a specification tension:

- RSMS treats `kappa_R` as a primitive scalar coordinate;
- connection curvature is derived from a separately chosen connection;
- making `kappa_R = K(F_nabla)` would make at least part of `kappa_R` derived from additional geometric structure.

The mapping can be introduced only as a future explicit RSMS specialization/revision. It cannot be silently assumed in the v0.4 Master Equation.

Result:

```text
KAPPA_FROM_CONNECTION_CURVATURE = OPEN_POSTULATE, NOT DERIVED
```

## 6. Can iota_R be a transport angle?

A second tempting mapping is to define `iota_R` as a relative inclination/angle between states under parallel transport.

But an angle requires at least:

- an internal metric or pairing;
- two comparable state directions/objects;
- a transport rule to compare them across fibers;
- an equivalence convention.

None is selected by RSMS.

Therefore:

```text
IOTA_FROM_TRANSPORT_ANGLE = OPEN_POSTULATE, NOT DERIVED
```

## 7. Holonomy and the earlier 4pi hypothesis

Nontrivial holonomy can produce a state change after transport around a closed loop. However an arbitrary holonomy can realize many groups and periods.

To obtain the specific pattern

```text
one loop  -> distinct physical state
two loops -> original state
```

one must choose a connection/representation with a corresponding order-two action or lifted structure.

That is exactly the extra structure the earlier `4pi` audit found missing. The generic bundle language does not select it.

Therefore:

```text
HOLONOMY_CAN_MODEL_TWO_STEP_CLOSURE = YES
HOLONOMY_DERIVES_RESOLUTIVE_4PI     = NO
```

## 8. Observable discriminator requirement

Any future transport extension must be compared against the nearest conventional bundle/gauge baseline of equal complexity.

Before target data, it must freeze:

1. base and fiber;
2. structure group;
3. connection and curvature convention;
4. representation on the state;
5. all couplings;
6. loop/path preparation;
7. an invariant observable `Q`;
8. a null/conventional comparator.

A valid Resolutive discriminator must not disappear under gauge choice, coordinate change, trivialization or field redefinition.
