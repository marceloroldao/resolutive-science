## 1. Purpose

T1 classified the minimal state-transition structure as category-like and identified, for each Resolutive state `A`, the endomorphism monoid

```text
End_R(A) = Hom_R(A,A)
```

of closed Resolutive trajectories.

T2 asks what can distinguish nonidentity loops algebraically, before adding topology, continuity, phase, winding, energy, time, metric or legacy 2pi/4pi structure.

## 2. Loop monoid

For a fixed state `A`, define

```text
L_A := End_R(A).
```

For `alpha,beta in L_A`, composition is closed:

```text
beta o alpha in L_A.
```

There is an identity

```text
e_A := I_A.
```

Associativity holds by T1.

Therefore

```text
(L_A, o, e_A)
```

is a monoid.

This alone permits nonidentity loops:

```text
alpha != e_A.
```

No numerical invariant is required to state this algebraic distinction.

## 3. Algebraic distinguishability from identity

The weakest distinction is equality in the loop monoid:

```text
alpha = e_A ?
```

If trajectory equivalence `~_C` is imposed, the physical question becomes

```text
[alpha]_C = [e_A]_C ?
```

Thus a nontrivial loop may exist mathematically while being physically collapsed by the chosen representation/readout.

Classification:

```text
ALGEBRAIC_LOOP_NONTRIVIALITY != PHYSICAL_LOOP_OBSERVABILITY
```

## 4. Powers and iteration

Any loop `alpha` generates iterates

```text
alpha^0 = e_A
alpha^1 = alpha
alpha^2 = alpha o alpha
...
alpha^n.
```

This introduces a purely algebraic notion of repeated traversal/composition.

No elapsed time or angular period is implied.

The sequence may be:

```text
aperiodic: alpha^m != alpha^n for m != n
periodic:  alpha^n = e_A for some n > 0
idempotent: alpha^2 = alpha
nilpotent-like only after adding a zero/absorbing element
```

Only the first three are meaningful in the current minimal monoid without extra structure.

## 5. Algebraic period/order

If `alpha` is invertible and there exists a least positive integer `n` such that

```text
alpha^n = e_A,
```

define its algebraic order

```text
ord(alpha) = n.
```

If no such finite `n` exists, its order is infinite.

Important:

```text
FINITE ALGEBRAIC ORDER != ANGULAR PERIODICITY
```

Nothing in T1-T2 selects `n=2`, `n=4`, `2pi`, `4pi`, or any angular interpretation.

Therefore:

```text
2PI_PERIODICITY = NOT_DERIVED
4PI_PERIODICITY = NOT_DERIVED
```

## 6. Invertible loops

The invertible loops form

```text
G_A := Aut_R(A),
```

a group.

Inside `G_A`, group-theoretic constructions become available without adding topology.

These include:

- inverse `alpha^-1`;
- powers `alpha^n` for integer `n`;
- conjugation;
- commutators;
- normal subgroups and quotient groups if an equivalence is specified compatibly.

## 7. Conjugacy

For `alpha,g in G_A`, define

```text
alpha' = g o alpha o g^-1.
```

Then `alpha` and `alpha'` are conjugate.

Conjugacy is a natural candidate for representation-independent classification when `g` is interpreted as a reversible change of internal algebraic frame.

However, the physical meaning of such a frame change is not yet established.

Thus:

```text
CONJUGACY_CLASS = DERIVED_ALGEBRAIC_OBJECT
CONJUGACY_AS_PHYSICAL_EQUIVALENCE = NOT_DERIVED
```

## 8. Commutator

For invertible loops `alpha,beta in G_A`, define

```text
[alpha,beta]
 = alpha o beta o alpha^-1 o beta^-1.
```

If

```text
[alpha,beta] = e_A,
```

then `alpha` and `beta` commute.

If

```text
[alpha,beta] != e_A,
```

then composition order carries algebraically nontrivial information.

This is an important result because it distinguishes two loop histories without introducing a numerical scale:

```text
alpha o beta != beta o alpha.
```

But it is still only algebraic unless a physical representation detects it.

## 9. Abelianization

For the invertible loop group `G_A`, the commutator subgroup

```text
[G_A,G_A]
```

collects the noncommutative sector.

The quotient

```text
G_A^ab = G_A / [G_A,G_A]
```

is the abelianization.

Any homomorphism from `G_A` to an abelian group factors through `G_A^ab`.

This gives a strong constraint on future scalar additive/signed invariants: if their codomain is abelian and they respect loop composition, they cannot detect information living purely in the commutator subgroup.

This is a genuine theoretical restriction on candidate Resolutive scalar quantities.

## 10. Consequence for future scalar quantities

Suppose a future loop quantity

```text
Q : G_A -> (K,+)
```

is a homomorphism into an abelian additive group:

```text
Q(alpha o beta) = Q(alpha) + Q(beta).
```

Then necessarily

```text
Q([alpha,beta]) = 0.
```

Therefore a single additive scalar cannot capture all possible noncommutative history information.

Classification:

```text
ADDITIVE_SCALAR_HISTORY = BLIND_TO_COMMUTATOR_SECTOR
```

This result follows from group algebra and does not require experimental data.

## 11. Quotient by physically invisible loops

Let

```text
N_A subseteq G_A
```

be a set of invertible loops mapped to physical identity by a future representation `F`:

```text
F(n) = I for all n in N_A.
```

For a group representation/homomorphism, the invisible loops form the kernel

```text
N_A = ker(F|G_A),
```

which is a normal subgroup.

The physically distinguishable invertible loop classes are then represented by the quotient

```text
G_A / N_A.
```

This formalizes the distinction between algebraic loops and observable loop classes.
