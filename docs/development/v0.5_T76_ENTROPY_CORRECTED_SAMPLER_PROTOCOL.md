## 2. Hard structural and matching constraints

Every state must preserve exactly:

- labeled final degree sequence;
- child quota of every vertex;
- recursive order p(v)<v;
- connected rooted-tree class.

Stage-B hard matching box uses the same four quantities as T69:

A1 = mean(R),
A2 = mean(R^2),
A3 = mean(R^3),
C_KR = Cov(K_pre,R).

For each parent, derive the half-widths from a fresh Stage-A ordinary recursive-null ensemble:

Delta_Q = 0.25 * population_sd_StageA(Q).

No band widening is allowed.

## 3. Stage A

Generate 99 ordinary T47 recursive-order nulls.

- burn-in = 2000 accepted swaps;
- thinning = 200;
- proposal ceiling = 10,000,000;
- parent-edge overlap <= 0.90.

Compute A1,A2,A3,C_KR only.

## 4. Exact local two-coordinate drift/diffusion

At the exact T25 parent, exhaustively enumerate all unordered child-pair proposals.

Keep the proposals that:

1. are structurally valid;
2. leave all four coordinates inside the Stage-A-derived hard box.

For z=(A1,C_KR), compute:

mu = E[Delta z]

and the 2x2 covariance matrix

Sigma = Cov(Delta z).

Require det(Sigma)>0.

Define the local diffusion-tilt vector

lambda = 2 * Sigma^{-1} * mu.

This is the two-dimensional extension of the reflected-diffusion relation confirmed in T75.

## 5. Entropy-corrected Stage B target

Inside the same hard four-coordinate box, define a Metropolis-Hastings target weight relative to the uniform graph-state measure:

w(state)
=
exp[-lambda_A1 * (A1-A1_parent)
    -lambda_C * (C_KR-C_parent)].

The child-pair proposal is symmetric.

For a structurally valid proposal that remains inside all four hard bands, accept with probability

min(1, exp[-lambda dot (z_new-z_current)]).

No A2/A3 soft weight is added.

No M3/M7 quantity is used.

## 6. Multi-chain construction

For each parent run exactly 9 independent corrected chains.

Each chain:

- starts from the exact T25 parent;
- burn-in = 2000 **accepted MH moves**;
- thinning = 200 accepted MH moves;
- stores 11 states;
- proposal ceiling = 2,000,000.

Pool 99 unique states.

Parent-edge overlap must be <=0.90 for stored states.

Duplicates are forbidden across the pooled ensemble.

## 7. Frozen validation gates

### Feasibility

All 9 chains per parent must store 11 states.

### Hard-box control

Every stored state must satisfy all four frozen hard bands.

### Parent bracketing

For each of A1,A2,A3,C_KR, the exact parent value must lie inside the pooled min/max range.

### Centering of corrected coordinates

For A1 and C_KR:

|pooled_mean - parent| <= 0.20 * corresponding hard-band half-width.

This 20% criterion is frozen before execution.

## 8. Decision

T76_CORRECTED_SAMPLER_VALIDATED = PASS only if all four validation gates pass for all three held-out parents.

No rescue seeds and no relaxation of the centering or bracketing gates.

## 9. Interpretation

A PASS would establish that the T75-derived local entropy correction can produce a larger-N matched null ensemble that is:

- structurally randomized;
- inside the unchanged T69 control box;
- bracketed around the exact parent;
- approximately centered in the two coordinates that caused T70/T71 support failure.

Only after a PASS may M3/M7 be reopened under a separate frozen protocol.
