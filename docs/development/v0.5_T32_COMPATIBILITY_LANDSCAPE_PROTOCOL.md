# v0.5 T32 — Compatibility Landscape Diagnostic Protocol

**Status:** FROZEN BEFORE EXECUTION
**Parent:** T30/T31. No new dynamics.

## Question

Why does local descent on the T30 compatibility field become trapped?

T32 distinguishes two mechanisms:

A. **representation aliasing** — distinct nodules collapse to identical or near-identical T30 profiles;
B. **genuine landscape ruggedness** — profiles remain distinguishable but the scalar field has many non-reference local minima and barriers on the existing relational graph.

## Matrix

Frozen T25 graphs:
- N=128,256,512;
- seeds 11,23,47;
- primary R=1,2,4,8;
- every nodule used as reference for aggregate landscape statistics.

## Diagnostic 1 — Profile degeneracy

For each graph/R:
- number of unique exact T30 profiles;
- multiplicity histogram;
- maximum multiplicity;
- fraction of nodules in a non-singleton profile class;
- pairwise exact-profile collision fraction.

No floating tolerance is introduced: exact equality is evaluated on the integer cumulative shell counts underlying the normalized profile.

## Diagnostic 2 — Metric identity

For reference a, D_R(a,a)=0. Count other v != a with D_R(a,v)=0.

If such aliases exist, the reference is not unique in T30 profile space.

Measure fraction of references with at least one zero-distance alias.

## Diagnostic 3 — Graph-distance correlation

For every unordered pair:
- parent graph distance d_G(u,v);
- T30 distance D_R(u,v).

Measure Spearman rank correlation and Pearson correlation.

This asks whether profile distance preserves any monotonic relation to relational graph separation. Correlation is diagnostic, not a physical metric identification.

## Diagnostic 4 — Strict local minima

For each reference a, count v != a satisfying

Phi_a(v) < Phi_a(w) for all w in N(v).

Measure:
- minima count;
- minima density;
- distribution across references;
- correlation with reference degree/eccentricity.

## Diagnostic 5 — Deterministic descent basins

Use the exact frozen T31 tie rule. For every reference and start nodule classify terminal state:
- reference reached;
- strict/non-strict non-reference trap;
- symmetry ambiguity.

For unambiguous traps, measure basin-size distribution.

## Diagnostic 6 — One-edge barrier

For a trapped terminal v relative to reference a, define the minimal uphill escape cost

B_a(v) = min_{w in N(v)} max(0, Phi_a(w)-Phi_a(v)).

Measure positive barrier distribution.

This is not energy and not a physical potential barrier.

## Decision gates

T32_ALIASING_DOMINANT if profile collisions/zero-distance aliases explain a majority of failed descent endpoints.

T32_RUGGEDNESS_DOMINANT if most failed endpoints have unique profiles and positive local barriers.

T32_GRAPH_DISTANCE_ALIGNMENT = STRONG only if rank correlation is reproducibly high across sizes/seeds and consecutive R; no numerical threshold is selected post hoc. Report raw correlations.

Multiple mechanisms may coexist.

## Forbidden rescue actions

- no profile smoothing;
- no added momentum/noise;
- no threshold;
- no new weights;
- no graph evolution;
- no target dimension;
- no physical force/energy interpretation.
