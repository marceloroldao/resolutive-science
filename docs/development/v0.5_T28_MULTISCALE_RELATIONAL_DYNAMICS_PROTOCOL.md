## Candidate D28-A — dyadic relational consolidation

Initial condition:
- start from the frozen T25 tree T0;
- each edge initially has relational scale label s=0;
- node identifiers are opaque.

For round s=0,1,...,S-1:

1. Define the current scale reach R_s = 2^s in **current graph-hop information propagation steps**, not Euclidean length.
2. Each nodule builds a signature of its radius-R_s relational neighborhood using only isomorphism-invariant local data:
   - degree multiset by shell;
   - shell population sequence;
   - no node identifiers in the signature.
3. Two currently nonadjacent nodules become *candidates* only if:
   - their signatures are equal;
   - their current graph distance is in (R_s, 2 R_s].
4. Candidate conflicts are resolved by an isomorphism-invariant deterministic rule based on signature and local degree tuple. If a residual exact symmetry leaves several indistinguishable choices, **no edge is added** rather than breaking symmetry by node ID.
5. Added edges receive scale label s+1.
6. All accepted relations are applied simultaneously.
7. Existing relations are never deleted in D28-A.

## Why dyadic reach is permitted

## Critical symmetry rule

This may cause D28-A to add few or zero edges. That is a valid negative result.
