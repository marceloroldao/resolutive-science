## 1. Question

Can two independently reversible finite relational transformations generate a nonidentity closed commutator loop, while a commuting control remains exactly identity?

Define

```text
Delta_AB(x) = B^-1 A^-1 B A (x)
```

with traversal implemented as `A -> B -> A^-1 -> B^-1`.

The exact operator-writing convention may reverse product notation; all comparisons use the same explicit traversal order.

## 2. Transformations

On `(x0,x1) in Z_m^2`:

```text
A: x0 <- x0 + x1 mod m
B: x1 <- x1 + x0 mod m
```

Both have exact algebraic inverses.

Commuting control:

```text
S0: x0 <- x0 + 1 mod m
S1: x1 <- x1 + 1 mod m.
```


This pattern is a property of this constructed algebraic rule family, not a physical law.

## 4. Interpretation

The control demonstrates that a closed sequence of reversible operations need not create a defect when the transformations commute.

The shear pair demonstrates that reversible local transformations can generate

```text
Delta_AB(x) != x
```

for most states solely because composition order matters.

Therefore T15 confirms computationally the discrete algebraic mechanism anticipated in T2/T5:

```text
reversibility + noncommutativity -> nontrivial commutator loop.
```
