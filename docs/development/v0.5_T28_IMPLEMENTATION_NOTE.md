# v0.5 T28 — Implementation Note

D28-A is implemented in `src/v05/t28_multiscale_relational_dynamics.py`.

## Exact protocol mapping

- parent graph: frozen T25 generator;
- rounds: five;
- R_s=1,2,4,8,16;
- local signature: shell population plus shell degree multiset;
- candidate range: R_s < d_G(u,v) <= 2R_s;
- equal signatures required;
- all candidates grouped by structural key;
- if a structural class contains multiple possible pairs, no pair from that class is chosen;
- only structurally unique candidate pairs are added;
- additions are simultaneous.

## Important conservative choice

The implementation intentionally under-selects when the current signature cannot distinguish automorphism-like alternatives. It does not use a canonical labeling package to prove full graph automorphism equivalence.

Therefore:

- an accepted pair is uniquely described by the implemented invariant;
- a rejected ambiguous class may contain pairs that a stronger invariant could distinguish.

If activity is zero, the correct conclusion is **blocked under the current invariant**, not a theorem that every coordinate-free rule is blocked.

## Execution outputs to freeze

For every N/seed/round:

- candidate_pairs;
- structural_classes;
- unresolved_pairs;
- unique_structural_pairs;
- added;
- edges;
- beta1.

Only if D28-A produces reproducible multiscale activity should dimensional estimators be run on its output. If it is blocked, dimension fitting is not performed as a rescue step.
