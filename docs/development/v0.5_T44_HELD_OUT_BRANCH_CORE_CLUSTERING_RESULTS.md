## 9. Consequence

The failure mode of K is informative: using only the *largest* branch-core component discards the rest of the branch-core cluster-size distribution.

A mathematically natural refinement, fixed by the same induced branch forest, is the probability that two randomly selected branch vertices belong to the same connected branch-core component:

```text
P_B(T)
=
sum_j C(s_j,2) / C(|V_B|,2),
```

where s_j are the component sizes of T[V_B].

This uses the full component-size distribution rather than only its maximum and introduces no new topology family.

It is a legitimate next single candidate, but requires a new held-out preregistration before evaluation.
