## 1. Statistic

For each sampled attachment event v=2,...,N-1 define:

K_v = current degree of parent p(v) immediately before attachment,

R_v = (p(v)+1)/(v+1).

The primary statistic is the population covariance

C_KR = E[K R] - E[K]E[R].

The marginal distribution of K is fixed by final degree sequence (T67); C_KR tests only the joint organization.
