# v0.5 R3 — Resolutive Orientation Test

**Line:** v0.5 relational ontology  
**Depends on:** R1, R2  
**Status:** STRUCTURAL RESULT  
**Target-data fitting:** NONE

## 1. Question

Must the primitive Resolutive Relation itself be oriented, or is orientation required only for a Resolutive Transition?

The test must not import time direction, entropy, causality, energy gradient, phase, or spatial orientation.

## 2. Endpoint relation

For physical-state candidates `[R_A]` and `[R_B]`, define the minimal endpoint relation as

```text
mathcal R{[R_A],[R_B]}.
```

At this level the relation only asserts/encodes that the pair participates in an admissible relational structure. Nothing in R1 or R2 distinguishes an ordering of the pair.

Therefore orientation is not derivable for the primitive endpoint relation.

Minimal choice:

```text
mathcal R{A,B} = mathcal R{B,A}
```

where braces emphasize an unordered pair at this stage.

This is not a claim that every future physical relation must be symmetric. It is a refusal to add orientation before a structure requires it.

## 3. Transition orientation

A transition has a source and a target:

```text
T_AB : [R_A] -> [R_B].
```

Thus orientation is structural for transitions:

```text
source(T_AB) = [R_A]
target(T_AB) = [R_B].
```

For distinguishable endpoint classes,

```text
T_AB != T_BA
```

as oriented arrows, even if both are admissible.

This distinction does not imply that one is physically preferred.

## 4. Orientation is not an arrow of time

The ordering

```text
A -> B
```

means only source-to-target orientation of the transition object.

R3 does not license:

```text
A occurs earlier than B
entropy(B) > entropy(A)
E_A > E_B
A causes B
T_AB is more probable than T_BA
```

All such statements require additional structure.

## 5. Reverse transition versus inverse transition

Define a reverse-oriented candidate

```text
T_BA : [R_B] -> [R_A].
```

Do not identify it automatically with an algebraic inverse.

An inverse exists only if

```text
T_BA o T_AB = I_[A]
T_AB o T_BA = I_[B].
```

Therefore:

```text
REVERSE_ORIENTATION != INVERSE_TRANSITION
```

unless R4/R5 or a later gate establishes invertibility.

## 6. Path distinction

For a trajectory

```text
Gamma_AB = (T_01, ..., T_(n-1)n)
```

orientation is inherited from ordered composition.

A reversed sequence

```text
Gamma_BA^rev
```

is a different formal trajectory unless an equivalence rule later identifies them.

Again, no physical irreversibility is inferred.

## 7. Minimal structural result

R3 selects the weakest ontology compatible with R1-R2:

```text

RESOLUTIVE_TRANSITION = ORIENTED
REVERSE_TRANSITION = DISTINCT_FORMAL_OBJECT
INVERSE_TRANSITION = NOT_YET_DERIVED

```

## 8. Conventional comparator

This separation is conventional mathematics: undirected relations can coexist with directed morphisms/transitions.

```text
R3_NOVELTY = CONVENTIONAL_STRUCTURAL_FOUNDATION
```

No new physics is claimed.

## 9. Constraint propagated forward

Any future scalar relational quantity `Q_AB` must explicitly declare its behavior under endpoint exchange:

```text
Q_AB = +Q_BA   symmetric
Q_AB = -Q_BA   antisymmetric
Q_AB unrelated to Q_BA   directed/general
```

This must be derived or postulated before interpreting `Q` as Resolutive Energy, potential, phase, coherence, action, or another physical quantity.
