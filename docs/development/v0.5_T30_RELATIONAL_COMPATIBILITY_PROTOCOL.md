# v0.5 T30 — Relational Compatibility Protocol

**Status:** FROZEN BEFORE EXECUTION
**Parent controls:** D28-A and T29 remain unchanged.

## Question

Can compatibility between Nódulos Resolutivos be represented as a continuous, coordinate-free structural quantity without introducing a post-hoc similarity threshold?

T29 showed that exact signature equality becomes extinct at larger relational radius. T30 does **not** loosen D28-A. It defines a distinct diagnostic/candidate family.

## Primitive observable

For nodule u and radius R, let

n_r(u) = number of nodules at graph distance exactly r from u.

Define the cumulative relational mass

M_r(u) = sum_{j=0}^r n_j(u).

Normalize only by the total number of nodules N:

m_r(u) = M_r(u)/N.

The radius-R profile is

p_R(u) = (m_0(u),...,m_R(u)).

This uses graph relations only. No coordinates, embedding, target dimension, node IDs, physical length or legacy constants enter.

## Continuous structural distance

Define

D_R(u,v) = [ (1/(R+1)) sum_{r=0}^R (m_r(u)-m_r(v))^2 ]^(1/2).

Properties:
- D_R >= 0;
- symmetric;
- D_R(u,u)=0;
- continuous as a profile-space distance;
- relabeling invariant;
- no fitted weights.

## Compatibility

Define

C_R(u,v) = 1/(1 + D_R(u,v)).

Thus 0 < C_R <= 1 and C_R=1 iff the cumulative shell-mass profiles are equal.

The constant 1 is only the dimensionless identity scale in this bounded normalization; it is not a physical parameter and is not fitted.

## Critical no-threshold rule

T30-A **does not add edges** and does not declare a pair compatible/incompatible using an arbitrary cutoff.

The first test is diagnostic: measure the distribution and scale behavior of D_R and C_R.

No value such as C>0.9 may be introduced after inspecting results.

For every R measure over nonadjacent pairs in R < d_G(u,v) <= 2R:

- coefficient of variation where defined.

Also measure all-pair profile-distance summaries as a control.

## Scale-stability gate

A useful continuous compatibility observable should not collapse trivially to:
- all D_R approximately zero, or
- a single saturated value,
and should exhibit reproducible distributional behavior across seeds and increasing N.

T30_COMPATIBILITY_OBSERVABLE = NONDEGENERATE only if distributions retain finite spread reproducibly.

T30_SCALE_STABILITY = IDENTIFIED only if normalized distribution summaries show a reproducible regime across at least two consecutive preregistered radii and improve or remain stable with N.

No effective dimension is inferred from this test.
