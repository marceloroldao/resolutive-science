# v0.5 T49 — Selection-Pressure Dose-Response Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T48. **New dynamics:** none beyond the frozen T25 birth process.

## 1. Question

T48 established a binary mechanism-level contrast:

```text
MIN-DEGREE selection
<
RANDOM-AVAILABLE selection
```

for both high-radius responses M3 and M7.

T49 asks whether this regulatory effect is graded.

Define a selection-pressure parameter

```text
alpha in {0.00,0.25,0.50,0.75,1.00}.
```

At each birth:

- with probability alpha, choose the available candidate of minimum current degree;
- otherwise choose uniformly among the available candidates.

The same birth order and candidate-set trace are reused across alpha.

## 2. Held-out matrix

Use exactly:

```text
N = 2048
parent seeds = {673,701,733}
```

These parents were not used in T25-T48.

No rescue seed may be added.

## 3. Exact trace

For each seed record the exact frozen T25 trace exactly as in T48:

- sampled candidate labels;
- tie-break values;
- baseline fallback parent.

The alpha=1.00 replay must reproduce `generate(N,seed)` edge-for-edge.

If not, T49 stops.

## 4. Paired random schedule

For each parent seed generate exactly 99 replicate random schedules.

For each replicate and every birth v store three independent uniforms:

```text
u_mode(v)
u_choice(v)
u_fallback(v)
```

The same stored uniforms are reused for all alpha values in that replicate.

Thus the dose levels are coupled counterfactuals rather than unrelated Monte Carlo samples.

## 5. Selection operator

At each birth v:

1. obtain the currently available members of the frozen candidate set;
2. if at least one is available:
   - if `u_mode(v) < alpha`, choose the minimum-current-degree candidate, using the recorded T25 tie values;
   - otherwise choose uniformly using `u_choice(v)`;
3. if no sampled candidate is available:
   - for alpha=1.00 use the exact recorded T25 fallback parent;
   - for alpha<1.00 choose uniformly from all older vertices below the degree cap using `u_fallback(v)`.

The maximum degree remains exactly 6.

## 6. Frozen dose levels and replicates

```text
alpha = {0.00,0.25,0.50,0.75,1.00}
replicates per parent for alpha<1 = 99
alpha=1 = exact deterministic T25 replay
```

No additional dose is allowed after execution.

## 7. Responses

For every generated tree compute:

```text
M3 = median nu_4 for 4->8
M7 = mean existing-edge D_J at R=8.
```

For alpha<1 report mean, sd, q025, median and q975.

For alpha=1 report the exact T25 value.

## 8. Degree-distribution report

For each tree compute degree histogram H_d for d=1,...,6 and

```text
TV_deg(alpha)
=
0.5 * sum_d |H_d(alpha)-H_d(alpha=1)|.
```

Report TV_deg by dose.

No degree matching is introduced in T49.

## 9. Gates

### T49_TRACE_REPLAY

PASS only if alpha=1 exact replay matches the frozen T25 generator edge-for-edge for all three parents.

### T49_COUNTERFACTUAL_CONTROL

PASS only if every generated tree:

- is connected;
- has N-1 edges;
- has max degree <=6;
- has exactly one older neighbor for every v>0.

### T49_M3_DOSE_RESPONSE

IDENTIFIED only if, for each of the three held-out parent traces, the dose means satisfy strictly:

```text
mean M3(alpha=0)
>
mean M3(0.25)
>
mean M3(0.50)
>
mean M3(0.75)
>
M3(alpha=1).
```

### T49_M7_DOSE_RESPONSE

IDENTIFIED under the analogous strict ordering for M7.

### T49_SELECTION_PRESSURE_REGULATOR

IDENTIFIED only if:

1. trace replay passes;
2. all counterfactual controls pass;
3. T49_M3_DOSE_RESPONSE is identified;
4. T49_M7_DOSE_RESPONSE is identified.

No rescue criterion is allowed.

## 10. Interpretation boundary

A passing result establishes a graded selection-pressure mechanism in the current relational tree model.

It does not establish that alpha is a physical coupling constant or that degree is a physical observable.

The degree-histogram mediation remains explicitly reported.

## 11. Forbidden

- new selection operators;
- degree matching;
- M3/M7-dependent generation;
- rescue seeds;
- target physical data;
- physical geometry claims.
