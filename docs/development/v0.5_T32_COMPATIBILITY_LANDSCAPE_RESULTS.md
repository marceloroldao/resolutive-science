# v0.5 T32 — Compatibility Landscape Results

**Protocol:** frozen T32. **Dynamics:** none.
Matrix: N=128,256,512; seeds 11,23,47; R=1,2,4,8.

## Test / Result / Conclusion

### Profile aliasing

Exact profile aliasing is substantial at small R because cumulative shell counts are a compressed structural representation. It falls rapidly as R increases. By R=8 the overwhelming majority of nodules have distinct profiles across the tested graphs.

Therefore the T31 large-R trapping cannot be attributed primarily to exact profile collisions.

T32_ALIASING = SCALE_DEPENDENT
T32_ALIASING_AS_PRIMARY_R8_CAUSE = REJECTED

### Metric identity

At small R, some references possess zero-distance aliases because another nodule has the same exact cumulative shell-count profile. This phenomenon contracts strongly with R and is rare/absent in the large-R sector.

Thus nonunique zero-distance identity is a real information-loss mode of T30 at short radius, but it does not explain the dominant T31 trapping at R=8.

### Graph-distance alignment

D_R carries positive statistical information about graph separation, but it is not an order-preserving graph metric. Pairwise graph distance and profile distance show only partial correlation and substantial scatter.

Hence a locally smaller D_R does not imply movement along a shortest or globally descending path to the reference.

T32_GRAPH_DISTANCE_ALIGNMENT = PARTIAL_NOT_MONOTONIC

### Local minima and barriers

Non-reference strict local minima remain abundant after exact profile aliasing has largely disappeared. The large majority of these minima have unique T30 profiles.

Their one-edge escape barriers are positive by construction for strict minima and remain nonzero in the measured landscape.

Therefore:

T32_RUGGEDNESS = IDENTIFIED
T32_RUGGEDNESS_DOMINANT_AT_R8 = SUPPORTED

### Mechanistic explanation of T31

The chain of evidence is:

1. T29: exact discrete compatibility dies at R=8.
2. T30: continuous relational information survives at R=8.
3. T31: a nonzero reference-relative gradient exists, but greedy descent is trapped.
4. T32: at R=8 most trapping persists even where exact profile aliasing is weak; D_R is only partially aligned with graph distance and contains many genuine local minima.

Thus the T31 failure is primarily a landscape-geometry problem under the T30 observable, not merely a collision/compression artifact.

## Consequence for T33

Do not smooth D_R or add stochastic escape.

The next test should ask whether the ruggedness arises because a scalar distance to one reference discards directional information present in the **full profile vector** p_R(v).

T33 should therefore test vector/tangent information along existing edges before defining any dynamics: compare edge displacement vectors p_R(v)-p_R(u), path composition, local rank/dimensionality of these displacements, and whether reference displacement p_R(a)-p_R(v) lies in the local span/cone of available edge displacements.

If the vector information resolves traps that the scalar D_R cannot, that would identify a missing geometric structure without post-hoc smoothing. If it does not, freeze the negative result.
