# v0.5 P0 — Resolutive Relational Postulate Selection Protocol

**Line:** v0.5 relational ontology  
**Depends on:** R1-R5, Q1-Q4  
**Status:** FROZEN PRE-DYNAMICAL SELECTION PROTOCOL  
**Target-data fitting:** FORBIDDEN

## 1. Why P0 exists

R1-Q4 established a consistent relational ontology but did not derive a physical selector for nontrivial trajectory information or a unique quantitative magnitude. Additional mathematics alone cannot responsibly turn the current ontology into a physical law.

P0 therefore freezes the rules by which the first genuinely physical Resolutive postulate may be selected.

No candidate may be selected because it reproduces a desired old RSMS feature, known physical equation, cosmological curve, quantum phase, energy law, or target dataset.

## 2. Baseline null hypothesis

The null model is:

```text
H0_ENDPOINT_SUFFICIENCY
```

For all admissible physical processes in the tested domain, every observable prediction factors through the operational endpoint state(s):

```text
O(Gamma) = F(pi_end(Gamma)).
```

No independent trajectory-sensitive physical state is required.

Any v0.5 physical postulate must provide a discriminator against this null.

## 3. Frozen selection criteria

A candidate postulate must satisfy all mandatory criteria.

### C1 — Independence

The postulate must be motivated without using target-domain residuals or tuning against a desired phenomenon.

### C2 — Primitive economy

It should introduce the minimum new primitive structure needed to generate a discriminator.

### C3 — Operational meaning

At least in principle, the postulate must specify what preparation/readout operation could distinguish it from H0.

### C4 — Representation invariance

Predictions must be well-defined on physical equivalence classes, not arbitrary state labels/coordinates.

### C5 — Composition consistency

If trajectory composition is used, equivalent subtrajectories must remain equivalent under admissible context-independent composition.

### C6 — Explicit failure condition

A result capable of rejecting or failing to support the postulate must be stated before target testing.

### C7 — No semantic rescue

Renaming a conventional quantity as Resolutive Energy, Coherence, Density, Memory or History does not count as a new postulate.

### C8 — No legacy import

No 4pi, golden ratio, old `(rho_R,Theta_R,iota_R,kappa_R)` tuple, layer structure, terrestrial frequency, SPARC scale, or other v0.4 feature may be used as a selector unless independently re-derived later.

## 4. Candidate postulate family P0-A — Relational Composability

Candidate statement:

> A physical process carries an operational relational object `K_R(Gamma)` whose composition is determined by a fixed binary law independent of target data.

Form:

```text
K_R(Gamma_2 o Gamma_1)
 = K_R(Gamma_2) star K_R(Gamma_1).
```

Required additions:

- value/object space `K`;
- composition law `star`;
- operational readout of `K_R`.

Strength: constrains trajectory information by composition.

Problem: current ontology does not select `K`, `star`, or its physical readout.

Classification:

```text
P0_A = ADMISSIBLE_FORM / UNDERDETERMINED_CONTENT
```

## 5. Candidate postulate family P0-B — Relational Reversal Covariance

Candidate statement:

> Reversal of an admissible physical process transforms a relational readout by a fixed involution `J`.

Form:

```text
K_R(Gamma_rev) = J(K_R(Gamma)),
J(J(x)) = x.
```

This is weaker than assuming a negative sign, inverse phase, or time reversal.

Strength: supplies a falsifiable relation between forward/reversed preparations.

Problem: a physical reversal operation and readout must first be operationally defined; `J` is not uniquely selected.

Classification:

```text
P0_B = ADMISSIBLE_FORM / UNDERDETERMINED_CONTENT
```

## 6. Candidate postulate family P0-C — Closed-Process Detectability

Candidate statement:

> At least one admissible closed process can be operationally distinguished from the identity transition despite sharing the same endpoint state class.

Form:

```text
exists Gamma_loop:
M(Gamma_loop) != M(I_[R]).
```

Strength: this is the minimal direct assertion of nontrivial Resolutive History Residue.

Problem: as stated, it is close to the desired conclusion and does not explain what independent structure produces the distinction.

Classification:

```text
P0_C = TESTABLE_BUT_INSUFFICIENTLY_GENERATIVE
```

It may serve as an empirical alternative hypothesis, not yet as a satisfactory fundamental postulate.

## 7. Candidate postulate family P0-D — Relational Locality

Candidate statement:

> The physical contribution of a composite trajectory is determined entirely by local transition relations plus a universal composition rule, not by arbitrary global labels of the complete path.

Abstract form:

```text
K_R(Gamma)
 = Fold_star(k_R(T_1), ..., k_R(T_n)).
```

where `k_R` is a local relational object and `star` is universal.

Strengths:

- excludes arbitrary whole-path lookup tables;
- constrains history to arise from composition of local relations;
- gives a route to finite experiments;
- is independent of energy/time terminology.

Weakness: neither `k_R` nor `star` is yet fixed.

Classification:

```text
P0_D = STRUCTURALLY_STRONGEST_CANDIDATE_FORM
P0_D_CONTENT = UNDERDETERMINED
```

This is not a winner declaration; it identifies that P0-D currently imposes more structure than P0-A-C while remaining compatible with the frozen criteria.

## 8. Candidate postulate family P0-E — Pure endpoint sufficiency

Candidate statement:

> All physical readouts depend only on operational endpoint state classes.

This is identical to H0 and is retained as the conventional/minimal comparator rather than a Resolutive extension.

```text
P0_E = NULL_COMPARATOR
```

## 9. Selection result

No candidate currently fixes a unique physical object or quantitative law.

P0-D provides a useful constraint on what a future trajectory-sensitive law would have to look like, but choosing its local object or composition rule now would be arbitrary.

Therefore the frozen outcome is:

```text
P0_UNIQUE_POSTULATE = NOT_SELECTED
P0_NONTRIVIAL_HISTORY = NOT_ESTABLISHED
P0_QUANTITATIVE_LAW = NOT_DERIVED
P0_ENERGY = NOT_DERIVED
P0_TIME = NOT_DERIVED
```

The v0.5 line is not allowed to jump directly to a Master Equation.

## 10. Narrow next move — P1

The next admissible step is not to invent `k_R` or `star`. It is to ask whether **Relational Locality** can itself be justified as a methodological/physical postulate and whether it generates any theorem independent of the detailed codomain.

P1 must test the abstract statement:

```text
GLOBAL_HISTORY_INFORMATION
is generated compositionally from
LOCAL_RESOLUTIVE_RELATIONS.
```

against the null alternatives:

```text
ENDPOINT_ONLY
```

and

```text
ARBITRARY_GLOBAL_PATH_FUNCTIONAL.
```

If P1 cannot constrain observable consequences without specifying arbitrary hidden structure, classify it as `RELATIONAL_LOCALITY_UNDERDETERMINED` and stop.

## 11. Stop rule

The following is frozen before P1:

```text
IF no independently constrained operational selector emerges,
THEN v0.5 status = RELATIONAL_ONTOLOGY_WITHOUT_PHYSICAL_SELECTOR.
```

No fit, numerical constant, legacy structure, or semantic reinterpretation may override this stop rule.
