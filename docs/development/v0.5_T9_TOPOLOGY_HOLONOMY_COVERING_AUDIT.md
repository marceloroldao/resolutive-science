## 1. Purpose

T8 identified closed-loop holonomy as the strongest metric-free representation of global trajectory information currently available. T9 adds only the minimum global topological structure needed to classify closed paths and asks whether any covering structure, especially a double cover, is forced.

No circle, SO(3), SU(2), spinor, 2pi or 4pi periodicity is assumed.

## 2. New assumptions

On the represented base X assume only enough topology to define continuous paths, path composition and homotopy with fixed endpoints. For fundamental-group statements, take the relevant connected component to be path connected and choose a base point x0.

This is representation-level topology; it is not claimed to be fundamental physical spacetime topology.

## 3. Fundamental group

Closed paths based at x0 are grouped by endpoint-fixed homotopy. Their classes form

pi_1(X,x0).

The group product is induced by loop concatenation.

This gives a topological quotient of the much broader loop/history structure introduced in T2: trajectories that are continuously deformable into each other become one homotopy class.

Therefore

T2_LOOP_INFORMATION >= T9_HOMOTOPY_INFORMATION

in the sense that homotopy can forget distinctions present in the original trajectory algebra.

## 4. Holonomy and homotopy

For a general connection with nonzero curvature, holonomy need not depend only on homotopy class; smooth deformations can change the enclosed curvature and hence the holonomy.

For a flat connection, under the standard regularity assumptions, parallel transport around based loops depends only on their homotopy class. Then holonomy defines a group representation

rho_H : pi_1(X,x0) -> G

up to conjugation associated with frame/base-point choices.

This is the clean global bridge:

homotopy class -> holonomy class.

## 5. Flat does not mean globally trivial

If F_R = 0 locally but pi_1(X) is nontrivial, rho_H may still be nontrivial.

Thus

F_R = 0

does not imply

Hol_Gamma = I for every closed Gamma.

This rigorously preserves the T8 distinction between local curvature and global history.

## 6. Kernel and physically invisible loops

For a flat represented sector with holonomy representation rho_H, define

K = ker(rho_H).

Loops in K are topologically nontrivial if their homotopy class is nonidentity, yet invisible to this particular holonomy representation.

The represented global loop information is therefore carried by

pi_1(X,x0) / K

which is isomorphic to the image of rho_H.

This mirrors the T2 quotient-by-invisible-loops construction at the topological representation level.

## 7. Universal cover

When X satisfies the standard hypotheses for covering-space theory, there may exist a simply connected universal cover

p : X_tilde -> X.

Its deck-transformation group is related to pi_1(X).

A loop in X lifts to a path in X_tilde whose endpoint can differ from its starting lift by a deck transformation.

Thus a path that is closed in the quotient/base can be open in the covering space until enough traversals return the lifted state.

This provides the mathematically legitimate mechanism by which apparent periodicity can differ between base variables and represented/internal states.

## 8. n-fold covers

Nothing in the topology machinery privileges degree two. Depending on X and the chosen subgroup of pi_1(X), one may obtain coverings of degree

n = 2,3,4,...

or infinite degree, when such subgroups/covers exist.

Therefore

DOUBLE_COVER = POSSIBLE
DOUBLE_COVER = NOT_FORCED.

## 9. Exact condition for a two-cycle return

Suppose a loop class gamma has a representation satisfying

rho(gamma) != I

but

rho(gamma)^2 = I.

Then one traversal changes the represented internal state and two traversals restore it. Algebraically the image has order two.

If the base loop is parameterized conventionally as one 2pi rotation, the represented state would require two such traversals, conventionally described as 4pi return.

But the angular labels 2pi and 4pi enter only after identifying the loop with a physical rotation angle.

The topology itself yields only:

one traversal != identity,
two traversals = identity.

## 10. Counterexamples to universal double cover

The minimal framework permits many alternatives:

- trivial representation: one traversal already returns the state;
- order-2 image: two traversals return it;
- order-n image: n traversals return it;
- infinite-order image: no finite traversal count returns it;
- non-Abelian image: return behavior depends on ordered loop composition.

Therefore T1-T9 do not select universal order two.

## 11. Where the familiar rotation double cover would enter

A familiar 4pi-return structure arises if additional physics independently selects a rotational symmetry whose relevant state representation is a double-valued/base-quotient representation, e.g. a Spin/SU(2)-type lift of an SO(3)-type rotation structure.

T9 does not select these groups. Introducing them solely to recover the legacy Resolutive 4pi rule would be circular.

Thus

SO(3) = NOT_DERIVED
SU(2) = NOT_DERIVED
SPINOR_REPRESENTATION = NOT_DERIVED.

## 12. 2pi/4pi audit result

The old 4pi concept has now reached a precise status:

4pi is MATHEMATICALLY AVAILABLE as a special representation/covering case,
but 4pi is NOT DERIVED as a universal Resolutive law.

More invariantly, the theory can legitimately discuss the order of a loop image:

ord(rho(gamma)) = n.

Angular periodicity is a later physical interpretation of n when a rotation variable is independently established.

## 13. Topological charge candidates

Once topology and a representation are supplied, discrete/global labels can classify sectors without a metric. Candidate labels may arise from homotopy classes, conjugacy classes of holonomy, characteristic classes, or representation kernels/images.

They are structural/topological invariants, not automatically conserved physical charges with energetic meaning.

## 14. Relation to Resolutive coherence

A future notion of Resolutive Coherence can now be formulated without importing the old phase variable: two transported internal states may be called coherently related only after specifying a comparison rule based on transport/holonomy and an invariant equivalence criterion.

This route is more general than assigning a scalar phase Theta from the start.

Scalar phase may emerge only in an Abelian one-dimensional representation or another independently justified reduction.

## 15. Relation to scalar phase

If a future physical representation has an Abelian U(1)-like sector, holonomy may be expressible as

H(Gamma) = exp(i theta_Gamma).

Only then does a phase angle become natural, with periodicity inherited from that representation.

But U(1), complex numbers and theta are not selected by T1-T9.

Therefore

RESOLUTIVE_PHASE = POSSIBLE_REPRESENTATION_REDUCTION
RESOLUTIVE_PHASE = NOT_FUNDAMENTAL_AT_T9.

## 17. Main theoretical consequence

The old statement 'transfer requires 4pi' is too strong for the new ontology.

The structurally justified replacement is:

A represented state returns after n traversals when the physically relevant loop image has finite algebraic order n.

Symbolically,

rho(gamma)^n = I,

with n determined by the independently selected physical representation/topology.

A 4pi return corresponds to the special case n=2 when one base traversal is physically identified with 2pi.

This preserves the possibility that motivated the old formulation while removing the unjustified universal numerical assumption.

## 18. Next theoretical gate — T10: Operational Clock and Time Audit

With endpoint/history, local transport, curvature and global topology separated, the next unresolved primitive is ordering versus physical time.

T10 should ask:

1. what distinguishes mere trajectory parameter lambda from an operational clock;
2. whether time can be defined relationally by correlations between subsystems;
3. what monotonicity/repeatability conditions a clock variable requires;
4. whether reparameterization invariance makes coordinate time gauge-like;
5. when a generator can legitimately become a time-translation generator;
6. only then, whether an energy-like quantity can be defined.

No external absolute time is to be assumed at the start of T10.
