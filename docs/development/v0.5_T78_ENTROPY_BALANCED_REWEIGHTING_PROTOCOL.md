# v0.5 T78 — Entropy-Balanced Reweighting of Full-4D Matched Nulls Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T77.  
**Purpose:** convert the T77 fully bracketed 99-state candidate ensemble into an exactly mean-matched control ensemble by maximum-entropy reweighting, without changing graph states or inspecting M3/M7.

## 1. Parent matrix retained

Use the same exact T25 parents as T77:

N = 4096  
seeds = {1847, 1871, 1901}.

T77 did not compute M3 or M7.

## 2. Candidate-state construction retained exactly

For each seed, regenerate the deterministic T77 candidate ensemble using the unchanged T77 procedure:

- Stage A: 99 ordinary recursive nulls;
- hard bands Delta_Q = 0.25 Stage-A sd for A1,A2,A3,C_KR;
- exact local normalized 4D drift/covariance;
- lambda_y = 2 pinv(Sigma_y) mu_y with rcond=1e-12;
- 9 corrected MH chains;
- 11 stored states per chain;
- 99 pooled unique states;
- parent-edge overlap <=0.90.

No graph-state generation parameter is changed.

## 3. Normalized control vectors

For each candidate state j define

y_j =
(
(A1_j-A1_parent)/Delta_A1,
(A2_j-A2_parent)/Delta_A2,
(A3_j-A3_parent)/Delta_A3,
(C_j-C_parent)/Delta_C
).

All candidates must remain inside [-1,+1]^4.

## 4. Maximum-entropy calibration

Start from uniform base weights 1/99.

Find theta in R^4 such that

w_j(theta)
=
exp(theta dot y_j) / sum_l exp(theta dot y_l)

satisfies

sum_j w_j y_j = 0.

This is the exponential-tilting / maximum-entropy solution relative to uniform candidate weights.

Solve by deterministic Newton iterations:

gradient = weighted mean y,
Hessian = weighted covariance(y).

At each iteration:
- Newton step uses Moore-Penrose pseudoinverse with rcond=1e-12;
- use backtracking step sizes 1, 1/2, 1/4, ... until the infinity norm of the weighted mean decreases;
- maximum 100 iterations;
- convergence tolerance max_abs(weighted_mean_y) <= 1e-10.

No regularization, clipping or coordinate deletion is allowed.

## 5. Frozen validation gates

For every parent:

### Candidate reconstruction
Exactly 99 T77 states are regenerated and all four parent-bracketing gates pass.

### Calibration convergence
max_abs(weighted_mean_y) <= 1e-10.

### Effective sample size
ESS = 1 / sum_j w_j^2 >= 50.

### Maximum single-state weight
max_j w_j <= 0.05.

### Positive support
All 99 weights must be strictly positive.

## 6. Decision

T78_ENTROPY_BALANCING_VALIDATED = PASS only if all five gates pass for all three parents.

No rescue seeds, no weight clipping and no relaxation of ESS/max-weight thresholds.

## 7. Held-out boundary

M3 and M7 are forbidden in T78.

If T78 passes, a separate frozen protocol may use the exact same deterministic states and control-only weights to evaluate weighted M3/M7 null distributions.

## 8. Interpretation

A PASS establishes a nondegenerate, exactly control-mean-matched null measure over structurally randomized T77 graph states.

This is a statistical calibration of the null ensemble, not a physical entropy principle.
