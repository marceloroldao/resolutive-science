# v0.5 T42 — Held-Out Size Replication Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T41. **New dynamics:** none.

## 1. Purpose

T41 produced a post-hoc descriptive size pattern:

```text
N=128  -> both M3/M7 high in 1/3 parents
N=256  -> both M3/M7 high in 1/3 parents
N=512  -> both M3/M7 high in 3/3 parents
```

T42 converts that observation into a held-out replication test.

The prediction is tested at a new system size and with new parent seeds fixed before execution.

## 2. Frozen hold-out matrix

Use exactly:

```text
N = 1024
parent seeds = {59, 83, 101}
```

These sizes/seeds were not used in T25-T41.

No additional seed may be added after inspecting M3/M7.

## 3. Parent construction

Use the unchanged frozen T25 parent generator:

```text
generate(N, seed)
```

with no coordinate input and no target dimension.

## 4. Matched-null construction

For each held-out parent, repeat the T41 construction unchanged:

- exact labeled-node degree sequence preserved;
- tree class preserved;
- baseline 99 Prüfer-randomized degree-matched nulls used only to standardize C/A/G;
- matched-null target variables = {C,A,G};
- matching tolerance = 0.50 each;
- constrained Prüfer random-transposition walk;
- burn-in accepted moves = 500;
- thinning accepted moves = 50;
- stored matched nulls = 99;
- maximum proposals = 250000;
- parent-edge overlap maximum = 0.90;
- M3/M7 forbidden from the sampler.

No T41 hyperparameter is changed.

## 5. Held-out responses

Only after each 99-tree matched ensemble is frozen compute:

```text
M3 = median nu_4 for 4->8
M7 = mean existing-edge D_J at R=8.
```

Report parent and matched-null q025, median and q975 exactly as in T41.

## 6. Gates

### T42_REPLICATION_FEASIBILITY

PASS only if all three N=1024 parents produce 99 valid matched nulls under the unchanged T41 budget and controls.

### T42_BOTH_HIGH_REPLICATION

IDENTIFIED only if for all three held-out parents:

```text
M3_parent > q975(M3 matched null)
M7_parent > q975(M7 matched null).
```

### T42_PARTIAL_REPLICATION

If exactly one or two of the three parents satisfy BOTH_HIGH, record the exact count but do not promote full replication.

### T42_REPLICATION_FAILURE

If zero of three satisfy BOTH_HIGH:

```text
T42_BOTH_HIGH_REPLICATION = NOT_REPRODUCED
```

No rescue seeds or alternative size are permitted in T42.

## 7. Interpretation

A 3/3 held-out replication at N=1024 would strengthen the claim that the T41 residual is not disappearing at the largest tested size.

It would still not establish an infinite-size limit.

A failure or partial replication would weaken the apparent size trend and keep finite-size structure as a viable explanation.

## 8. Forbidden

- changing T41 matcher settings;
- changing N after execution;
- adding seeds after execution;
- using M3/M7 in matching;
- adding topology predictors;
- fitting a trend exponent;
- physical dimension claims;
- graph dynamics.
