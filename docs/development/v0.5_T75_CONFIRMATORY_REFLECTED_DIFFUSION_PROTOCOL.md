# v0.5 T75 — Confirmatory Reflected-Diffusion Sampler-Bias Test

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T74 post-hoc diagnostic.  
**Purpose:** confirm on new held-out parents that the local accepted-swap drift/diffusion predicts the coordinate bias of the constrained multi-chain sampler, without using M3/M7.

## 1. New held-out parent matrix

Exact T25 parents:

N = 4096  
seeds = {1663, 1693, 1721}.

These seeds were not used in T70–T74.

## 2. Stage A band construction

For each parent generate 99 ordinary T47 recursive-order nulls with:

- burn-in = 2000 accepted swaps;
- thinning = 200 accepted swaps;
- proposal ceiling = 10,000,000;
- overlap <= 0.90.

Compute A1,A2,A3,C_KR only.

For each control Q define the frozen Stage-B half-width

Delta_Q = 0.25 * StageA_population_sd(Q).

No M3/M7 quantity is computed.

## 3. Exact local accepted-step law

At the exact T25 parent, exhaustively enumerate all unordered child-pair proposals.

A proposal contributes to the local accepted-step law only if:

1. the parent swap is structurally valid;
2. the resulting one-step state remains inside all four Stage-A-derived bands.

For the accepted set compute exactly:

mu_A1 = mean(Delta A1),
sigma_A1 = sd(Delta A1),

mu_C = mean(Delta C_KR),
sigma_C = sd(Delta C_KR).

The predictions are computed **before the constrained chains are run**.

## 4. Frozen reflected-diffusion prediction

For x in {-Delta,+Delta}, approximate the local constrained coordinate by a reflected diffusion with constant drift mu and variance sigma^2.

Let

kappa = 2*mu/sigma^2.

The predicted stationary offset from the exact T25 parent is

m_pred
=
Delta*coth(kappa*Delta) - 1/kappa.

Compute this independently for A1 and C_KR.

If |kappa*Delta| is numerically small, use the analytic zero-drift limit m_pred=0.

## 5. Stage B confirmatory sampler

After predictions are fixed in memory, run exactly 9 independent constrained chains per parent.

Each chain:

- starts from the exact T25 parent;
- accepts only structurally valid swaps that keep A1,A2,A3,C_KR inside their frozen bands;
- burn-in = 2000 accepted constrained swaps;
- thinning = 200;
- stores 11 states;
- proposal ceiling = 1,000,000.

Pool 99 states per parent.

Duplicates are forbidden across the pooled ensemble.

No parent-bracketing gate is used in T75 because the target of T75 is the **sampler coordinate measure itself**, not accounting of M3/M7.

## 6. Observed offsets

For each pooled ensemble compute:

m_obs_A1 = mean(A1_null) - A1_parent,

m_obs_C = mean(C_null) - C_parent.

## 7. Frozen confirmatory gate

For all six seed-coordinate cases:

1. sign(m_obs) = sign(m_pred);
2. 0.80 <= |m_obs / m_pred| <= 1.20.

T75_REFLECTED_DIFFUSION_CONFIRMED = PASS only if all six cases pass.

No rescue seeds and no tolerance widening.

## 8. Interpretation

A PASS confirms prospectively that the T70/T71 one-sided coordinate support is generated by the constrained swap kernel's drift/diffusion under reflecting matching bands.

It does not validate a physical diffusion process; this is a Markov-chain approximation for the null sampler.

## 9. Scientific stop

M3/M7 are forbidden in T75.

No new structural feature is introduced.
