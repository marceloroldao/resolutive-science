# v0.5 T31 — Relational Compatibility Flow Protocol

**Status:** FROZEN BEFORE EXECUTION
**Parent:** T30 continuous compatibility diagnostic.
**No graph evolution in this test.**

## Question

Does the continuous relational profile distance D_R induce an intrinsic, coordinate-free directional structure along already existing Relações Resolutivas?

The goal is to test whether relative compatibility can define a flow/gradient object without introducing an absolute similarity threshold.

## Scalar field relative to a reference nodule

For a fixed reference nodule a, define

Phi_a^(R)(v) = D_R(a,v),

where D_R is exactly the frozen T30 RMS cumulative shell-mass profile distance.

No new weights or learned metric are introduced.

## Oriented edge difference

For an existing undirected edge {u,v}, define the reference-relative difference

Delta_a^(R)(u->v) = Phi_a^(R)(v) - Phi_a^(R)(u).

This is antisymmetric:

Delta_a(u->v) = -Delta_a(v->u).

An edge is:
- descending relative to a if Delta_a < 0;
- ascending if Delta_a > 0;
- neutral if Delta_a = 0.

This orientation is reference-relative, not an absolute arrow of time or physical force.

## Discrete relational gradient energy

Define

G_a^(R) = sum_{{u,v} in E} [Phi_a(v)-Phi_a(u)]^2 / |E|.

This measures how strongly the T30 compatibility field varies across existing relations.

Also define the neutral-edge fraction

Z_a^(R) = (# edges with Delta_a = 0)/|E|.

## Local extremum diagnostic

For every nodule v != a, compare Phi_a(v) with its neighbors.

A strict local minimum satisfies

Phi_a(v) < Phi_a(w) for every w in N(v).

If many non-reference strict local minima exist, a purely local descent rule can become trapped. If they are rare/absent reproducibly, D_R supplies a more globally coherent directional field.

## Descent reachability diagnostic

Starting at every v, repeatedly move to a neighbor with strictly smaller Phi_a.

Critical symmetry rule:
- if exactly one neighbor has the minimum strictly smaller Phi, move there;
- if several neighbors tie for the same minimum, stop as ambiguous;
- if no smaller neighbor exists, stop.

No node ID breaks ties.

Measure:
- fraction reaching reference a;
- fraction trapped at non-reference local minima;
- fraction stopped by symmetry ambiguity;
- path-length distribution.

This is diagnostic only. It does not modify the graph.

## Reference selection without privileged labels

For each graph, evaluate all nodules as references for aggregate statistics. For expensive path diagnostics, use a preregistered deterministic structural subset:
- references with minimum degree,
- median degree,
- maximum degree;
- if a degree class contains multiple structurally indistinguishable choices, aggregate over the entire class rather than selecting by ID.

Primary conclusions must be based on aggregate behavior, not a favorable reference.
