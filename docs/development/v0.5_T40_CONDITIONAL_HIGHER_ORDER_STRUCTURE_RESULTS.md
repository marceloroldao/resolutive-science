# v0.5 T40 — Conditional Higher-Order Structure Results

**Protocol:** `v0.5_T40_CONDITIONAL_HIGHER_ORDER_STRUCTURE_PROTOCOL.md`  
**Parent:** T39. **New dynamics:** none.  
**Nulls:** exact T38/T39 degree-sequence-matched ensembles.

## 1. Executive result

The preregistered topology family

```text
C = compactness composite from H1-H3
A = degree assortativity H4
G = betweenness Gini H8
```

has moderate predictive content inside the degree-matched null ensembles.

The median leave-one-out predictive coefficients are:

```text
median LOOCV R^2(Y3) = 0.518
median LOOCV R^2(Y7) = 0.524
```

so both responses pass the frozen T40 predictive-adequacy threshold of 0.50.

However, the decisive support gate fails:

```text
INTERPOLATION_SAFE parents = 0 / 9
```

Most importantly, the parent compactness coordinate C lies above the maximum value reached by the 99 matched nulls in **all 9 parent ensembles**.

Therefore the regression cannot be used to attribute or remove the parent M3/M7 departure.

```text
T40_CONDITIONAL_ATTRIBUTION =
    UNDERDETERMINED_OUTSIDE_NULL_SUPPORT
```

This stop rule overrides the apparent predictive performance.

## 2. Predictive adequacy inside the null ensemble

Across the nine parent-specific matched-null ensembles:

```text
Y3 LOOCV R^2 range = 0.433 .. 0.599
Y3 median          = 0.518

Y7 LOOCV R^2 range = 0.454 .. 0.685
Y7 median          = 0.524
```

Thus:

```text
T40_MODEL_PREDICTIVE_ADEQUACY_Y3 = IDENTIFIED
T40_MODEL_PREDICTIVE_ADEQUACY_Y7 = IDENTIFIED
```

This means C,A,G explain a meaningful fraction of M3/M7 variation among ordinary degree-matched null trees.

It does not mean they explain the T25 parents.

## 3. Compactness support failure

The standardized parent compactness values are:

```text
N=128:  C = 2.105, 2.590, 2.667
N=256:  C = 3.035, 3.447, 2.789
N=512:  C = 3.619, 3.828, 3.691
```

The corresponding maximum C values in their 99-null ensembles are:

```text
N=128:  1.815, 1.876, 2.208
N=256:  2.418, 1.953, 1.760
N=512:  1.903, 1.880, 2.222
```

Therefore:

```text
parent C > max(null C)
```

in all 9 cases.

```text
T40_COMPACTNESS_SUPPORT = FAIL_OUTSIDE_RANGE_9_OF_9
```

This is the main T40 result.

## 4. Assortativity and betweenness-concentration support

The other coordinates also leave the null range in several parents:

```text
A inside null min-max: 4 / 9
G inside null min-max: 6 / 9
C inside null min-max: 0 / 9
all C,A,G inside:      0 / 9
```

So no parent satisfies the preregistered interpolation-safe condition.

## 5. Why extrapolated predictions are not promoted

For diagnostics only, the linear model extrapolated toward the parent and generally predicted part, but not all, of the large M3/M7 standardized departures.

For example, at N=512 the parent standardized departures are roughly

```text
Y3_parent = 5.65 .. 6.82
Y7_parent = 8.55 .. 10.01
```

while extrapolated model predictions are only roughly

```text
Y3_pred = 2.56 .. 2.86
Y7_pred = 2.23 .. 2.63.
```

Those residuals look large, but T40 explicitly forbids treating them as evidence because the predictor coordinates are outside the null support.

Accordingly:

```text
T40_CONDITIONAL_ACCOUNTING = NOT_EVALUABLE_UNDER_SUPPORT_RULE
T40_CONDITIONAL_RESIDUAL_SPECIFICITY = NOT_EVALUABLE_UNDER_SUPPORT_RULE
```

## 6. Structural interpretation

T39/T40 now distinguish three levels:

### A. Degree sequence

Already controlled exactly by T38.

### B. Ordinary higher-order variation among degree-matched trees

C,A,G account for about half of M3/M7 variance in this region.

### C. T25 parent region

The parents occupy a much more compact and partly more assortative/concentrated topology region than ordinary degree-matched Prüfer randomization reaches.

Therefore the unresolved question is no longer simply:

> Which scalar correlates with M3/M7?

It is:

> What happens to M3/M7 among **degree-matched trees deliberately constrained to occupy the same higher-order topology region as the parent**?

That requires a new matched null ensemble.

## 8. Consequence

The correct next test is not a more flexible regression.

A T41 null ensemble should preserve:

1. N;
2. exact degree sequence;
3. tree class;

and additionally **match the parent higher-order topology coordinates C,A,G**, while being generated without using M3 or M7.

Only then can M3/M7 be tested as held-out structural responses.

This creates a clean falsification:

- if matched higher-order-topology nulls reproduce parent M3/M7, T38 is accounted for by the C,A,G structural family;
- if M3/M7 remain extreme, an additional invariant is required.

No physical dynamics should be introduced before that matched-null test.
