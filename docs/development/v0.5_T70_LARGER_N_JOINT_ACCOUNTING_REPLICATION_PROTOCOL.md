# v0.5 T70 — Larger-N Replication of Joint Structural Accounting Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T69.  
**Purpose:** replicate the T69 accounting result at larger N without adding or changing any matching variable.

## 1. Frozen held-out matrix

Exact T25 parents:

N = 4096
seeds = {1571, 1601, 1627}.

These seeds are new relative to T47–T69.

## 2. Matching construction — unchanged from T69

Every null preserves exactly:

- labeled final degree sequence;
- child quota of every vertex;
- recursive order parent(v)<v;
- connected rooted-tree class.

Stage B matches exactly the same four generator-derived quantities used in T69:

A1 = mean(R),
A2 = mean(R^2),
A3 = mean(R^3),

where R=(parent+1)/(child+1),

and

C_KR = Cov(K_pre,R),

where K_pre is the parent's degree immediately before attachment.

No new statistic is introduced.

## 3. Stage A

For each parent generate 99 ordinary T47 recursive-order nulls.

- burn-in = 2000 accepted swaps;
- thinning = 200 accepted swaps;
- proposal ceiling = 10,000,000;
- parent-edge overlap <= 0.90.

Stage A computes A1,A2,A3,C_KR only.

M3/M7 are forbidden.

For each control Q, set

Delta_Q = 0.25 * StageA_population_sd(Q).

## 4. Stage B

Start an independent parent-swap chain from the exact T25 parent.

Accept a recursive-valid child-parent swap only if all four frozen controls remain within their respective Stage-A-derived bands.

- target = 99 unique matched states;
- burn-in = 2000 accepted constrained swaps;
- thinning = 200 accepted constrained swaps;
- proposal ceiling = 10,000,000;
- parent-edge overlap <= 0.90.

No M3/M7 quantity may enter sampling.

## 5. Matching gate

For each of A1,A2,A3,C_KR:

- all Stage-B states lie in the frozen band;
- the parent value lies inside the realized Stage-B min/max range.

All structural controls must pass.

If any parent fails, T70 is INFEASIBLE and no accounting conclusion is drawn.

## 6. Held-out responses

Only after each parent's 99 Stage-B states are frozen, compute M3 and M7.

Classify against Stage-B q0.025 and q0.975.

T70_ACCOUNTING = REPLICATED only if both M3 and M7 are INSIDE for all three parents.

T70_RESIDUAL = IDENTIFIED only if both M3 and M7 are LOW for all three.

Any other feasible pattern is MIXED.

## 7. Interpretation

A 3/3 accounting replication at N=4096 would support size-stable structural closure of the tested T25 higher-radius residual by the T69 control family.

It remains a graph-process result only.
