# v0.5 T45 — Held-Out Branch-Core Pair Connectivity Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T44. **New dynamics:** none.

## 1. Motivation

T44 showed that the largest branch-core fraction K is a partial correlate but not a stable missing invariant.

K uses only the largest connected component of the induced branch forest and discards the remainder of the component-size distribution.

T45 tests one refinement from the same frozen structural family: the probability that two randomly selected branch vertices belong to the same connected branch-core component.

No additional topology metric is introduced.

## 2. Held-out matrix

Use exactly:

```text
N = 2048
parent seeds = {307,331,359}
```

These parents were not used in T25-T44.

No rescue seed may be added after execution.

## 3. Null construction

For each parent reuse the exact T41 C/A/G-matched null construction unchanged:

- exact labeled degree sequence;
- tree class;
- C/A/G tolerance 0.50 each;
- 500 accepted burn-in;
- 50 accepted moves thinning;
- 99 matched nulls;
- 250000 proposal ceiling;
- parent-edge overlap <= 0.90;
- M3/M7 excluded from sampler;
- P_B excluded from sampler.

## 4. Branch-core pair connectivity

Define the branch-vertex set

```text
V_B(T) = {v : degree(v) >= 3}.
```

Let

```text
T_B = T[V_B]
```

be the induced branch forest.

Let its connected-component sizes be

```text
s_1, s_2, ..., s_m.
```

Define

```text
P_B(T)
=
[sum_j C(s_j,2)] / C(|V_B|,2)
```

when |V_B| >= 2, otherwise P_B = 0.

Interpretation within the graph model:

> P_B is the probability that two uniformly selected distinct branch vertices lie in the same connected component of the induced branch forest.

No alternative degree threshold, weighting, normalization or component statistic may be selected after execution.

## 5. Held-out responses

After each 99-tree matched-null ensemble is frozen, compute:

```text
P_B
M3
M7
```

for the parent and every stored null.

P_B, M3 and M7 are forbidden from proposal acceptance.

## 6. Diagnostics

For each parent report:

- P_B parent;
- matched-null P_B mean, sd, q025, median, q975;
- parent percentile;
- Spearman rho(P_B,M3);
- Spearman rho(P_B,M7);
- M3/M7 held-out classification.

## 7. Gates

### T45_MATCH_FEASIBILITY

PASS only if all three held-out parents produce 99 valid T41-matched nulls.

### T45_RESIDUAL_REPLICATION

IDENTIFIED only if both M3 and M7 exceed q975 for all three held-out parents.

### T45_PAIR_CONNECTIVITY_PARENT_DEPARTURE

Directional hypothesis:

```text
P_B(parent) > q975(P_B matched null)
```

for all three parents.

### T45_PAIR_CONNECTIVITY_RESPONSE_ASSOCIATION

IDENTIFIED only if, in all three matched-null ensembles,

```text
rho(P_B,M3) > 0
rho(P_B,M7) > 0
```

and

```text
median over parents of
min(rho(P_B,M3),rho(P_B,M7)) >= 0.50.
```

The 0.50 threshold is frozen before execution.

### T45_PAIR_CONNECTIVITY_CANDIDATE

IDENTIFIED only if all four preceding gates pass.

Otherwise P_B is not promoted as the missing invariant.

## 8. Interpretation boundary

A passing result would identify P_B only as a held-out structural candidate in the current tree model.

A separate intervention matching P_B itself would still be required to test whether P_B accounts for the M3/M7 residual.

No physical interpretation is authorized in T45.

## 9. Forbidden

- alternative branch threshold;
- additional component-distribution metrics;
- P_B in the sampler;
- M3/M7 in the sampler;
- rescue seeds;
- changed T41 matcher settings;
- target physical data;
- graph dynamics.
