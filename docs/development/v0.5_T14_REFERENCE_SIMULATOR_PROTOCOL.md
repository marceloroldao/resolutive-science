## Purpose

T14 converts the three T13 transition-law families into a minimal executable reference harness. These tests are mathematical/computational consistency checks only; they do not validate the laws as physics.

## Implemented checks

### D13-A

- randomized exact forward/backward reconstruction;
- permutation/relabeling covariance;
- exhaustive small-state orbit closure for default `n=3, m=2`;
- explicit second-order reversible state `(x_{k-1},x_k)`.

### D13-B

- bounded finite history state;
- controlled history ablation: identical instantaneous `x`, different `h`, then compare next `x`;
- no raw unbounded trajectory log.

### D13-C

- normalized relational local transition kernel;
- reproducible seeded sampling support;
- score parameter is explicitly computational and is not interpreted as temperature or energy.

## Default reference rule

For a relational graph with neighborhood `N(v)`, the D13-A reference interaction is

```text
f_v(x) = sum_{u in N(v)} [x(u)-x(v)] mod m
```

and

```text
x_{k+1}(v) = x_{k-1}(v) + f_v(x_k) mod m.
```

The inverse is algebraically exact:

```text
x_{k-1}(v) = x_{k+1}(v) - f_v(x_k) mod m.
```

This rule is selected only as a minimal test implementation, not as a physical law.

## Why a ring appears in the harness

The default graph is a finite cycle graph because it is simple and has nontrivial relational automorphisms. Its graph geometry is a test fixture, not physical space and not a claim of circular fundamental topology.

The simulator's update functions accept an explicit neighbor relation so other graph families can be substituted.

## Stop rules

A candidate implementation fails internal T14 consistency if:

```text
A: any exact inversion test fails;
A: relabeling covariance fails;
A: an exhaustive finite reversible state space fails to close into an orbit;
B: history storage grows without declared bound in the base model;
C: any local probability kernel fails normalization;
```

A positive D13-B history-ablation result is not physical evidence; it only confirms that the intentionally history-sensitive implementation actually uses its history state.

## Scientific interpretation discipline

The harness may establish:

```text
implementation correctness
finite-state reversibility
covariance under tested relabelings
bounded-history behavior
probability normalization
orbit/cycle structure of the selected mathematical rule
```

It cannot establish:

```text
that nature uses D13-A/B/C
that physical space is a graph/ring
that k is physical time
that a simulated orbit is 2pi/4pi physics
that a loop defect is measured physical curvature
that history sensitivity exists in nature
```
