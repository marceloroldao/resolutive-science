# v0.4 Orientation-to-Layer Audit

**Status:** WORKING RESULT — FOLLOW-UP TO ISSUES #84/#85

## Question

Can the candidate binary layer variable `ell in Z2` be derived from the already proposed orientation field `n in S^2`, instead of being introduced as an independent postulate?

## 1. Topological obstruction for `n in S^2`

The sphere `S^2` is connected. Any continuous map

```text
ell : S^2 -> Z2
```

into the discrete space `Z2={0,1}` must therefore be constant on all of `S^2`.

Hence a single continuously varying orientation vector `n in S^2` cannot generate a nontrivial global binary layer label without adding a discontinuity, a cut, a reference structure, or extra degrees of freedom.

Classification: **D — no nontrivial continuous Z2 layer follows from S^2 alone**.

## 2. Why hemisphere labels do not solve the problem

One may choose a fixed reference axis `a` and define

```text
ell(n) = 0 if a.n >= 0,
ell(n) = 1 if a.n < 0.
```

This creates two labels, but the construction depends on an externally chosen axis and changes discontinuously across the equator `a.n=0`. It is therefore not an intrinsic topological layer carried by `S^2` itself.

Classification: **P/K reference-dependent classifier, not derived layer topology**.

## 3. Antipodal identification

Replacing `S^2` by the projective orientation space

```text
RP^2 = S^2 / (n ~ -n)
```

creates a nontrivial double covering `S^2 -> RP^2`.

However the two points `n` and `-n` are then two representatives of the same projective orientation. The sheet index of the covering is not automatically observable; it becomes physical only if the theory includes additional structure that distinguishes the two lifts.

Therefore `RP^2` supplies mathematically interesting double-cover structure, but it does not by itself justify a physical layer variable.

Classification: **D topology; physical layer interpretation OPEN**.

## 4. Chirality test

A single vector `n` has direction but no intrinsic handedness. Chirality requires at least an oriented frame or multiple non-coplanar vectors, e.g.

```text
C = sign( a . (b x c) ) in Z2.
```

Such a pseudoscalar can define two physically distinguishable sectors if `a,b,c` are independently physical state variables and parity reversal is not a gauge equivalence.

Thus a genuine `Z2` layer can arise from handedness, but not from `n in S^2` alone.

Classification: **C/P viable extension requiring extra orientation structure**.

## 5. Full orientation and double covers

A complete rigid orientation is represented by `SO(3)`, not `S^2`. Its standard double cover is

```text
SU(2) -> SO(3),
```

with `q` and `-q` mapping to the same ordinary spatial rotation. A lifted path may require `4pi` before the lift returns to the same point.

This is a genuine mathematical source of `4pi` behavior. But importing `SU(2)` solely because it has the desired periodicity would be circular. Resolutive Science may use this route only if its primitive state naturally requires a lifted orientation/spinor-like object and if an observable depends on the lift rather than only on the projected `SO(3)` orientation.

Classification: **known mathematical candidate, not yet derived from Resolutive primitives**.

## 6. Result for the current state content

For the current candidate primitive

```text
n in S^2,
```

the layer derivation fails:

```text
LAYER_FROM_S2 = NOT_DERIVED
```

The previously introduced independent `ell in Z2` must therefore remain an explicit postulate unless the state space is enlarged.

## 7. Smallest defensible next candidates

Three routes remain scientifically admissible:

1. **No physical layer**
   - remove `ell`;
   - retain ordinary `U(1)` phase and `n in S^2`;
   - classify physical `4pi` as unsupported.

2. **Chiral/oriented-frame layer**
   - replace a lone `n` by an oriented frame or equivalent physical variables;
   - derive `ell` from a parity/handedness invariant;
   - preregister a parity-sensitive observable.

3. **Lifted-orientation layer**
   - promote the state from ordinary orientation to an explicitly justified lifted space;
   - define the projection and transition law;
   - identify an observable that distinguishes the two lifts.

Route 2 is the smallest extension that produces a physical binary quantity without postulating `ell` directly. Route 3 is the strongest route to genuine `4pi` topology but carries a larger burden of justification.
