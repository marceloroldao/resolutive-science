# v0.5 T71 — Multi-Chain Larger-N Joint Accounting Replication Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T70 support infeasibility; T69 accounting result.  
**Purpose:** repeat the unchanged T70 structural hypothesis using multiple independent constrained chains to address one-sided sampler support without weakening any matching gate.

## 1. Parent matrix retained

Use the **same** exact T25 parents as T70:

N = 4096
seeds = {1571, 1601, 1627}.

T70 did not evaluate M3 or M7 for these parents. Retaining the same parent matrix avoids replacing difficult cases after a feasibility failure.

## 2. Scientific controls unchanged

Every null preserves exactly:

- labeled final degree sequence;
- child quota;
- recursive order parent(v)<v;
- connected rooted-tree class.

Stage B matches exactly:

A1 = mean(R),
A2 = mean(R^2),
A3 = mean(R^3),
C_KR = Cov(K_pre,R).

No new feature is introduced.

## 3. Stage A unchanged

Recompute the same Stage-A calibration as T70:

- 99 ordinary recursive-order nulls;
- burn-in = 2000 accepted swaps;
- thinning = 200;
- proposal ceiling = 10,000,000;
- overlap <= 0.90.

For each Q in {A1,A2,A3,C_KR}:

Delta_Q = 0.25 * StageA_population_sd(Q).

No M3/M7 calculation is permitted.

## 4. Stage B multi-chain sampler

Run exactly 9 independent constrained Markov chains for each parent.

Each chain:

- starts from the exact T25 parent;
- uses an independently frozen RNG seed derived from parent seed and chain index;
- accepts a recursive-valid quota-preserving swap only if all four quantities remain inside the same frozen Stage-A bands;
- burn-in = 2000 accepted constrained swaps;
- thinning = 200 accepted constrained swaps;
- stores exactly 11 states;
- proposal ceiling = 1,000,000 per chain.

Pool the 9*11 = 99 stored states.

Duplicates are forbidden across the complete pooled ensemble.

Parent-edge overlap must remain <=0.90.

## 5. Support/bracketing gate unchanged

For each of A1,A2,A3,C_KR:

1. every pooled state must lie inside its frozen symmetric band around the parent;
2. the exact parent value must lie inside the realized pooled min/max range.

This is the same scientific bracketing requirement that made T70 infeasible.

T71 does not widen bands and does not remove that gate.

## 6. Held-out M3/M7

Only after all 99 pooled states pass all structural, band and bracketing controls may M3 and M7 be computed.

T71_ACCOUNTING = REPLICATED only if M3 and M7 are INSIDE in all 3 parents.

T71_RESIDUAL = IDENTIFIED only if M3 and M7 are LOW in all 3 parents.

Any other feasible pattern is MIXED.

If support still fails, T71 is INFEASIBLE and M3/M7 remain uncomputed.

## 7. Interpretation

A successful support gate followed by 3/3 accounting would replicate T69 at doubled N without changing the structural hypothesis.

A repeated support failure would indicate that the exact T25 parent may lie near a boundary of the constrained null manifold at N=4096; it would not be treated as a failed accounting result.
