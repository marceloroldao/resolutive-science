## 3. Conventional baseline action

Take

```text
S0 = integral d^4x L0,
L0 = partial_mu Psi* partial^mu Psi - U(|Psi|^2).
```

Using

```text
Psi = sqrt(rho_R) exp(i phi_R),
```

we obtain exactly

```text
L0 = (partial rho_R)^2/(4 rho_R)
   + rho_R (partial phi_R)^2
   - U(rho_R).
```

Equivalently, with `Theta_R = 2 phi_R`,

```text
L0 = (partial rho_R)^2/(4 rho_R)
   + rho_R (partial Theta_R)^2/4
   - U(rho_R).
```

Therefore the kinetic structure is the ordinary polar form of a conventional complex scalar.

```text
NOVELTY_(rho_R,phi_R) = EQUIVALENT_REPARAMETRIZATION
```

## 4. Euler-Lagrange equation for phase

Since `L0` depends on `phi_R` only through derivatives,

```text
partial L0 / partial(partial_mu phi_R)
= 2 rho_R partial^mu phi_R.
```

Hence

```text
partial_mu (rho_R partial^mu phi_R) = 0.
```

Up to normalization convention, define

```text
j^mu = 2 rho_R partial^mu phi_R,
```

so

```text
partial_mu j^mu = 0.
```

This is the standard global-phase Noether current.

## 5. Euler-Lagrange equation for rho_R

For

```text
L0 = (partial rho_R)^2/(4 rho_R)
   + rho_R (partial phi_R)^2
   - U(rho_R),
```

the amplitude equation is

```text
(partial rho_R)^2/(4 rho_R^2)
+ (partial phi_R)^2
- U'(rho_R)
- box(rho_R)/(2 rho_R)
= 0.
```

Equivalently,

```text
-box(rho_R)
+ (partial rho_R)^2/(2 rho_R)
+ 2 rho_R (partial phi_R)^2
- 2 rho_R U'(rho_R)
= 0.
```

This is the ordinary complex-scalar amplitude equation in polar variables.

## 6. Direct complex-field check

Varying

```text
L0 = partial_mu Psi* partial^mu Psi - U(Psi*Psi)
```

gives

```text
box Psi + U'(rho_R) Psi = 0,
```

with `rho_R = Psi*Psi` under the stated normalization.

Separating real and imaginary parts reproduces the phase and amplitude equations above.

## 7. Symmetry and conservation

The baseline action is invariant under

```text
phi_R -> phi_R + alpha,
Psi -> exp(i alpha) Psi.
```

Noether's theorem gives

```text
j^mu = i(Psi* partial^mu Psi - Psi partial^mu Psi*)
```

which is proportional, up to sign convention, to

```text
rho_R partial^mu phi_R.
```

No independent `4pi` conservation law appears.

## 8. Limiting cases

### Constant phase

If `partial_mu phi_R = 0`, the phase equation is automatically satisfied and the amplitude equation reduces accordingly.

### Constant amplitude

If `rho_R = rho0 > 0` is constant, the phase obeys `box phi_R = 0`, with the amplitude equation imposing the corresponding relation involving `U'(rho0)`.

### Free massless baseline

If `U(rho_R)=0`, then

```text
box Psi = 0.
```

This provides a clean conventional limiting case.
