## 3. Minimal action family

Take the nearest conventional baseline action

```text
S0 = integral d^4x L0,
```

with

```text
L0 = partial_mu Psi* partial^mu Psi - U(|Psi|^2).
```

Using

```text
Psi = sqrt(rho) exp(i phi),
```

this becomes exactly

```text
L0 = (partial rho)^2/(4 rho)
   + rho (partial phi)^2
   - U(rho).
```

Equivalently, with `Theta = 2 phi`,

```text
L0 = (partial rho)^2/(4 rho)
   + rho (partial Theta)^2/4
   - U(rho).
```

Thus the current kinetic structure is not a new Resolutive term; it is the polar form of the conventional complex-scalar baseline.

Classification: **D — algebraic equivalence**.

## 4. Euler-Lagrange equation for phase

Because `L0` depends on `phi` only through its derivative,

```text
partial L0 / partial(partial_mu phi)
= 2 rho partial^mu phi.
```

The Euler-Lagrange equation is therefore

```text
partial_mu (rho partial^mu phi) = 0.
```

This is the continuity/Noether equation associated with global phase invariance.

Define, up to normalization convention,

```text
j^mu = 2 rho partial^mu phi,
```

so

```text
partial_mu j^mu = 0.
```

Classification: **D**.

## 5. Euler-Lagrange equation for rho

For

```text
L0 = (partial rho)^2/(4 rho)
   + rho (partial phi)^2
   - U(rho),
```

the rho equation is

```text
(partial rho)^2/(4 rho^2)
+ (partial phi)^2
- U'(rho)
- box(rho)/(2 rho)
= 0.
```

Equivalently,

```text
-box(rho)
+ (partial rho)^2/(2 rho)
+ 2 rho (partial phi)^2
- 2 rho U'(rho)
= 0.
```

This is exactly the amplitude equation obtained from the ordinary complex scalar written in polar variables.

Classification: **D**.

## 6. Direct complex-field check

Varying

```text
L0 = partial_mu Psi* partial^mu Psi - U(Psi*Psi)
```

directly gives

```text
box Psi + U'(rho) Psi = 0,
```

where `U'(rho)` denotes derivative with respect to `rho = Psi*Psi` under the stated normalization.

Separating this complex equation into real and imaginary parts reproduces the rho and phi equations above.

Therefore the polar derivation is internally consistent.

## 7. Symmetry and conserved quantity

The baseline action is invariant under global phase shifts

```text
phi -> phi + alpha,
Psi -> exp(i alpha) Psi.
```

Noether's theorem gives the conserved current

```text
j^mu = i(Psi* partial^mu Psi - Psi partial^mu Psi*)
```

which equals, up to sign convention,

```text
j^mu = -2 rho partial^mu phi.
```

The overall sign is conventional; conservation is not:

```text
partial_mu j^mu = 0.
```

No independent `4pi` conservation law appears.

## 8. Limiting cases

### 8.1 Constant phase

If

```text
partial_mu phi = 0,
```

the phase equation is automatically satisfied and the amplitude obeys

```text
(partial rho)^2/(4 rho^2)
- U'(rho)
- box(rho)/(2 rho)
= 0.
```

### 8.2 Constant amplitude

If

```text
rho = rho0 > 0,
```
then

```text
box rho = 0,
partial rho = 0,
```

and the amplitude equation requires

```text
(partial phi)^2 = U'(rho0).
```

The phase equation reduces to

```text
box phi = 0
```

when `rho0` is constant.

### 8.3 Free massless baseline

If

```text
U(rho) = 0,
```

the original complex field satisfies

```text
box Psi = 0.
```

This is a clean conventional limiting case.
