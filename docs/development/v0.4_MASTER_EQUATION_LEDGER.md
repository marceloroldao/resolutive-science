## 1. Resolved 4pi state-space audit

For the present half-angle representation define

```text
phi = Theta/2.
```

Then

```text
Theta in R/(4pi Z) <-> phi in R/(2pi Z),
```

with a smooth bijection and smooth inverse. Therefore the bare `4pi` angular coordinate is diffeomorphic to an ordinary phase circle.

From

```text
Psi = sqrt(rho) exp(i Theta/2),
```

we obtain

```text
Psi(Theta + 2pi) = -Psi(Theta),
Psi(Theta + 4pi) =  Psi(Theta),
```

but in the ordinary phase coordinate this is simply

```text
Psi(phi + pi)  = -Psi(phi),
Psi(phi + 2pi) =  Psi(phi).
```

Thus the sign change alone does not establish new `4pi` physics.

## 2. Kinetic-sector equivalence

Direct differentiation yields, up to metric/sign convention,

```text
|partial Psi|^2
= (partial rho)^2/(4 rho)
  + rho (partial Theta)^2/4
= (partial rho)^2/(4 rho)
  + rho (partial phi)^2.
```

Therefore ME-09 and ME-10 are algebraically the ordinary polar decomposition of a conventional complex scalar kinetic sector.

This does not invalidate them as candidate terms; it means they do not establish Resolutive novelty by themselves.

## 4. Lifted-orientation result

The canonical double cover

```text

```

has

```text
p(U) = p(-U),
```

and a lifted `2pi` path can connect `U` to `-U`, while `4pi` returns to `U`.

However the current vector orientation transforms through `SO(3)`:

```text
n -> p(U)n = p(-U)n.
```

Likewise a quaternion orientation satisfies

```text

```

If all current observables depend only on projected scalar/vector/orientation quantities, the sign of the lift is unobservable. Adding a new field solely to detect that sign would be a new postulate, not a derivation.
