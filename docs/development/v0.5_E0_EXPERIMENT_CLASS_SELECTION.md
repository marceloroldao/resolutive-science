# v0.5 E0 — Experiment-Class Selection

**Line:** v0.5 relational ontology  
**Depends on:** P2 preregistered empirical hypothesis  
**Status:** EXPERIMENT-CLASS SELECTION  
**Target-anomaly selection:** FORBIDDEN

## 1. Objective

Select the first physical domain in which to instantiate P2 without choosing a system because it previously showed an anomaly favorable to Resolutive interpretation.

P2 requires:

```text
common initial preparation
 -> controlled path P1 or P2
 -> endpoint-equivalence verification A_E
 -> independent terminal probe M_H
 -> frozen null comparison.
```

## 2. Frozen criteria

The criteria inherited from P2 are applied before defining a desired positive effect:

- E1: endpoint state can be measured precisely;
- E2: at least two reproducible preparation paths exist;
- E3: known memory/hysteresis mechanisms can be characterized;
- E4: a terminal probe distinct from endpoint verification is feasible;
- E5: apparatus is reproducible and reasonably inexpensive;
- E6: standard physics provides a quantitative null model;
- E7: path labels/order can be randomized or blinded;
- E8: null results remain interpretable.

Additional implementation preference, not a physical criterion:

- E9: first experiment should be automatable and repeatable at high cycle count.

No criterion awards points for agreement with prior Resolutive expectations.

## 3. Candidate A — Linear electrical network

Possible system:

```text
RLC / switched passive network
```

Two drive histories can be constructed to converge to a preregistered terminal electrical state, followed by an independent small-signal probe.

Strengths:

- voltage/current endpoints measurable with high precision;
- waveform histories easily programmable;
- standard circuit equations provide a strong null model;
- large numbers of randomized trials are practical;
- temperature and instrument drift can be logged;
- inexpensive instrumentation is possible.

Main risks:

- capacitor dielectric absorption;
- inductor/core hysteresis if magnetic materials are used;
- parasitic thermal state;
- switch charge injection;
- hidden internal state means apparently equal terminal V/I may not represent equal complete conventional state.

Scientific value: excellent as a methodology/control platform, provided conventional hidden state is modeled rather than mistaken for novel history.

## 4. Candidate B — Resonant oscillator

Possible system:

```text
high-Q electrical or mechanical resonator
```

Different excitation histories can be arranged to produce nominally equal terminal amplitude/state estimates before a ring-down or perturbative probe.

Strengths:

- path preparation is easy;
- ring-down supplies sensitive terminal dynamics;
- phase/amplitude can be measured repeatedly;
- standard damped-oscillator models are quantitative.

Risks:

- phase is itself part of the conventional state;
- nonlinearities, thermal drift and mode coupling create ordinary memory;
- equal amplitude alone is not adequate endpoint equivalence.

Scientific value: useful after the endpoint-state definition is mature.

## 5. Candidate C — Optical interferometric system

Possible system:

```text
Mach-Zehnder / fiber interferometric preparation
```

Strengths:

- extreme sensitivity;
- well-developed standard predictions;
- path manipulations are natural.

Risks:

- optical phase/path dependence is already conventional physics;
- environmental stabilization is demanding;
- a positive path-sensitive result would be difficult to interpret as new without an exceptionally precise null;
- equipment and calibration burden are higher.

Scientific value: high later, poor as the first discriminator of generic history because known path dependence dominates.

## 6. Candidate D — Mechanical system

Possible system:

```text
mass-spring / torsional oscillator / pendular preparation
```

Strengths:

- conceptually transparent;
- direct state variables can be measured;
- low-cost variants exist.

Risks:

- friction, backlash, material hysteresis and environmental coupling;
- lower automated cycle rate;
- endpoint precision typically weaker than electronic measurement.

Scientific value: good independent replication domain after protocol development.

## 7. Candidate E — Magnetic/core system

Possible system:

```text
inductor/transformer/ferrite core under alternative excitation histories
```

Strengths:

- very strong history dependence;
- easy electrical excitation/readout.

Critical problem:

Magnetic hysteresis is established conventional physics. A history-sensitive terminal response is expected and therefore cannot serve as a clean first test of the generic P2 hypothesis.

Scientific value: useful as a **positive control** demonstrating that the P2 architecture detects known historical state, not as the first anomaly-search system.

## 8. Selection without numerical pseudo-scoring

A numerical score is deliberately avoided because arbitrary weights would create false precision. The candidates are instead filtered by the mandatory criteria.

For the first implementation:

```text
LINEAR ELECTRICAL NETWORK
```

passes the practical filters most cleanly as a protocol-development and null-test platform, with one essential restriction:

> the initial system should avoid intentionally hysteretic magnetic components and should explicitly model capacitor, thermal and parasitic internal states.

This is an engineering selection, not evidence that electrical systems are more likely to show Resolutive effects.

## 9. First selected class

```text
E0_SELECTED_CLASS = PASSIVE_LINEAR_ELECTRICAL_NETWORK
E0_ROLE = NULL_TEST_AND_PROTOCOL_VALIDATION
```

Recommended initial topology class:

```text
precision RC network first
RLC extension second
```

Reason for RC first: fewer hidden magnetic states and simpler conventional dynamics.

## 10. Required conventional state model

For an ideal finite RC network, a complete Markov state can be represented by capacitor voltages (with topology/parameters fixed). If two preparations truly reach the same complete capacitor-voltage vector and environmental parameters, ideal linear circuit theory predicts identical future response under the same subsequent probe.

Therefore the null test is conceptually sharp:

```text
x_E(P1) = x_E(P2)
```

followed by identical probe `u_H(t)` should imply identical output trajectory under the ideal state-space model:

```text
x_dot = A x + B u
y     = C x + D u.
```

Real components require expanded state/control variables for dielectric absorption, leakage, temperature, switch effects and measurement loading.

## 11. Proposed E1 experiment concept

Use a small precision RC network with multiple accessible capacitor nodes.

Construct two programmable drive histories:

```text
P1: waveform/history A
P2: waveform/history B
```

that are actively driven to the same preregistered endpoint capacitor-voltage vector within tolerance.

Then disconnect/standardize the preparation path and apply the same small probe pulse or step.

Endpoint family `A_E`:

```text
all accessible capacitor-node voltages
supply/reference voltage
temperature
selected leakage/rest current indicators
```

History probe `M_H`:

```text
full transient response to a fixed small probe
```

Primary outcome candidate:

```text
difference between P1 and P2 probe-response residuals after subtraction of the fitted conventional RC model.
```

The exact statistic and tolerance must be frozen in E1 before data collection.

## 12. Positive control and negative control

### Negative control

Use identical preparation history under randomized labels. The pipeline must not generate a path effect.

### Positive control

Later introduce a deliberately history-dependent conventional element/system (for example a characterized hysteretic or dielectric-memory component) to verify that the protocol can detect known hidden state.

Positive-control effects must never be counted as evidence for Resolutive novelty.

## 14. Next gate — E1: RC preregistration and simulation

Before touching hardware, E1 must freeze a concrete RC topology, two preparation waveforms, complete accessible endpoint vector, tolerances, probe waveform, sampling protocol, null state-space model, residual statistic, randomization, sample/stop rule, and conventional nuisance models.

Then run a synthetic-data validation in which the analysis must correctly return null for an ideal RC model and detect only deliberately injected known memory terms.

Hardware testing is forbidden until the synthetic null/positive-control pipeline passes.
