# v0.5 T80 — Weighted Larger-N M3/M7 Structural Accounting Replication Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T79 validated expanded-pool entropy-balanced null.  
**Purpose:** perform the final held-out larger-N test of whether the T69 control family A1,A2,A3,C_KR accounts for M3 and M7 when the constrained null measure is corrected without using either response.

## 1. Held-out parent matrix

Use the same exact T25 parents whose M3/M7 remained unopened through T77–T79:

N = 4096  
seeds = {1847, 1871, 1901}.

No replacement or rescue seeds are allowed.

## 2. Candidate graph states

For each parent, deterministically regenerate exactly the validated T79 candidate ensemble:

- Stage A exactly as T77/T79;
- hard bands Delta_Q = 0.25 * Stage-A population sd;
- full-4D local T77 correction;
- 27 independent corrected chains;
- 11 states per chain;
- exactly 297 unique candidates;
- all candidates inside the hard A1/A2/A3/C_KR box;
- parent bracketed in all four controls.

No M3/M7 quantity may enter graph generation.

## 3. Entropy weights

Using only candidate control coordinates, deterministically regenerate the validated T79 weights:

w_j(theta)
=
exp(theta dot y_j) / sum_l exp(theta dot y_l),

with y_j the normalized A1/A2/A3/C_KR offsets and theta chosen so

sum_j w_j y_j = 0.

Require before held-out evaluation:

- convergence <= 1e-10;
- ESS >= 50;
- max weight <= 0.05;
- all weights > 0;
- exact candidate reconstruction and parent bracketing.

If any gate fails, T80 is INFEASIBLE and M3/M7 are not interpreted.

## 4. Held-out responses

Only after the complete candidate graph set and weights are frozen for a parent, compute:

- parent M3 and M7;
- candidate M3 and M7 for all 297 graphs.

Weights remain exactly the control-only T79 weights.

## 5. Frozen weighted empirical distribution

For any response X with candidate pairs (X_j,w_j):

1. sort candidates by X_j ascending;
2. carry their already-fixed weights with them;
3. normalize weights to sum exactly 1;
4. define weighted quantile q_p as the **first observed X value whose cumulative weight is >= p**.

No interpolation is used.

Compute q0.025, weighted median q0.5 and q0.975.

Also report weighted mean and weighted population standard deviation descriptively.

## 6. Classification

For each response:

- LOW if parent < q0.025;
- HIGH if parent > q0.975;
- INSIDE otherwise, including equality with either boundary.

## 7. Frozen decision

T80_ACCOUNTING_REPLICATED = YES only if:

- M3 classification = INSIDE for all 3 parents;
- M7 classification = INSIDE for all 3 parents.

T80_RESIDUAL = IDENTIFIED only if:

- M3 = LOW for all 3 parents;
- M7 = LOW for all 3 parents.

Any other feasible result is MIXED.

No threshold adjustment, alternative quantile definition, alternate weights or extra seeds are allowed after the responses are seen.

## 8. Secondary comparison

For transparency, also compute the **unweighted** 2.5%–97.5% interval over the same 297 candidate graphs.

This comparison is descriptive only and cannot replace the weighted primary decision.

Its purpose is to show how much the entropy-balancing correction changes the response null distribution.
