# v0.4 Iota/Kappa Extension Audit

**Status:** WORKING NEGATIVE RESULT — ISSUE #84

## Question

Do the RSMS-native variables `iota_R` and `kappa_R` currently provide independently motivated physical structure beyond the conventional `(rho_R, phi_R)` baseline?

Baseline:

```text
B0 = (rho_R, phi_R),
phi_R = Theta_R/2 mod 2pi.
```

The kinetic sector of `B0` has already been classified as the ordinary polar form of a conventional complex scalar.

## 1. Documentary test for iota_R

RSMS defines `iota_R` as a real scalar coordinate with the semantic role **resolutive inclination**. It explicitly leaves open its exact geometric meaning, range, degeneracies and physical dimension, stating only that it is dimensionless if a later specialization independently interprets it as an angle.

No current RSMS law supplies:

- an intrinsic transformation law for `iota_R`;
- a metric or topology beyond a provisional real scalar domain;
- a dynamical equation;
- a coupling to `(rho_R,phi_R)`;
- an observable projection that reads `iota_R` independently;
- an experimental operation that prepares or changes it.

Therefore its present status is:

```text
IOTA_R = RSMS_NATIVE_POSTULATE_WITHOUT_PHYSICAL_CLOSURE
```

Classification: **P — retained by specification, not yet a physical law**.

## 2. Free-scalar null for iota_R

The minimal generic extension

```text
L = L0 + (c_i/2) (partial iota_R)^2 - W(iota_R)
```

would simply add an ordinary real scalar field unless a nonstandard transformation, constraint, coupling or observable is independently justified.

Therefore a free kinetic term cannot be counted as Resolutive novelty.

Result:

```text
IOTA_FREE_SCALAR_NOVELTY = NO
```

## 3. Documentary test for kappa_R

RSMS defines `kappa_R` as a real scalar coordinate with the semantic role **local resolutive curvature** and explicitly forbids identifying it with spacetime curvature without a later normative mapping.

No current RSMS law supplies:

- a geometric object whose curvature equals `kappa_R`;
- units or a reference scale for `kappa_R`;
- a transformation law;
- a dynamical equation;
- a coupling to `(rho_R,phi_R)`;
- an observable projection that measures it independently;
- a theorem relating it to the connection curvature `F_nabla` of Chapter 4.

Therefore its present status is:

```text
KAPPA_R = RSMS_NATIVE_POSTULATE_WITHOUT_GEOMETRIC_IDENTIFICATION
```

Classification: **P — retained by specification, not yet derived geometry or physical law**.

## 4. Free-scalar null for kappa_R

The generic extension

```text
L = L0 + (c_k/2) (partial kappa_R)^2 - Z(kappa_R)
```

is again an ordinary multi-scalar theory unless `kappa_R` is tied to an independently defined geometric or transport invariant.

Therefore:

```text
KAPPA_FREE_SCALAR_NOVELTY = NO
```

## 5. Joint extension test

A generic four-scalar potential

```text
V(rho_R, phi_R, iota_R, kappa_R)
```

has enough functional freedom to manufacture interactions but supplies no derivation. Choosing such a function after inspecting target residuals would violate the v0.4 anti-retuning rule.

Hence the full four-component tuple alone does not imply a unique Master Equation.

```text
FOUR_COMPONENT_STATE != FOUR_COMPONENT_DYNAMICS
```

and

```text
RSMS_PRIMITIVE_STATUS != EMPIRICAL_NOVELTY
```

## 6. Strongest surviving route

The only structurally nontrivial object already present in RSMS that could give `kappa_R` or `iota_R` a non-arbitrary role is the bundle/transport framework:

```text
pi_M : E_R -> M
connection / parallel transport / holonomy / curvature
```

However Chapter 4 explicitly does **not** select a physical connection, structure group or topology.

A defensible next extension must therefore proceed in the opposite direction from the earlier free-field ansatz:

1. choose the smallest connection/transport structure required to compare resolutive states at distinct base points;
2. derive an invariant from that structure;
3. test whether `iota_R` or `kappa_R` can be mapped to that invariant without circular definition;
4. derive an observable consequence of transport/holonomy;
5. compare against a conventional bundle/gauge baseline of equal mathematical complexity.

This route is scientifically preferable to assigning arbitrary scalar kinetic terms because it can fail before any data fit.

## 7. Primitive-minimality warning

RS-R013 says a quantity should be primitive only when required to define the universal resolutive state. The present audit cannot yet demonstrate that either `iota_R` or `kappa_R` is required by the already derived dynamics.

Because RSMS-1.0 is a frozen baseline, this audit does not delete them. It records a future specification question:

```text
ARE_IOTA_AND_KAPPA_REQUIRED_PRIMITIVES = UNRESOLVED
```

If neither acquires an independent mathematical/observable role, a future RSMS revision should consider demoting one or both from universal primitives rather than preserving them only by historical convention.
