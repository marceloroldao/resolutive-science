# v0.5 T48 — Same-Candidate Selection-Operator Counterfactual Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T47. **New dynamics:** none beyond the already frozen T25 birth process.

## 1. Question

T47 showed that exact-degree recursive-order null trees have M3/M7 substantially above the T25 parents.

The T25 generator differs from a generic recursive tree by its online parent-selection rule:

1. sample up to five older vertices;
2. prefer the currently lowest-degree candidate;
3. break degree ties randomly;
4. enforce max degree 6.

T48 isolates this selection operator.

Question:

> Holding birth order and the per-birth candidate sets fixed, does replacing MIN-DEGREE selection by RANDOM-AVAILABLE selection raise M3/M7?

## 2. Held-out matrix

Use exactly:

```text
N = 2048
parent seeds = {577,607,641}
```

These parents were not used in T25-T47.

No rescue seed may be added.

## 3. Baseline trace extraction

For each seed replay the exact frozen T25 generator and record, for every birth v>=2:

- the sampled candidate labels in their original sample order;
- one random tie-break value per sampled candidate;
- whether fallback was used;
- the exact fallback parent when baseline fallback occurs.

The trace replay must consume random numbers exactly as the original generator does.

## 4. Exact MIN replay gate

Using only the recorded trace:

- sort candidates by (current degree, recorded tie value);
- attach v to the first candidate below max degree 6;
- if all candidates are full, use the recorded baseline fallback parent.

The resulting adjacency must be exactly identical to

```text
generate(N, seed)
```

edge-for-edge for all three held-out seeds.

If exact replay fails, T48 stops and no counterfactual inference is allowed.

## 5. RANDOM-AVAILABLE counterfactual

For each baseline trace generate exactly 99 counterfactual trees.

At each birth v>=2:

1. use the **same recorded candidate set** as the baseline;
2. collect candidates whose current degree is <6;
3. if one or more are available, select one uniformly at random;
4. if none are available, select uniformly from all older vertices with degree <6.

The choice RNG is independent of the candidate-trace RNG and uses a deterministic seed based on parent seed and replicate index.

Thus all replicas share:

- N;
- birth order;
- candidate sets;
- max degree 6;
- one-parent-per-birth recursive tree class.

They differ only in the parent-selection operator and its counterfactual random choices.

## 6. Frozen counterfactual count

```text
99 RANDOM-AVAILABLE trees per parent.
```

No replicate count may be changed after execution.

## 7. Held-out responses

For the exact MIN replay and each RANDOM-AVAILABLE counterfactual compute:

```text
M3 = median nu_4 for 4->8
M7 = mean existing-edge D_J at R=8.
```

Report the MIN value against the RANDOM distribution:

- mean;
- sd;
- q025;
- median;
- q975;
- MIN percentile.

## 8. Degree-distribution confound report

Because changing the online selection operator may change final degree counts, report for every RANDOM tree:

```text
H_d = fraction of vertices with degree d, d=1,...,6.
```

For each replica define total-variation distance from the MIN degree histogram:

```text
TV_deg
=
0.5 * sum_{d=1}^6 |H_d(random)-H_d(min)|.
```

Report the TV_deg distribution.

No degree matching is introduced in T48.

T47 remains the complementary exact-degree control.

## 9. Gates

### T48_TRACE_REPLAY

PASS only if the recorded-trace MIN replay is exactly edge-identical to the frozen T25 generator for all three parents.

### T48_COUNTERFACTUAL_CONTROL

PASS only if every RANDOM tree:

- is connected;
- has N-1 edges;
- satisfies max degree <=6;
- has exactly one older neighbor for every v>0.

### T48_SELECTION_REGULATORY_DIRECTION

The preregistered directional prediction is:

```text
M3_MIN < q025(M3_RANDOM)
M7_MIN < q025(M7_RANDOM)
```

for all three held-out parent traces.

Only then:

```text
T48_SELECTION_REGULATORY_DIRECTION = IDENTIFIED
```

### T48_MIXED_OR_NULL

Any other pattern is recorded exactly.

No rescue rule is allowed.

## 10. Joint interpretation with T47

If T48 regulatory direction is identified, then two independent controls support the same mechanism:

1. T47: exact-degree recursive-order randomization raises M3/M7 above T25;
2. T48: same-candidate RANDOM selection raises M3/M7 above exact MIN replay.

This would identify the low-degree choice rule as a robust **structural regulator** inside the current model.

It would not establish a physical interaction or law of nature.

## 11. Forbidden

- changing candidate sets in a RANDOM replica;
- changing max degree 6;
- adding MAX-degree or other variants after seeing results;
- degree matching inside T48;
- rescue seeds;
- fitting M3/M7;
- target physical data.
