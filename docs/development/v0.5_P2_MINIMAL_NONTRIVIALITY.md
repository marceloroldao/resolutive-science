# v0.5 P2 — Minimal Nontriviality of Resolutive History

**Line:** v0.5 relational ontology  
**Depends on:** R1-R5, Q1-Q4, frozen P0, P1  
**Status:** PREREGISTERED EMPIRICAL HYPOTHESIS / NOT A FUNDAMENTAL POSTULATE  
**Target-data fitting:** FORBIDDEN BEFORE PROTOCOL FREEZE

## 1. Boundary inherited from P1

P1 showed that Relational Locality constrains the algebra of a hypothetical history object but admits the trivial representation. Mathematics alone has not established that nature contains nontrivial Resolutive history information.

P2 therefore does not pretend to derive nontriviality. It formalizes the weakest empirical statement capable of testing it.

## 2. Two-stage operational state definition

To avoid the Q4 contradiction, distinguish two preregistered readout families.

### Endpoint readouts

Let `A_E` be a fixed family of endpoint-local readouts chosen **before** the history probe is applied.

Two preparations `P1` and `P2` are endpoint-equivalent when their terminal preparations are statistically indistinguishable under every readout in `A_E` within preregistered tolerances:

```text
P1 ~_E P2.
```

This defines a **Resolutive Endpoint State Class** relative to `A_E`.

### History probe

Let `M_H` be a distinct preregistered terminal probe not used to establish endpoint equivalence.

The purpose of `M_H` is to test whether the two preparation histories leave an operational distinction not captured by `A_E`.

## 3. P2 hypothesis pair

### H0 — Endpoint sufficiency relative to the protocol

For endpoint-equivalent preparations,

```text
P(outcome | P1, M_H)
=
P(outcome | P2, M_H)
```

within the preregistered statistical criterion.

### H1 — Minimal nontrivial history

There exists at least one reproducible pair `P1,P2` such that

```text
P1 ~_E P2
```

but

```text
P(outcome | P1, M_H)
!=
P(outcome | P2, M_H).
```

This is the minimal empirical content of a nonzero Resolutive History Residue relative to `A_E`.

## 4. Epistemic classification

P2 is **not** accepted as a fundamental principle merely because it is testable.

It is classified as:

```text
P2_NONTRIVIALITY = EMPIRICAL_HYPOTHESIS
```

If supported, it would show that the endpoint-state description relative to `A_E` is incomplete for predicting `M_H`. It would not by itself prove a new fundamental degree of freedom.

Conventional hidden variables, uncontrolled state variables, hysteresis, ordinary memory, environmental coupling, preparation contextuality or known path-dependent physics must be excluded before a novel Resolutive interpretation is considered.

## 5. Minimal protocol architecture

```text
Common initial preparation
        |
```

The terminal apparatus and analysis pipeline must be identical between arms except for the controlled path construction.

## 7. Mandatory controls

At minimum, a physical implementation must address:

1. calibration drift;
2. temperature/environmental differences;
3. timing differences introduced by the paths;
4. residual electromagnetic/mechanical coupling where relevant;
5. instrument memory/hysteresis;
6. order effects;
7. data-analysis leakage;
8. unequal endpoint preparation;
9. known conventional path-dependent mechanisms;
10. reproducibility under randomized path labels.

Controls must be specialized further for the chosen physical system.

## 8. Failure criterion

P2 fails to support nontrivial history if any of the following holds:

```text
A) endpoint equivalence P1 ~_E P2 is not established;
B) M_H does not distinguish the preparations under the frozen criterion;
C) the distinction disappears under mandatory controls;
D) a known conventional state variable accounts for the distinction;
E) the result does not replicate under the frozen replication rule.
```

A null result is a valid scientific result and must not be rescued by redefining `A_E`, `M_H`, or the path after observing the data.

## 9. Positive-result interpretation ladder

If H0 is rejected, interpretation must proceed conservatively:

```text
LEVEL 1: protocol-dependent effect detected
LEVEL 2: endpoint description A_E shown incomplete for M_H
LEVEL 3: conventional path-dependent explanations tested/excluded
LEVEL 4: reproducible history-sensitive state extension warranted
LEVEL 5: candidate Resolutive mechanism may be modeled
```

No jump from Level 1 directly to a new fundamental law is allowed.

## 13. Next gate — E0: Experiment-class selection

The next legitimate step is to select a physical experiment class using criteria fixed before looking for a positive anomaly.

Selection criteria:

1. same endpoint state can be verified with high precision;
2. two controllable preparation paths exist;
3. known hysteresis/memory mechanisms can be characterized;
4. a terminal probe independent from endpoint verification is available;
5. apparatus is inexpensive/reproducible where possible;
6. standard physics provides a quantitative null model;
7. path labels can be randomized/blinded;
8. null results are interpretable.

Candidate domains must be compared against these criteria before choosing one. No candidate may be selected because prior anomalous data appear favorable.
