# v0.5 T64 — Direct A1-Matched Recursive-Order Intervention Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T63.  
**Purpose:** test whether the T47 M3/M7 residual is accounted for by the parent-child age-alignment statistic A1.

## 1. Frozen parent matrix

Exact T25 parents:

N = 2048
seeds = {1129, 1151, 1187}

These seeds are new relative to T47–T63.

## 2. Preserved structure

All nulls preserve exactly:
- labeled final degree sequence;
- child quota of every vertex;
- recursive order parent(v)<v;
- connected rooted-tree class.

The only null move is the T47 two-child parent swap.

## 3. Frozen statistic

A1 = mean_{v=1,...,N-1} [(parent(v)+1)/(v+1)].

No other age statistic can be substituted if A1 matching fails.

## 4. Stage A — baseline recursive null calibration

For each parent:
- generate 99 ordinary T47 recursive-order nulls;
- burn-in 2000 accepted swaps;
- thinning 200 accepted swaps;
- proposal ceiling 1,000,000;
- parent-edge overlap <=0.90;
- no duplicate stored assignments.

Stage A computes A1 only. M3 and M7 are forbidden.

Let sigma_A be the population standard deviation of the 99 Stage-A A1 values.

Freeze the Stage-B matching half-width

Delta_A = 0.25 * sigma_A.

If sigma_A=0 or Stage A cannot produce 99 valid states, stop.

## 5. Stage B — direct A1-matched intervention

Start a new independent parent-swap chain from the exact T25 parent.

Use independent RNG seed

19000081*N + 19013*parent_seed.

A proposed recursive-valid swap is accepted only if the resulting A1 obeys

|A1_current - A1_parent| <= Delta_A.

Stage-B chain:
- proposal ceiling 5,000,000;
- burn-in 2000 accepted A1-constrained swaps;
- thinning 200 accepted A1-constrained swaps;
- store 99 unique states;
- parent-edge overlap <=0.90.

Every stored state must satisfy exact quota/degree and recursive-order controls.

No M3/M7 quantity enters proposal acceptance, storage, thinning, matching or diversity checks.

## 6. Matching gate

For every stored Stage-B state:

|A1_null - A1_parent| <= Delta_A.

Also require:
- parent A1 lies inside the realized Stage-B A1 min/max range;
- at least 99 unique Stage-B states;
- maximum parent-edge overlap <=0.90.

If any parent fails, T64 is INFEASIBLE and M3/M7 are not interpreted.

## 7. Held-out responses

Only after all 99 Stage-B nulls for a parent are frozen, compute:
- parent M3 and M7;
- Stage-B null M3 and M7.

Classify parent relative to q0.025 and q0.975 as LOW / INSIDE / HIGH.

## 8. Frozen decision

T64_A1_ACCOUNTING = IDENTIFIED only if both parent M3 and parent M7 are INSIDE the Stage-B 95% interval for all 3 held-out parents.

T64_RESIDUAL_AFTER_A1 = IDENTIFIED only if both responses remain LOW in all 3 parents, matching the preregistered T47 residual direction.

Any other pattern is MIXED and is not promoted as either full accounting or stable residual.

## 9. Interpretation

If accounting is identified, the T47 degree-preserving recursive residual is explained by parent-child age alignment A1 within the tested null family.

If LOW/LOW residual persists in 3/3, A1 is relevant but insufficient and another pairing/ancestral statistic remains.

This is a graph-process result only.
