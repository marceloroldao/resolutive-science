# v0.5 T40 — Conditional Higher-Order Structure Audit

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T39. **New dynamics:** none.

## 1. Question

Can the two stable T38 departures

```text
M3 = median nu_4 for 4->8
M7 = mean existing-edge D_J at R=8
```

be statistically accounted for by the preregistered T39 higher-order topology family, or does a stable residual remain?

No new topology feature is selected in T40.

## 2. Frozen predictor family

Reuse the exact T39 quantities.

Within each parent-specific 99-null ensemble standardize every quantity using that ensemble's null mean and null standard deviation.

Define:

### C — compactness composite

```text
C = -[z(H1) + z(H2) + z(H3)] / 3
```

so larger C means a more compact tree.

### A — assortativity coordinate

```text
A = z(H4)
```

### G — betweenness-concentration coordinate

```text
G = z(H8)
```

No H5, H6 or H7 term is allowed because T39 did not carry them forward as primary source variables.

No interaction or nonlinear term is allowed.

## 3. Frozen responses

```text
Y3 = z(M3)
Y7 = z(M7)
```

using the same parent-specific null standardization.

## 4. Frozen conditional model

Fit two ordinary least-squares models on the 99 null trees only:

```text
Y3 = b0 + bC C + bA A + bG G + error
Y7 = c0 + cC C + cA A + cG G + error.
```

No feature selection, interaction, polynomial, regularization or model replacement is permitted after execution.

## 5. Null predictive diagnostic

For each parent-specific null ensemble perform leave-one-out cross-validation.

Report:

- LOOCV R^2 for Y3;
- LOOCV R^2 for Y7;
- distribution of signed LOOCV residuals;
- distribution of absolute LOOCV residuals.

This is a predictive adequacy diagnostic, not a physical law.

## 6. Parent support / extrapolation gate

Standardize the parent C, A and G using the null mean and standard deviation.

For each coordinate separately report:

- parent standardized value;
- null minimum;
- null maximum;
- null q005;
- null q995.

Define:

```text
INTERPOLATION_SAFE
```

for a parent only if its C, A and G values all lie within the observed null [min,max] range.

This is a deliberately strict no-extrapolation rule.

No regression-based attribution may be promoted for a parent that fails this gate.

## 7. Parent conditional residual

For interpolation-safe parents only, use the full 99-null OLS model to predict Y3 and Y7 at the parent (C,A,G).

Define:

```text
E3_parent = Y3_parent - Y3_pred
E7_parent = Y7_parent - Y7_pred.
```

Compare |E3_parent| and |E7_parent| with the central 95% distribution of absolute LOOCV null residuals.

## 8. Classification gates

### T40_MODEL_PREDICTIVE_ADEQUACY

IDENTIFIED for a response only if median LOOCV R^2 across the 9 parent-specific ensembles is >= 0.50.

The threshold is frozen before execution.

### T40_CONDITIONAL_ACCOUNTING

IDENTIFIED only if:

1. all 9 parents are INTERPOLATION_SAFE;
2. predictive adequacy is identified for both Y3 and Y7;
3. both parent residuals lie within the null central 95% absolute-residual range for all 9 parents.

### T40_CONDITIONAL_RESIDUAL_SPECIFICITY

IDENTIFIED only if:

1. all 9 parents are INTERPOLATION_SAFE;
2. predictive adequacy is identified for both responses;
3. both E3_parent and E7_parent are positive and exceed the null q97.5 absolute-residual boundary in all 9 parents.

### Extrapolation stop

If any parent fails INTERPOLATION_SAFE:

```text
T40_CONDITIONAL_ATTRIBUTION =
    UNDERDETERMINED_OUTSIDE_NULL_SUPPORT
```

and neither ACCOUNTING nor RESIDUAL_SPECIFICITY may be promoted from the regression.

This stop rule overrides visually good fits or large coefficients.
