- E = N - 1
- connected components C = 1

### Explanation of T25 disagreement

The decisive structural fact is beta_1=0 in all runs. The frozen attachment rule adds each new nodule through one successful relation and never creates an additional relation between already connected nodules. Consequently it generates a tree by construction.

Thus the T25 disagreement is not evidence for an ordinary finite-dimensional manifold geometry. It is consistent with testing dimension estimators on a sparse acyclic relational geometry.

This is a diagnosis, not a failure to be repaired post hoc.
