# v0.5 R2 — Resolutive Relation Identity

**Line:** v0.5 relational ontology  
**Depends on:** R1 state distinguishability  
**Status:** STRUCTURAL TEST  
**Target-data fitting:** NONE

## 1. Question

Does the minimal relational ontology require an identity relation or identity transition, and what may legitimately be inferred from it?

## 2. Identity at the state-class level

R1 established physical-state candidates as equivalence classes

```text
P_R = S_R / ~.
```

For any `[R] in P_R`, define an identity transition candidate

```text
I_[R] : [R] -> [R].
```

If transitions are to admit composition, an identity morphism is the minimal neutral object satisfying

```text
T_AB o I_[A] = T_AB
I_[B] o T_AB = T_AB
```

whenever the compositions are defined.

This is a structural identity, not a physical claim about energy or time.

## 3. Self-relation versus identity transition

A self-relation

```text
mathcal R([R],[R])
```

need not be identical to the identity transition `I_[R]`.

Reason: a relation may encode static relational information, while a transition is oriented/composable structure.

Therefore v0.5 keeps them distinct:

```text
SELF_RELATION != IDENTITY_TRANSITION   (unless later derived)
```

## 4. Identity transition and physical change

At the quotient-state level, the identity transition has the same source and target:

```text
source(I_[R]) = target(I_[R]) = [R].
```

Thus it represents **no change of physical-state class** by definition.

Define a structural change predicate

```text
Delta_R(T) = 0  when source(T) ==_phys target(T)
Delta_R(T) = 1  when source(T) !=_phys target(T).
```

This is Boolean and non-metric.

For identity:

```text
Delta_R(I_[R]) = 0.
```

## 5. What cannot be inferred

The following implications are forbidden at R2:

```text
Delta_R = 0  =>  E = 0
Delta_R = 0  =>  Delta tau = 0
Delta_R = 0  =>  action = 0
Delta_R = 0  =>  no internal process
Delta_R = 0  =>  no phase accumulation
```

Why: source/target equivalence only says that admissible readouts do not distinguish the endpoint classes. A closed process could in principle return to the same class while accumulating some path-dependent quantity. Whether such quantities exist is a later question.

This prevents premature identification of state difference with energy or elapsed time.

## 6. Composition consequence

If the transition structure admits identity and associative composition, the minimal algebraic object begins to resemble a category/groupoid-like structure.

However, v0.5 does not yet assume:

- every transition is invertible;
- composition is globally defined;
- transitions form a group;
- trajectories are continuous;
- any Lie algebra or generator exists.

These are future gates.

## 7. Conventional comparator

Identity morphisms under composition are standard algebraic structure.

Classification:

```text
R2_NOVELTY = CONVENTIONAL_STRUCTURAL_FOUNDATION
```

Again, this is acceptable as scaffolding. No Resolutive novelty is claimed here.

## 8. Result

Provided transition composition is retained as a desired primitive operation, identity is structurally required:

```text
R2_IDENTITY_TRANSITION = DERIVED_FROM_COMPOSITION_REQUIREMENT
R2_SELF_RELATION_EQ_IDENTITY = NOT_DERIVED
R2_ZERO_STATE_CLASS_CHANGE = DERIVED_FOR_IDENTITY
R2_ZERO_ENERGY = NOT_DERIVED
R2_ZERO_TIME = NOT_DERIVED
```

## 9. New distinction for the ontology

The following terms are now separated:

- **Resolutive Identity Transition** — neutral transition on a physical-state class;
- **Resolutive Self-Relation** — relation of a state class with itself;
- **Resolutive Change Predicate** — Boolean endpoint distinction;
- **Resolutive Trajectory** — ordered composition, potentially capable of carrying information not present in endpoints.

The last point is important: endpoint equality does not imply trajectory triviality.
