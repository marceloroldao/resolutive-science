# v0.5 T35 — Canonical Scale Transport Protocol

**Status:** FROZEN BEFORE EXECUTION  
**Parent:** T34. **New dynamics:** none.

## 1. Question

Does the local relational displacement subspace persist when the profile radius is enlarged from R to 2R **without discarding the new higher-radius coordinates**?

T34 cannot answer this because its restriction

```text
X_2R[:,0:R+1]
```

is identically equal to `X_R`.

T35 replaces that tautological comparison with a canonical inclusion into the common higher-dimensional ambient space.

## 2. Frozen objects

At nodule v and radius R,

```text
X_R(v)
```

has rows

```text
delta p_R(v->w) = p_R(w)-p_R(v)
```

for existing neighbors `w in N(v)`.

For the pair R -> 2R define the canonical zero-padding inclusion

```text
E_R : R^(R+1) -> R^(2R+1)

E_R(x_0,...,x_R)
=
(x_0,...,x_R,0,...,0).
```

Then

```text
X_R^up(v) = [ X_R(v) | 0 ]
```

and both `X_R^up(v)` and `X_2R(v)` live in `R^(2R+1)`.

No fitted embedding or rotation is allowed.

## 3. Diagnostics

### A. Canonical principal-angle transport

Compute orthonormal row-space bases for

```text
X_R^up(v)
X_2R(v)
```

and the singular values of their cross-Gram matrix.

Report for every admissible v:

- lower rank;
- higher rank;
- common-rank dimension;
- mean principal cosine;
- minimum principal cosine.

No cosine threshold is chosen.

### B. Added-coordinate power

Let

```text
X_2R = [ X_inner | X_outer ]
```

where `X_inner` contains coordinates 0..R and `X_outer` contains coordinates R+1..2R.

Report

```text
eta_outer
=
||X_outer||_F^2 / ||X_2R||_F^2
```

when the denominator is nonzero.

This measures how much local displacement power is genuinely added by the larger radial profile.

### C. Projection residual

Project each row of `X_2R` onto the row space of `X_R^up`.

Report the normalized Frobenius residual

```text
epsilon_R_to_2R
=
||X_2R - Proj_row(X_R^up) X_2R||_F
/
||X_2R||_F.
```

No residual threshold is chosen.

### D. Size stability

Use the frozen matrix:

- N=128,256,512;
- seeds 11,23,47;
- transitions 1->2, 2->4, 4->8.

For each transition report distributions of principal cosines, `eta_outer`, and projection residual versus N.

### E. Degree conditioning

Report all three diagnostics conditioned on local graph degree.

The parent T25 graph is nearly tree-like with mean degree approximately two; degree effects must not be interpreted as physical dimension.

## 4. Gates

```text
T35_CANONICAL_SCALE_PERSISTENCE
```

may be classified descriptively only if principal-cosine distributions remain reproducibly concentrated near one across N and seeds **while `eta_outer` is nonzero**, so that persistence is not caused by absence of new coordinates.

```text
T35_SCALE_EXTENSION_NONTRIVIAL
```

is identified only if the added-coordinate power is reproducibly nonzero.

```text
T35_SCALE_COMPLETION
```

is not derived merely from persistence. A high overlap means that lower-scale directions persist; it does not imply that the lower subspace spans the higher-scale structure.

```text
T35_EFFECTIVE_DIMENSION
```

remains NOT_DERIVED unless an independent rank-like quantity stabilizes after degree conditioning.
