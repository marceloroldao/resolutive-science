# v0.5 T19 — Scaling Exponent Result

**Status:** theory-only mathematical result; no physical validation.

Starting from the D13-A ring low-mode result of T18,

```text
lambda_j(n) = -4 sin^2(pi j/n)
            ~ -4 pi^2 j^2 / n^2
```

and the exact two-update defect on a Laplacian eigenmode,

```text
M_j^2-I = [[0, c lambda_j],
           [c lambda_j, c^2 lambda_j^2]],
```

define the candidate relational scaling

```text
delta_R(n) = n^(-p).
```

Then the leading scaled generator term is

```text
c lambda_j / delta_R
~ -4 c pi^2 j^2 n^(p-2).
```

Therefore, for fixed low mode j:

```text
p < 2  => G -> 0
p = 2  => G -> finite nonzero limit
p > 2  => ||G|| -> infinity.
```

Hence the ring family uniquely selects

```text
T19_RING_SCALING_EXPONENT = 2.
```

This is not postulated and was not selected from legacy Resolutive numerology. It follows from the spectral scaling of the ring graph Laplacian.

For the implementation audit with c=0.05, the asymptotic log-log slopes for mode j=1 over n=256..2048 are approximately:

```text
p=1.0  -> -0.99998
p=1.5  -> -0.49998
p=2.0  -> +0.00002
p=2.5  -> +0.50002
p=3.0  -> +1.00002
```

matching the analytic exponent `p-2`.

For p=2 the off-diagonal generator limit is

```text
G_* offdiag -> -4 c pi^2 j^2.
```

At c=0.05 and j=1 this is approximately

```text
-1.9739208802.
```

## Interpretation

The continuum scaling variable is therefore not the raw update count. In this ring/low-mode sector a nontrivial continuum description requires a relational increment scaling as the inverse square of resolution:

```text
delta_R ~ n^-2.
```

This is mathematically analogous to a diffusive/Laplacian dynamic exponent, but T19 does not identify it with physical diffusion or physical time.

## Universality guard

