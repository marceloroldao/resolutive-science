# v0.5 T34 — Local Subspace Stability Protocol

**Status:** FROZEN BEFORE EXECUTION
**Parent:** T33. **New dynamics:** none.

## Question

Do the T33 local profile-displacement vectors organize into a reproducible low-rank local subspace as relational scale R and system size N increase?

No target rank or target dimension is supplied.

## Frozen object

At nodule v and radius R, construct X_R(v), whose rows are the existing-edge displacements

delta p_R(v->w)=p_R(w)-p_R(v),  w in N(v).

Let singular values be

s_1 >= s_2 >= ... >= 0.

## Diagnostics

### A. Exact local rank
Report rank(X_R(v)), limited naturally by degree(v) and R+1.

### B. Participation rank
With lambda_i=s_i^2,

r_part = (sum lambda_i)^2 / sum lambda_i^2.

No rounding to an integer and no target rank.

### C. Spectral concentration
Report cumulative fractions

C_k = sum_{i<=k} lambda_i / sum_i lambda_i

for every available k. Do not select k after inspecting the data.

### D. Scale embedding and subspace overlap

Because p_R is nested in p_2R through its first R+1 components, compare the R subspace with the restriction of the 2R displacement vectors to the first R+1 coordinates.

Use principal-angle singular values between orthonormal row-space bases. Report:
- common-rank dimension;
- mean principal cosine;
- minimum principal cosine.

No arbitrary angle cutoff.

### E. Size stability

For each R compare distributions of exact rank, participation rank and spectral concentration across N=128,256,512 and seeds.

A stable effective local subspace requires convergence/stabilization with N rather than systematic drift.

### F. Degree conditioning

Because the frozen T25 parent is tree-like with mean degree ~2, report rank statistics conditioned on degree. This prevents graph degree from being mistaken for emergent spatial dimension.
