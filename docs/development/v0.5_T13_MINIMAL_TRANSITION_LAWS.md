## 1. Purpose

T12 selected a discrete/categorical Resolutive Transition Law `D_R` as the minimal foundational dynamics route. T13 constructs three explicit minimal law families without importing legacy constants, 2pi/4pi rules, rho_R, a metric, absolute time, quantum amplitudes or a continuum action.

The candidates are deliberately small enough to implement and falsify.

## 2. Common primitive substrate

Let the primitive relational system at update index `k` be a finite or locally finite labeled interaction structure

```text
Sigma_k = (V_k, E_k, x_k, h_k)
```

where:

- `V_k` is a set of Resolutive Nodules (primitive relational sites/objects);
- `E_k` is the admissible relation structure between nodules;
- `x_k(v)` is a finite local state label at nodule `v`;
- `h_k(v)` is an optional compressed history label.

The update index `k` is an ordering label, not physical time.

## 3. Resolutive neighborhood

For each nodule `v`, define its declared relational neighborhood

```text
N_k(v) = {u | u is related to v by an admissible primitive relation}.
```

No metric radius is used. Locality is entirely relational.

A local context is

```text
C_k(v) = (x_k(v), multiset/typed pattern of x_k(u) for u in N_k(v), h_k(v)).
```

The law must be invariant under arbitrary relabeling of nodules that preserves the relation structure.

## 4. Common constraints

Every candidate must satisfy:

```text
K1 categorical/typing consistency
```

## 5. D13-A — Deterministic reversible local rule

### 5.1 State

Use a finite alphabet `A` and augment the instantaneous local state with the previous local state:

```text
z_k(v) = (x_{k-1}(v), x_k(v)).
```

This second-order construction permits reversible updates without storing the entire past.

### 5.2 Rule family

Choose a finite group/finite Abelian state alphabet for the minimal implementation, e.g. `Z_m`, but keep `m` as a model-family choice rather than a physical constant.

Define a permutation-covariant neighborhood function

```text
f_v(x_k) = f(x_k(v), multiset{x_k(u): u in N_k(v)}).
```

Then update

```text
x_{k+1}(v) = x_{k-1}(v) + f_v(x_k)   mod m.
```

Given `(x_k, x_{k+1})`, recover

```text
x_{k-1}(v) = x_{k+1}(v) - f_v(x_k)   mod m.
```

Therefore the global second-order map is bijective whenever `f` is deterministic and well-defined.

### 5.3 Interpretation

Reversibility here is algebraic reversibility of the update map. It is not yet thermodynamic time reversal.

### 5.4 Minimal null instance

A minimal interaction choice is

```text
f_v = sum_{u in N(v)} phi(x_k(u), x_k(v)) mod m
```

with `phi` chosen from a preregistered finite rule class and constrained by permutation covariance.

No preferred numeric `m` or `phi` is selected at T13.

### 5.5 Predictions/tests

Test:

- exact forward/backward reconstruction;
- orbit length distribution;
- emergence or absence of nontrivial loops;
- commutator/order sensitivity under composed local perturbations;
- coarse-grained transport behavior;
- whether stable relational structures arise without inserted periodic constants.

Failure of exact inversion falsifies an implementation as D13-A.

## 6. D13-B — Deterministic history-sensitive rule

### 6.1 Motivation

T2-T9 permit endpoint-identical states with different physically relevant trajectory classes. D13-B tests whether a compressed history variable changes future transitions.

### 6.2 State

```text
Sigma_k = (x_k, h_k)
```

with finite history alphabet `H`.

### 6.3 History update

Define a local transition symbol

```text
a_k(v) = encode(x_k(v), local relational transition at v).
```

Update history by a finite automorphism/action

```text
h_{k+1}(v) = T_{a_k(v)}(h_k(v)),
```

where each `T_a` is explicitly defined and, in the reversible subfamily, bijective.

The physical update is then

```text
x_{k+1}(v) = F(C_k(v), h_k(v)).
```

Thus two systems with identical current `x_k` but different history classes may evolve differently:

```text
x_k = x'_k,
h_k != h'_k
=> possibly
x_{k+1} != x'_{k+1}.
```

### 6.4 History compression requirement

`h_k` must have fixed/bounded state size for the base model. It cannot be an unbounded raw log disguised as a state variable.

Candidate finite history encodings include:

- finite group element accumulated from transition generators;
- conjugacy-class label;
- finite quotient of a loop-word algebra;
- finite holonomy surrogate.

### 6.5 Decisive test

Prepare or simulate pairs with the same instantaneous observable state but controlled different `h` labels. Measure whether future readouts differ.

If all future observable distributions are identical for every admissible history pair, the tested history variable is physically redundant and must be quotiented out.

This is the first direct falsification rule for Resolutive history sensitivity.

## 7. D13-C — Stochastic relational rule

### 7.1 State

Use instantaneous or compressed-history state

```text
Sigma_k = (x_k, h_k optional).
```

### 7.2 Local kernel

Define a normalized local transition kernel

```text
P_R(x_{k+1}(v)=a | C_k(v); theta)
```

that is invariant under relation-preserving relabelings.

For interacting simultaneous updates, the global kernel must be explicitly specified rather than assumed to factorize if dependencies exist.

### 7.3 Minimal exponential-family parameterization

One possible implementation family is

```text
P(a|C) = exp[s_theta(a,C)] / sum_b exp[s_theta(b,C)],
```

where the score `s_theta` depends only on declared relational invariants of `C`.

This is a computational parameterization, not a thermodynamic Boltzmann law unless temperature/energy are independently defined.

### 7.4 Tests

Test:

- normalization and covariance;
- calibration of predicted transition frequencies;
- conditional independence claims;
- entropy-rate behavior as a descriptive statistic only;
- whether stochasticity is required by data or merely hides deterministic omitted state.

D13-C must be compared against deterministic baselines with complexity penalties/out-of-sample prediction.

## 8. Common symmetry test

Let `pi` be any automorphism/relabeling preserving the relational structure. For deterministic candidates require

```text
D_R(pi Sigma) = pi D_R(Sigma).
```

For stochastic candidates require

```text
P(pi Sigma' | pi Sigma) = P(Sigma' | Sigma).
```

Violation indicates dependence on arbitrary labels and rejects the candidate implementation.

## 9. Common history test

For each model define an observable map

```text
O : Sigma -> Y.
```

Construct states `Sigma` and `Sigma'` satisfying

```text
O_instant(Sigma) = O_instant(Sigma')
```

but differing in a controlled history invariant. Then compare future observables.

This separates:

```text
endpoint-only dynamics
from
history-sensitive dynamics.
```

## 11. Continuum bridge target

For candidate regimes with slowly varying coarse observables, test whether repeated updates admit an effective generator.

For a represented update operator `U_delta`, ask whether

```text
U_delta ~= I + delta G_eff + O(delta^2)
```

under an explicitly defined scaling limit.

If so, test whether compositions recover the T5 ordered-exponential structure.

No continuum limit is guaranteed.

## 12. Curvature/loop target

Where multiple independent coarse relational directions can be defined, compose small update loops and measure the defect

```text
Delta_loop = U_a U_b U_a^-1 U_b^-1.
```

A nonidentity defect is the discrete precursor of the T5-T6 commutator/curvature structure.

The continuum curvature formula may only be claimed after a controlled scaling derivation.

## 13. Relational clock target

Search for a subsystem/readout `c_k` that is sufficiently distinguishable and monotonic over a regime. Then express another observable as

```text
q(c)
```

and compare relational rates across alternative update parameterizations/coarse-grainings.

The update index `k` itself must not be called physical time.

## 14. Model comparison protocol

The three families are not ranked by aesthetics. Compare them on the same preregistered tasks using:

```text
predictive accuracy/log likelihood as appropriate
parameter/state complexity
reversibility error
symmetry-covariance violations
history ablation effect
robustness under relabeling
coarse-graining stability
out-of-sample prediction
```

A more complex history/stochastic model is justified only if it predicts something the simpler model cannot.
